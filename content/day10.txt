@@ concept
title: patchify：把图片切成 token
--- body
Transformer 吃的是一串 token，形状 (B, N, D)。图片的形状是 (B, C, H, W)。DiT（Diffusion Transformer）的做法：把图片切成 p×p 的小方块（patch），每个方块拉平成一个向量，一个方块就是一个 token。

以 (B, C, H, W) = (2, 3, 8, 8)、p = 2 为例：

- 竖着 8/2 = 4 块，横着 4 块，一共 N = 4×4 = 16 个 patch
- 每个 patch 有 C×p×p = 3×2×2 = 12 个数
- 结果是 (2, 16, 12)

只用 reshape 和 permute 三步就能切好：

1. `x.reshape(B, C, nh, p, nw, p)`：把 H 拆成 (nh, p)，W 拆成 (nw, p)。nh = H/p 表示「第几行方块」，后面那个 p 表示「方块里的第几行像素」
2. `permute(0, 2, 4, 1, 3, 5)`，变成 (B, nh, nw, C, p, p)：「哪一块」的两个维度放前面，「块里的内容」放后面
3. `reshape(B, nh*nw, C*p*p)`：前面两维合成 N，后面三维合成一个向量

patch 按行优先排列：token 0 是左上角那块，token 1 是它右边那块，token nw 是第二行的第一块。每块内部先按通道 C，再按块里的行、块里的列展开。

为什么不能直接 `x.reshape(B, N, C*p*p)`？内存里的数是按「一整行像素接着一整行」排的。直接 reshape 会把一行里连续的几个像素塞进同一个 token，得到的不是方块。下面的代码里能看到。

unpatchify 是反过来：先 reshape 回 (B, nh, nw, C, p, p)，再 permute 回 (B, C, nh, p, nw, p)，最后 reshape 成 (B, C, H, W)。
--- code
x = torch.arange(16.).reshape(1, 1, 4, 4)     # 1 张图，1 个通道，4×4 像素
print(x[0, 0])

B, C, H, W = x.shape
p = 2
nh, nw = H // p, W // p                        # 竖着 2 块，横着 2 块
t = x.reshape(B, C, nh, p, nw, p)              # 把 H 拆成 (nh, p)，W 拆成 (nw, p)
t = t.permute(0, 2, 4, 1, 3, 5)                # (B, nh, nw, C, p, p)
tok = t.reshape(B, nh * nw, C * p * p)
print(tok.shape)                               # 4 个 patch，每个 1*2*2 = 4 个数
print(tok[0])                                  # 第 0 行是左上角那块：0 1 4 5

wrong = x.reshape(B, nh * nw, C * p * p)       # 错误做法：不 permute，直接 reshape
print(wrong[0, 0])                             # 0 1 2 3：是一整行像素，不是方块

@@ concept
title: 二维位置编码：告诉模型每块在哪
--- body
attention 本身不知道 token 的顺序：把输入的 token 打乱，输出也只是跟着同样打乱（练习区有一道题让你亲眼看到）。所以要给每个 token 加上一个「位置向量」，模型才分得清左上角和右下角。

先看一维的正弦编码，和第 8 天的时间嵌入是同一个思路：用一组不同频率的 sin/cos 来表示一个数。

- 选 d/2 个频率：`freqs = 1 / 10000 ** (arange(0, d, 2) / d)`
- 位置 pos 的编码：`cat([sin(pos * freqs), cos(pos * freqs)])`，长度 d

图片上的位置是两个数：（行，列）。DiT 的二维做法很简单：一半维度编码行号，另一半编码列号，拼起来。

- `row = pe_1d(dim/2, 行号)`，`col = pe_1d(dim/2, 列号)`
- 位置（i, j）的编码 = `cat([row[i], col[j]])`，长度 dim
- token 按行优先排：第 k 个 token 在第 `k // w` 行、第 `k % w` 列

例子：4×4 的网格、dim = 64。token 0 在 (0, 0)，token 3 在 (0, 3)，token 12 在 (3, 0)。token 0 和 3 同一行，所以前 32 维一样；token 0 和 12 同一列，所以后 32 维一样。

这张表是固定的，不需要训练。在模型里用 `register_buffer` 存起来，它会跟着 `.to(device)` 一起走，但不会被优化器更新。
--- code
def pe_1d(d, pos):
    freqs = 1.0 / (10000 ** (torch.arange(0, d, 2).float() / d))   # d/2 个频率
    a = pos.float()[:, None] * freqs[None]                          # (len(pos), d/2)
    return torch.cat([a.sin(), a.cos()], dim=-1)                    # (len(pos), d)

print(pe_1d(4, torch.arange(3)))       # 3 个位置，每个 4 维；位置 0 是 [0, 0, 1, 1]

h, w, dim = 2, 3, 8
row = pe_1d(dim // 2, torch.arange(h))    # (2, 4)：每行一个
col = pe_1d(dim // 2, torch.arange(w))    # (3, 4)：每列一个
k = torch.arange(h * w)
print("row:", k // w)                     # 每个 token 在第几行
print("col:", k % w)                      # 每个 token 在第几列
table = torch.stack([torch.cat([row[i // w], col[i % w]]) for i in range(h * w)])
print(table.shape)                                  # (6, 8)
print(torch.equal(table[0, :4], table[2, :4]))      # True：token 0 和 2 同在第 0 行
print(torch.equal(table[0, 4:], table[3, 4:]))      # True：token 0 和 3 同在第 0 列

@@ concept
title: modulate：用条件缩放和平移
--- body
扩散模型每一步都必须知道「现在是什么时刻、噪声有多大」（时间 t）；按类别或文字出图时，还要知道类别或文字。这些信息先被变成一个条件向量 c，形状 (B, D)。问题是：怎么把 c 注入到每个 token 里？

第 8 天的 UNet 用的是 FiLM：`h * (1 + scale) + shift`，scale 和 shift 由条件算出来。DiT 用同一个公式，只是放在 LayerNorm 之后，所以叫 adaLN（adaptive LayerNorm，自适应的层归一化）：

`modulate(x, shift, scale) = x * (1 + scale) + shift`

形状要对齐：x 是 (B, N, D)，有 N 个 token；shift 和 scale 是 (B, D)，每张图一组。要先 `unsqueeze(1)` 变成 (B, 1, D)，才能广播到这张图的所有 token 上。同一张图的 N 个 token 用同一组参数。

为什么写 `1 + scale`，而不是 `scale`？这样 scale = 0、shift = 0 时，modulate 什么都不做（恒等）。网络刚开始时输出都在 0 附近，从「不改动」开始学，比从「全部乘 0」开始稳得多。

为什么 LayerNorm 要写 `elementwise_affine=False`？普通 LayerNorm 自带可学习的 γ（缩放）和 β（平移）。adaLN 的 scale 和 shift 已经在做这件事，而且会随条件变化，所以 LayerNorm 自己那一份就关掉，免得重复。
--- code
x = torch.randn(2, 3, 4)          # 2 张图，每张 3 个 token，每个 4 维
shift = torch.zeros(2, 4)
scale = torch.zeros(2, 4)
print(scale.shape, scale.unsqueeze(1).shape)

y = x * (1 + scale.unsqueeze(1)) + shift.unsqueeze(1)
print(torch.equal(y, x))          # True：全是 0 时是恒等

scale[0] = 1.0                    # 只给第 0 张图 scale = 1
y = x * (1 + scale.unsqueeze(1)) + shift.unsqueeze(1)
print(torch.equal(y[0], 2 * x[0]), torch.equal(y[1], x[1]))   # True True：第 0 张图放大 2 倍，第 1 张不变

@@ concept
title: adaLN-Zero：gate 和零初始化
--- body
DiT 的每个 block 有两条残差分支：attention 和 MLP。每条分支要 3 组参数：shift、scale、gate。一共 6 组，都从条件 c 算出来：

`SiLU → Linear(D, 6D)`，得到 (B, 6D)，再用 `chunk(6, dim=-1)` 切成 6 个 (B, D)，顺序是 shift_msa、scale_msa、gate_msa、shift_mlp、scale_mlp、gate_mlp（msa 是 multi-head self-attention 的缩写）。

gate 乘在分支的输出上：`x = x + gate * attn(...)`。gate = 0 时，这条分支完全不起作用。

adaLN-Zero 里的「Zero」：这个 Linear 的 weight 和 bias 都初始化为 0。于是训练刚开始时，6 组参数全是 0：

- shift = scale = 0，modulate 是恒等
- gate = 0，两条分支都被关掉
- 整个 block 就是恒等映射：输出 = 输入

为什么要这样？几十个 block 叠在一起时，如果每层一开始都随机改一点，信号会被越改越乱。从恒等出发，每层先「什么都不做」，训练再慢慢把 gate 打开。DiT 论文比较了几种注入条件的方式，adaLN-Zero 效果最好。

零初始化不等于学不动：gate 的梯度来自分支的输出，不是 0，所以第一次更新之后 gate 就不再是 0 了。下面的代码能看到 gate 那一组确实有梯度。
--- code
D = 4
lin = nn.Linear(D, 6 * D)
nn.init.zeros_(lin.weight)
nn.init.zeros_(lin.bias)

c = torch.randn(2, D)                                 # 2 张图的条件向量
groups = lin(F.silu(c)).chunk(6, dim=-1)
print(len(groups), groups[0].shape)                   # 6 组，每组 (2, 4)
print(all(bool((g == 0).all()) for g in groups))      # True：一开始全是 0

x = torch.randn(2, 3, D)
branch = nn.Linear(D, D)                              # 随便拿一个层当分支
gate = groups[2]                                      # gate_msa
y = x + gate.unsqueeze(1) * branch(x)
print(torch.equal(y, x))                              # True：恒等映射

y.pow(2).sum().backward()
print(lin.weight.grad[2 * D:3 * D].abs().sum() > 0)   # tensor(True)：gate 那一组有梯度

@@ concept
title: DiTBlock：第 4 天的 Block 换个条件注入
--- body
先回忆第 4 天的 pre-LN Block：

```
x = x + attn(ln1(x))
x = x + mlp(ln2(x))
```

DiTBlock 只改了三处：

1. LayerNorm 不带 γ/β（`elementwise_affine=False`），后面接 modulate
2. 每条分支的输出乘上 gate
3. attention 不加 causal mask：图片的每一块都能看到所有其他块，没有「未来」一说

```
s1, sc1, g1, s2, sc2, g2 = modulation(c)
x = x + g1.unsqueeze(1) * attn(modulate(norm1(x), s1, sc1))
x = x + g2.unsqueeze(1) * mlp(modulate(norm2(x), s2, sc2))
```

MLP 和第 4 天一样：`Linear(D, 4D) → GELU → Linear(4D, D)`。x 的形状进来是 (B, N, D)，出去还是 (B, N, D)；c 是 (B, D)。

练习区已经给你准备好了 `SelfAttention(dim, n_head)`，就是下面代码里这个类，直接用即可。它和第 4 天的 CausalSelfAttention 只差两点：没有 causal mask，所以也不需要 block_size 和那个下三角 buffer。它用的 `F.scaled_dot_product_attention` 和第 4 天手写的 softmax(QKᵀ/√d)·V 算的是同一个东西。
--- code
class SelfAttention(nn.Module):
    def __init__(self, dim, n_head):
        super().__init__()
        self.n_head = n_head
        self.qkv = nn.Linear(dim, 3 * dim, bias=False)
        self.proj = nn.Linear(dim, dim, bias=False)

    def forward(self, x):
        B, T, C = x.shape
        hd = C // self.n_head
        q, k, v = self.qkv(x).split(C, dim=-1)
        q, k, v = (t.view(B, T, self.n_head, hd).transpose(1, 2) for t in (q, k, v))
        o = F.scaled_dot_product_attention(q, k, v)     # 没有 is_causal=True：每个 token 看所有 token
        return self.proj(o.transpose(1, 2).reshape(B, T, C))


torch.manual_seed(0)
attn = SelfAttention(8, 2)
x = torch.randn(1, 4, 8)          # 4 个 token
x2 = x.clone()
x2[0, 3] += 1.0                   # 只改最后一个 token
with torch.no_grad():
    diff = (attn(x)[0, 0] - attn(x2)[0, 0]).abs().max()
print(f"{diff.item():.4f}")       # 不是 0：第 0 个 token 也「看到」了最后一个

@@ concept
title: Rectified flow：从噪声到数据走直线
--- body
第 8 天的 DDPM：按 beta 调度一步步加噪，模型预测噪声 ε，公式里有 alpha、alpha_bar 一大串，原版采样要 1000 步。

Flow matching 换了个思路。这里用最简单的一种，叫 rectified flow：

- 取一份噪声 x0 ~ N(0, I) 和一张真图 x1
- 在两者之间连一条直线：`x_t = (1 - t) * x0 + t * x1`，t 从 0 走到 1
- t = 0 是纯噪声，t = 1 是干净数据。注意这和 DDPM 相反（DDPM 里 t 越大越吵）。有些论文和库（比如 Stable Diffusion 3）又把 t = 1 定为噪声，读别人代码时先看清约定
- 沿这条直线走的速度（x_t 对 t 求导）：`v = x1 - x0`。它不随 t 变化，因为直线上的速度是恒定的

模型学的就是这个速度：输入 (x_t, t)，输出一个和 x_t 同形状的 v。训练一步只有四件事：

1. 每个样本随机抽一个 t ~ U(0, 1)：`torch.rand(B)`
2. 抽和数据同形状的噪声：`torch.randn_like(x1)`
3. 算出 x_t
4. loss = MSE(model(x_t, t), x1 - x0)

形状细节：t 是 (B,)，图片是 (B, C, H, W)。要把 t reshape 成 (B, 1, 1, 1)，才能让每个样本用自己的 t。通用写法：`t.reshape(-1, *([1] * (x.dim() - 1)))`，不管数据有几维都对。

一个好用的检验：如果模型永远输出 0，loss 就等于目标 v 的方差。数据也是标准正态时，Var(x1 - x0) = 1 + 1 = 2，所以 loss ≈ 2。
--- code
torch.manual_seed(0)
x0 = torch.randn(3)                         # 噪声
x1 = torch.tensor([2.0, -1.0, 0.5])         # 「数据」
for t in [0.0, 0.5, 1.0]:
    print(t, (1 - t) * x0 + t * x1)         # t=0 是噪声，t=1 是数据
print("v:    ", x1 - x0)

h = 1e-3                                    # 数值求导：x_t 在 t=0.3 附近的变化率
xa = (1 - 0.3) * x0 + 0.3 * x1
xb = (1 - 0.3 - h) * x0 + (0.3 + h) * x1
print("dx/dt:", (xb - xa) / h)              # 和 v 几乎一样

img = torch.randn(4, 3, 8, 8)               # 一个 batch 的图片
t = torch.rand(4)                           # 每张图一个 t
print(t.reshape(-1, *([1] * (img.dim() - 1))).shape)   # (4, 1, 1, 1)

data, noise = torch.randn(100000), torch.randn(100000)
print(((data - noise) ** 2).mean())         # ≈ 2：永远输出 0 的模型的 loss

@@ concept
title: 欧拉采样：沿着速度一步步走
--- body
训练好的模型能告诉你：在位置 x、时刻 t，速度是 v(x, t)。采样就是从纯噪声出发，沿着速度一小步一小步走到 t = 1。最简单的走法叫欧拉法（Euler method）：

```
x = 纯噪声;  dt = 1 / steps
for i in range(steps):
    t = i * dt
    x = x + v(x, t) * dt
```

几个要点：

- 时间从 t = 0 开始，最后一步用的是 t = 1 - dt，走完正好到 t = 1
- 给模型的 t 要做成 (B,) 的张量：`torch.full((B,), i * dt)`，batch 里每个样本一个
- 采样不需要梯度，函数上加 `@torch.no_grad()`，省显存也更快

检验积分写对没有，有个好办法：用一个「速度恒为 5」的假模型。从 x 出发走完 1 个单位时间，结果必须是 x + 5，而且不管 steps 是 4 还是 100 都一样。如果 dt 写错了（比如写成 `1 / (steps - 1)`），结果就会随步数变化。

步数和路径的关系：速度不变（路径是直线）时，欧拉法一步都不会走偏；路径越弯，每一步的误差越大，需要的步数越多。下面代码里「速度 = x」就是一条弯路径，从 1 出发，真正的终点是 e ≈ 2.718，1 步只能走到 2.0。rectified flow 学出来的路径大体是直的（不完全直：很多条噪声到数据的直线会交叉，模型学到的是它们的平均速度），所以常常 20–50 步就够了，而 DDPM 原版要 1000 步。
--- code
def euler(v, x, steps):
    dt = 1.0 / steps
    for i in range(steps):
        x = x + v(x, i * dt) * dt
    return x

const5 = lambda x, t: torch.full_like(x, 5.0)     # 速度恒为 5
x0 = torch.tensor([1.0, -2.0])
print(euler(const5, x0, 4), euler(const5, x0, 100))   # 都是 x0 + 5

curved = lambda x, t: x                           # 速度 = x 本身：弯的路径
for n in [1, 4, 100]:
    print(n, round(euler(curved, torch.tensor([1.0]), n).item(), 4))   # 真值 e ≈ 2.7183

@@ concept
title: MiniDiT：把零件拼成模型
ref: day8, day10
--- body
MiniDiT 的输入是带噪的图 x (B, C, H, W) 和时间 t (B,)，输出和 x 同形状的速度。以 in_ch = 4、img = 8、patch = 2、dim = 64、B = 2 为例，一步步看形状：

1. `patchify(x, 2)`：(2, 4, 8, 8) → (2, 16, 16)。16 个 patch，每个 2×2×4 = 16 个数
2. `Linear(16, 64)`：每个 token 变成 64 维，(2, 16, 64)
3. 加上二维位置编码 `pos_embed_2d(64, 4, 4)`，形状 (16, 64)，自动广播到整个 batch
4. 时间条件：`c = t_mlp(timestep_embedding(t, 64))`，形状 (2, 64)。timestep_embedding 就是第 8 天写的正弦时间嵌入，t_mlp 是 `Linear(64, 64) → SiLU → Linear(64, 64)`
5. n_layer 个 DiTBlock：`h = block(h, c)`，形状一直是 (2, 16, 64)
6. 输出层：LayerNorm（不带 γ/β）→ modulate → `Linear(64, 16)`，得到 (2, 16, 16)。这里的 shift、scale 只要 2 组：`Linear(64, 128)(silu(c))` 再 `chunk(2)`
7. `unpatchify`：(2, 16, 16) → (2, 4, 8, 8)

零初始化：输出层里算 shift/scale 的那个 Linear 和最后那个 `Linear(64, 16)`，weight 和 bias 都设为 0。于是没训练时，整个网络对任何输入都输出 0。这是 DiT 论文的做法，不是 bug：训练从「预测速度为 0」开始，梯度从一个干净的起点长出来。

怎么确认时间条件真的接上了？零初始化时输出全是 0，看不出来。先给所有参数加一点随机扰动（模拟训练了几步），再比较 t = 0 和 t = 1 的输出，两者应该不同。

下面的代码直接调用了今天练习要写的 patchify、pos_embed_2d、DiTBlock、unpatchify（后台已经准备好参考实现）和第 8 天的 timestep_embedding，只看形状。
--- code
torch.manual_seed(0)
B, C, H, p, dim = 2, 4, 8, 2, 64
x = torch.randn(B, C, H, H)
t = torch.rand(B)

tok = patchify(x, p)
print("patchify:   ", tuple(tok.shape))
h = nn.Linear(p * p * C, dim)(tok) + pos_embed_2d(dim, H // p, H // p)
print("embed + pos:", tuple(h.shape))
t_mlp = nn.Sequential(nn.Linear(dim, dim), nn.SiLU(), nn.Linear(dim, dim))
c = t_mlp(timestep_embedding(t, dim))
print("condition c:", tuple(c.shape))
h = DiTBlock(dim, 4)(h, c)
print("DiTBlock:   ", tuple(h.shape))
out = unpatchify(nn.Linear(dim, p * p * C)(h), p, H, H, C)
print("output:     ", tuple(out.shape))

    raise todo()
--- solution
def patchify(x, p):
    B, C, H, W = x.shape
    nh, nw = H // p, W // p
    x = x.reshape(B, C, nh, p, nw, p)
    x = x.permute(0, 2, 4, 1, 3, 5)            # (B, nh, nw, C, p, p)
    return x.reshape(B, nh * nw, C * p * p)


def unpatchify(tok, p, H, W, C):
    B = tok.size(0)
    nh, nw = H // p, W // p
    x = tok.reshape(B, nh, nw, C, p, p).permute(0, 3, 1, 4, 2, 5)   # (B, C, nh, p, nw, p)
    return x.reshape(B, C, H, W)

--- solution
def _pe_1d(d, pos):
    freqs = 1.0 / (10000 ** (torch.arange(0, d, 2).float() / d))
    a = pos.float()[:, None] * freqs[None]         # (L, d/2)
    return torch.cat([a.sin(), a.cos()], dim=-1)   # (L, d)


def pos_embed_2d(dim, h, w):
    half = dim // 2
    row = _pe_1d(half, torch.arange(h))         # (h, half)
    col = _pe_1d(half, torch.arange(w))         # (w, half)
    r = row[:, None, :].expand(h, w, half)
    c = col[None, :, :].expand(h, w, half)
    return torch.cat([r, c], dim=-1).reshape(h * w, dim)

class DiTBlock(nn.Module):
    def __init__(self, dim, n_head):
        super().__init__()
        self.norm1 = nn.LayerNorm(dim, elementwise_affine=False)
        self.norm2 = nn.LayerNorm(dim, elementwise_affine=False)
        self.attn = SelfAttention(dim, n_head)
        self.mlp = nn.Sequential(nn.Linear(dim, 4 * dim), nn.GELU(), nn.Linear(4 * dim, dim))
        self.modulation = AdaLNModulation(dim)

    def forward(self, x, c):
        s1, sc1, g1, s2, sc2, g2 = self.modulation(c)
        x = x + g1.unsqueeze(1) * self.attn(modulate(self.norm1(x), s1, sc1))
        x = x + g2.unsqueeze(1) * self.mlp(modulate(self.norm2(x), s2, sc2))
        return x

def flow_interpolate(x0_noise, x1_data, t):
    tt = t.reshape(-1, *([1] * (x0_noise.dim() - 1)))    # (B,) -> (B, 1, 1, 1)

@torch.no_grad()
def flow_sample(model, shape, steps=20, device="cpu"):
    x = torch.randn(shape, device=device)
    dt = 1.0 / steps
    for i in range(steps):
        t = torch.full((shape[0],), i * dt, device=device)
        x = x + model(x, t) * dt
    return x

--- solution
class MiniDiT(nn.Module):
    def __init__(self, in_ch=4, img=8, patch=2, dim=64, n_layer=2, n_head=4):
        super().__init__()
        self.in_ch, self.img, self.patch, self.dim = in_ch, img, patch, dim
        pdim = patch * patch * in_ch
        self.embed = nn.Linear(pdim, dim)
        self.register_buffer("pos", pos_embed_2d(dim, img // patch, img // patch))
        self.t_mlp = nn.Sequential(nn.Linear(dim, dim), nn.SiLU(), nn.Linear(dim, dim))
        self.blocks = nn.ModuleList([DiTBlock(dim, n_head) for _ in range(n_layer)])
        self.norm_out = nn.LayerNorm(dim, elementwise_affine=False)
        self.mod_out = nn.Linear(dim, 2 * dim)
        nn.init.zeros_(self.mod_out.weight)
        nn.init.zeros_(self.mod_out.bias)
        self.head = nn.Linear(dim, pdim)
        nn.init.zeros_(self.head.weight)
        nn.init.zeros_(self.head.bias)

    def forward(self, x, t):
        h = self.embed(patchify(x, self.patch)) + self.pos        # (B, N, dim)
        c = self.t_mlp(timestep_embedding(t, self.dim))           # (B, dim)
        for b in self.blocks:
            h = b(h, c)
        shift, scale = self.mod_out(F.silu(c)).chunk(2, dim=-1)
        h = self.head(modulate(self.norm_out(h), shift, scale))   # (B, N, patch*patch*in_ch)
        return unpatchify(h, self.patch, self.img, self.img, self.in_ch)

- 这一层的参数永远学不动，因为参数是 0，梯度也是 0

--- prompt
下面的速度场，是「只有一个数据点 d = 3」时的理想速度：在时刻 t、位置 x，它总是指向 d，大小正好让你在剩下的时间 1 - t 里走到 d。起点是 -1。写出打印的三行。
--- code
d = torch.tensor([3.0])
v = lambda x, t: (d - x) / (1 - t)

for steps in [1, 2, 4]:
    x = torch.tensor([-1.0])           # 起点（「噪声」）
    dt = 1.0 / steps
    for i in range(steps):
        x = x + v(x, i * dt) * dt
    print(steps, x.item())
--- explain
三行都是 3.0。第一步 t = 0：v = (3 - (-1)) / 1 = 4。走 dt 之后，x 正好落在从 -1 到 3 的直线上，之后每一步都还在这条直线上，速度一直是 4。速度不变，欧拉法就没有误差，所以 1 步、2 步、4 步都正好走到 3.0。比如 2 步：-1 → 1 → 3。

真实模型面对很多数据点，学到的是平均速度，路径有些弯，所以还需要 20–50 步。卡片里「速度 = x」那条弯路径，1 步只能走到 2.0，离真值 e ≈ 2.718 差很远。

class DiTBlock(nn.Module):
    def __init__(self, dim, n_head):
        super().__init__()
        self.norm1 = nn.LayerNorm(dim, elementwise_affine=False)
        self.norm2 = nn.LayerNorm(dim, elementwise_affine=False)
        self.attn = SelfAttention(dim, n_head)
        self.mlp = nn.Sequential(nn.Linear(dim, 4 * dim), nn.GELU(), nn.Linear(4 * dim, dim))
        self.modulation = AdaLNModulation(dim)

    def forward(self, x, c):
        s1, sc1, g1, s2, sc2, g2 = self.modulation(c)
        x = x + g1.unsqueeze(1) * self.attn(modulate(self.norm1(x), s1, sc1))
        x = x + g2.unsqueeze(1) * self.mlp(modulate(self.norm2(x), s2, sc2))
        return x

--- solution
def flow_loss(model, x1_data):
    B = x1_data.size(0)
    t = torch.rand(B, device=x1_data.device)
    noise = torch.randn_like(x1_data)
    tt = t.reshape(-1, *([1] * (x1_data.dim() - 1)))
    xt = (1 - tt) * noise + tt * x1_data
    return F.mse_loss(model(xt, t), x1_data - noise)
--- tests
@check("Flow 训练目标")
def t07():
    seed(1)

    class Zero(nn.Module):
        def forward(self, x, t):
            return torch.zeros_like(x)

    l = flow_loss(Zero(), torch.randn(4096, 1, 4, 4))
    true(l.dim() == 0, "loss 应该是一个标量（0 维张量）：F.mse_loss 默认就会求平均")
    true(abs(l.item() - 2.0) < 0.15,
         f"永远输出 0 的模型，loss 应该 ≈ Var(data - noise) = 2，实际是 {l.item():.3f}")

    # 一个知道数据的模型，能从 (x_t, t) 算出真正的速度：
    # data - x_t = (1 - t) * (data - noise)，所以 v = (data - x_t) / (1 - t)。它的 loss 必须 ≈ 0
    data = torch.randn(256, 1, 4, 4)

    class Oracle(nn.Module):
        def forward(self, x, t):
            return (data - x) / (1 - t.reshape(-1, 1, 1, 1))

         f"预测出真实速度的模型，loss 应该 ≈ 0，实际是 {lo.item():.3f}。检查约定 "
