@@ concept
title: shape 与 dim：先读懂张量的形状
--- body
张量（tensor）就是多维数组。`x.shape` 告诉你它每一维有多长。写模型时，大部分 bug 都是 shape 对不上。所以要养成一个习惯：每写一行，先在心里说出结果的 shape，再往下写。

语言模型的代码里，最常见的是这三个字母：
- `B`：batch，一次喂给模型几条样本
- `T`：time，每条样本有几个 token
- `C`：channels，每个 token 用多长的向量表示

`(B, T, C) = (2, 5, 4)` 读作：2 条样本，每条 5 个 token，每个 token 是一个 4 维向量。

`dim` 是「第几维」，从 0 开始数；也可以倒着数，`dim=-1` 就是最后一维。下面是常用操作对 shape 的影响（x 是 `(2, 5, 4)`）：
- `x.sum(dim=-1)`、`x.mean(dim=-1)`：沿最后一维求和或求平均，这一维消失 → `(2, 5)`
- 再加上 `keepdim=True`：这一维留下，长度变成 1 → `(2, 5, 1)`。之后还要和 x 做加减时就用它
- `x.unsqueeze(1)`：在第 1 维插入一个长度为 1 的维 → `(2, 1, 5, 4)`。`squeeze(1)` 是反过来
- `torch.cat([x, x], dim=0)`：沿第 0 维拼接，这一维变长 → `(4, 5, 4)`
- `x.transpose(0, 1)`：交换两维 → `(5, 2, 4)`。`x.permute(2, 0, 1)` 一次把所有维按新顺序排好 → `(4, 2, 5)`
- `x.flatten(1)`：从第 1 维到最后一维合成一维 → `(2, 20)`
- `x @ W`：矩阵乘，只看最后两维，要求 x 的最后一维等于 W 的倒数第二维。W 是 `(4, 3)` 时 → `(2, 5, 3)`，前面的维原样保留
--- code
x = torch.randn(2, 5, 4)             # (B, T, C)
W = torch.randn(4, 3)
print("x                    ", tuple(x.shape))
print("x.mean(dim=-1)       ", tuple(x.mean(dim=-1).shape))
print("x.mean(-1, keepdim)  ", tuple(x.mean(dim=-1, keepdim=True).shape))
print("x.unsqueeze(1)       ", tuple(x.unsqueeze(1).shape))
print("torch.cat([x, x], 0) ", tuple(torch.cat([x, x], dim=0).shape))
print("x.transpose(0, 1)    ", tuple(x.transpose(0, 1).shape))
print("x.permute(2, 0, 1)   ", tuple(x.permute(2, 0, 1).shape))
print("x.flatten(1)         ", tuple(x.flatten(1).shape))
print("x @ W                ", tuple((x @ W).shape))

@@ concept
title: 广播：从右往左对齐
--- body
两个 shape 不同的张量做 `+ - * /` 时，PyTorch 会自动**广播**（broadcasting）：把小的那个扩展成和大的一样，再逐个元素计算。（内存里并没有真的复制，但你可以这样想。）

规则只有一条：**把两个 shape 靠右对齐，从最后一维开始一对一对地比**。每一对必须满足下面之一：
- 两个长度相等
- 其中一个是 1（它会被扩展成另一个的长度）
- 其中一个根本没有这一维（当成 1）

例子：
- `(2, 3, 4) + (4,)`：`(4,)` 被当成 `(1, 1, 4)`，结果 `(2, 3, 4)`。给每个 token 加同一个 bias 就是这么写的
- `(2, 1, 4) + (3, 1)`：对齐后是 `(2, 1, 4)` 和 `(1, 3, 1)`，每一维取较大的，结果 `(2, 3, 4)`。两边都被扩展了
- `(2, 3, 4) + (3,)`：最右边是 4 对 3，都不是 1 → 报错

广播最危险的地方是**不报错却算错**。模型输出常常是 `(B, 1)`，标签是 `(B,)`。两者相减得到 `(B, B)`：每个预测减了每个标签。loss 照样算得出来，只是完全不对。这时要先 `squeeze(-1)`，把输出变成 `(B,)`。

广播也很好用：一个 `(B, T, 1)` 的 mask 乘上 `(B, T, C)` 的特征，就能把某些位置的整条向量清零（第 7 张卡会用到）。
--- code
x = torch.ones(2, 3, 4)
bias = torch.tensor([0., 10., 20., 30.])        # (4,)
print("(2,3,4) + (4,)  ->", tuple((x + bias).shape))
print("第一个 token    :", (x + bias)[0, 0].tolist())   # 每个 token 都加了同一个 bias
a = torch.zeros(2, 1, 4)
b = torch.zeros(3, 1)
print("(2,1,4) + (3,1) ->", tuple((a + b).shape))
pred = torch.tensor([[1.0], [2.0], [3.0]])      # (3, 1)
y = torch.tensor([1.0, 2.0, 3.0])               # (3,)
print("(3,1) - (3,)    ->", tuple((pred - y).shape), " 不报错，但已经错了")
print("squeeze 之后    ->", tuple((pred.squeeze(-1) - y).shape))
try:
    x + torch.ones(3)
except RuntimeError as e:
    print("(2,3,4) + (3,) 报错:", e)

@@ concept
title: 拆头与合头：view、transpose、contiguous
--- body
多头注意力（multi-head attention，第 4 天细讲）会把每个 token 的 C 维向量切成 `nh` 段（nh 是头的个数），每段长 `hs = C / nh`（head size），每个头各算各的。

通常一个 Linear 一次算出 q、k、v，拼在一起是 `(B, T, 3C)`。`qkv.split(C, dim=-1)` 沿最后一维每 C 个切一块，得到三个 `(B, T, C)`。

然后每一个都要拆头，shape 的变化是：

`(B, T, C)` → `view(B, T, nh, hs)` → `(B, T, nh, hs)` → `transpose(1, 2)` → `(B, nh, T, hs)`

为什么要 transpose？后面的矩阵乘只看最后两维。把头移到前面，最后两维就是 `(T, hs)`：每个头里是一个「T 个 token × hs 维」的小矩阵。

三个工具的区别：
- `view(新 shape)`：不复制数据，只是换一种方式读同一块内存，元素总数必须不变。它按内存里的顺序切：把最后一维 C 切成 `(nh, hs)`，第 0 个头正好拿到前 hs 个数
- `transpose(i, j)`：交换两维。也不复制数据，只改「跳着读」的方式。结果在内存里就**不连续**了（contiguous：元素按行紧挨着存放）
- `.contiguous()`：真的按现在的顺序复制一份，变回连续

合头是反过来：`(B, nh, T, hs)` → `transpose(1, 2)` → `(B, T, nh, hs)` → `(B, T, C)`。transpose 之后直接 `view` 会报错 `view size is not compatible with input tensor's size and stride`，因为 view 要求内存连续。修法：`.contiguous().view(...)`，或者改用 `.reshape(...)`（需要时它自己会复制）。

注意：不能跳过 transpose，直接把 `(B, nh, T, hs)` view 成 `(B, T, C)`。shape 看起来对，也不报错，但数字的顺序全乱了。
--- code
B, T, nh, hs = 1, 3, 2, 2
C = nh * hs
x = torch.arange(B * T * C).view(B, T, C)   # 3 个 token，每个 4 维；数字 = 它在内存里的位置
print("x[0]    :", x[0].tolist())
h = x.view(B, T, nh, hs).transpose(1, 2)    # 拆头 -> (B, nh, T, hs)
print("拆头后  :", tuple(h.shape))
print("第 0 个头:", h[0, 0].tolist())        # 每个 token 的前 2 维
print("第 1 个头:", h[0, 1].tolist())        # 每个 token 的后 2 维
y = h.contiguous()                          # 假装这是 attention 新算出来的输出
t = y.transpose(1, 2)                       # (B, T, nh, hs)
print("transpose 后还连续吗?", t.is_contiguous())
try:
    t.view(B, T, C)
except RuntimeError as e:
    print("直接 view 报错:", str(e)[:48], "...")
back = t.contiguous().view(B, T, C)
print("contiguous().view 还原了吗?", torch.equal(back, x))

title: 矩阵乘：Linear、attention 分数与 einsum
--- body
`nn.Linear(in, out)` 里存着两个参数：`weight`，shape 是 `(out, in)`，注意不是 `(in, out)`；`bias`，shape 是 `(out,)`。它做的事只有一行：

`y = x @ W.T + b`

`x` 可以是 `(N, in)`，也可以是 `(B, T, in)`。`@` 只拿最后两维做矩阵乘，前面的维原样保留，所以输出是 `(..., out)`。bias 靠广播加到每一行上。

attention 分数（第 4 天细讲）：每个 query 和每个 key 做点积，再除以 `sqrt(hs)`。q、k 都是 `(B, nh, T, hs)`，把 k 的最后两维交换一下就能直接相乘：

`q @ k.transpose(-2, -1)`：`(B, nh, T, hs) @ (B, nh, hs, T)` → `(B, nh, T, T)`

结果里第 i 行第 j 列，就是第 i 个 query 和第 j 个 key 的点积。

`torch.einsum` 是另一种写法：给每一维起一个字母名字，一眼就能看出哪些维相乘、哪些维求和。规则：
- 逗号隔开每个输入的维度名，箭头右边是输出的维度名
- 在输入里出现、但输出里没有的字母，会被相乘后求和
- 输入和输出都有的字母，原样保留

例如普通矩阵乘 `a @ b` 就是 `torch.einsum("ik,kj->ij", a, b)`：k 不在输出里，所以沿 k 相乘再求和。`"btc,btc->bt"` 则是每个 token 上两个向量的点积。
--- code
lin = nn.Linear(4, 3)
print("weight", tuple(lin.weight.shape), " bias", tuple(lin.bias.shape))
x = torch.randn(2, 5, 4)                                  # (B, T, in)
mine = x @ lin.weight.T + lin.bias
print("手写:", tuple(mine.shape), " 和 nn.Linear 一样吗?", torch.allclose(mine, lin(x), atol=1e-6))
a, b = torch.randn(3, 4), torch.randn(4, 2)
print("einsum ik,kj->ij 等于 a @ b 吗?", torch.allclose(torch.einsum("ik,kj->ij", a, b), a @ b, atol=1e-6))
u, v = torch.randn(2, 5, 4), torch.randn(2, 5, 4)
dots = torch.einsum("btc,btc->bt", u, v)                  # 每个 token 一个点积
print("逐 token 点积:", tuple(dots.shape), torch.allclose(dots, (u * v).sum(-1), atol=1e-6))

@@ concept
title: 沿最后一维：softmax、LayerNorm、RMSNorm
--- body
这三个操作是同一个套路：**每个向量单独处理**（沿最后一维）。先用 `keepdim=True` 算出每个向量的一个统计量（最大值、均值、方差），shape 是 `(..., 1)`；再靠广播把它作用到这个向量的每个元素上。

**softmax** 把一组任意实数变成加起来等于 1 的概率：

`softmax(x)_i = exp(x_i) / (exp(x_1) + ... + exp(x_n))`

直接算有个坑：`exp(1000)` 在 float32 里是 `inf`，`inf / inf = nan`。办法是先减去这组数的最大值 m。分子分母同时乘了 `exp(-m)`，结果不变；但最大的数变成了 0，`exp` 最多是 1，不会溢出。

**LayerNorm**：每个向量减去自己的均值，除以自己的标准差，再乘可学习的 `g`（gain，缩放），加 `b`（bias，偏移）：

`y = (x - mean) / sqrt(var + eps) * g + b`

这里的 `var` 是除以 N 的方差：`x.var(-1, keepdim=True, unbiased=False)`。默认的 `unbiased=True` 除以 N-1，和 PyTorch 的 LayerNorm 对不上。`eps` 是一个很小的数，防止除以 0。

**RMSNorm**（Llama 用它，第 5 天会用到）更简单：不减均值，也没有 b，只除以均方根（root mean square）：

`y = x / sqrt(mean(x²) + eps) * g`

`torch.rsqrt(t)` 就是 `1 / sqrt(t)`。g 全是 1 时，RMSNorm 之后每个向量的 `mean(y²)` 约等于 1。
--- code
x = torch.tensor([1000.0, 1001.0, 1002.0])
print("直接算  :", (x.exp() / x.exp().sum()).tolist())
e = (x - x.max()).exp()                     # 先减最大值
print("减最大值:", [round(v, 4) for v in (e / e.sum()).tolist()])
print("官方    :", [round(v, 4) for v in F.softmax(x, dim=0).tolist()])

h = torch.tensor([[1.0, 2.0, 3.0, 6.0]])
mu = h.mean(-1, keepdim=True)
var = h.var(-1, keepdim=True, unbiased=False)
print("均值", mu.item(), " 方差", var.item(), " 统计量的 shape", tuple(mu.shape))
z = (h - mu) / torch.sqrt(var + 1e-5)
print("归一化后:", [round(v, 3) for v in z[0].tolist()])
print("新的均值 %.3f  新的方差 %.3f" % (abs(z.mean().item()), z.var(unbiased=False).item()))

title: cross_entropy：log_softmax 加 gather
--- body
分类模型对每个样本输出 V 个 **logits**（原始分数，还没过 softmax），V 是类别数（语言模型里就是词表大小）。**cross_entropy**（交叉熵）只关心一件事：模型给「正确答案」的概率 p 有多大。每个样本的 loss 是 `-log(p)`，再对所有样本取平均。p 越接近 1，loss 越接近 0。

手写分三步：
1. 算 log 概率：`logp = logits - logits.logsumexp(dim=-1, keepdim=True)`，这就是 `F.log_softmax`。`logsumexp` 算的是 `log(exp(x_1) + ... + exp(x_n))`，内部已经减过最大值，不会溢出。别写 `softmax(...).log()`：概率小到变成 0 时，`log(0) = -inf`
2. 用 `gather` 取出每个样本正确类别的那一个 log 概率
3. 取负号，求平均

`input.gather(dim, index)`：沿 `dim` 按 `index` 里的下标取值。`index` 的维数必须和 `input` 一样。标签是 `(N,)`，要先 `unsqueeze(-1)` 变成 `(N, 1)`；取出来是 `(N, 1)`，再 `squeeze(-1)` 变回 `(N,)`。

一个要记住的数：如果 logits 全相等（模型完全平均地猜），每个类的概率都是 `1/V`，loss 就是 `-log(1/V) = ln V`。刚初始化的模型，第一步的 loss 应该接近这个数。

语言模型的 logits 是 `(B, T, V)`，标签是 `(B, T)`。`F.cross_entropy` 要求类别在第 1 维：`(N, V)` 配 `(N,)`。最省事的做法是把 B 和 T 合成一维：`logits.reshape(-1, V)` 配 `targets.reshape(-1)`，变成 `B*T` 道独立的「V 选 1」分类题。
--- code
logits = torch.tensor([[2.0, 0.0, -1.0],
                       [0.0, 3.0,  0.0]])        # N=2 个样本，V=3 类
y = torch.tensor([0, 2])                         # 正确答案的下标
logp = F.log_softmax(logits, dim=-1)
print("log 概率  :", [[round(v, 3) for v in row] for row in logp.tolist()])
picked = logp.gather(-1, y.unsqueeze(-1))        # index (2, 1) -> 结果 (2, 1)
print("gather 取出:", [round(v, 3) for v in picked.squeeze(-1).tolist()])
print("取负求平均:", round(-picked.mean().item(), 4))
print("官方 loss :", round(F.cross_entropy(logits, y).item(), 4))
V = 3
flat = F.cross_entropy(torch.zeros(1, V), torch.tensor([1]))
print("logits 全相等:", round(flat.item(), 4), "  ln 3 =", round(math.log(V), 4))

@@ concept
title: 变长序列：padding 与 mask
--- body
一个 batch 里的句子长短不一，但张量必须是规整的长方体。办法是 **padding**（补齐）：短的样本在右边补上一个特殊的 `pad_id`，一直补到最长那条的长度 `Tmax`。同时做一个同样 shape 的 **mask**：真实 token 的位置是 1，补出来的位置是 0。

DataLoader 把几条样本拼成一个 batch 的那个函数叫 `collate_fn`，padding 通常就写在这里。几个有用的工具：
- `torch.full((B, Tmax), pad_id, dtype=torch.long)`：先造一个全是 pad_id 的张量，再把真实 token 填进去
- `x[i, :n] = s`：把长度为 n 的样本 s 填进第 i 行的前 n 个位置
- token 下标用 `int64`（也就是 `torch.long`）：`nn.Embedding` 只接受整数下标，而 `F.cross_entropy` 的类别标签用 int32 会报错，所以统一用 int64

有了 padding，之后所有的统计都要记得 mask。比如求每个样本的平均向量：pad 位置的数不能算进分子，分母也只能数真实 token 的个数：

`平均 = sum(x * mask) / sum(mask)`

x 是 `(B, T, C)`，mask 是 `(B, T)`。先 `mask.unsqueeze(-1)` 变成 `(B, T, 1)`，靠广播乘到每个通道上。mask 是整数时，用 `.to(x.dtype)` 转成浮点数。
--- code
seqs = [torch.tensor([5, 6, 7]), torch.tensor([8])]
x = torch.full((2, 3), 0, dtype=torch.long)       # pad_id = 0
x[0, :3] = seqs[0]
x[1, :1] = seqs[1]
print("padding 后:", x.tolist())

feat = torch.tensor([[[1.0], [3.0], [8.0]],      # 样本 0：2 个真实 token + 1 个 pad
                     [[2.0], [8.0], [8.0]]])     # 样本 1：1 个真实 token + 2 个 pad  (B=2, T=3, C=1)
mask = torch.tensor([[1, 1, 0],
                     [1, 0, 0]])                 # pad 位置的 8.0 是没有意义的数
print("直接 mean  :", feat.mean(1).squeeze(-1).tolist())   # pad 也被算进去了
m = mask.unsqueeze(-1).to(feat.dtype)                     # (2, 3, 1)
print("masked mean:", ((feat * m).sum(1) / m.sum(1)).squeeze(-1).tolist())

@@ concept
title: Parameter、buffer 与 autograd
--- body
自己写模型时要继承 `nn.Module`。在 `__init__` 里放张量有三种方式，效果完全不同：
- `self.w = nn.Parameter(t)`：**可学习参数**。出现在 `model.parameters()` 里，优化器会更新它；会存进 `state_dict()`（保存下来的权重）
- `self.register_buffer("name", t)`：**buffer**。不学习，但算模型状态的一部分：会存进 `state_dict()`，`model.to("cuda")` 时也会跟着搬过去；它不在 `parameters()` 里，优化器不碰它。例子：BatchNorm 的滑动平均、固定的 causal mask
- `self.t = torch.zeros(3)`：普通属性。两边都不算：保存时丢失，`.to()` 时留在原地，换到 GPU 就会报设备不一致

更新 buffer 时，放在 `with torch.no_grad():` 里，用原地操作 `self.name.copy_(新值)`，这样它不会连进计算图。

**autograd**（自动求导）：对 `requires_grad=True` 的张量做运算，PyTorch 会记下计算图。对一个标量调用 `loss.backward()` 之后，每个这样的张量的 `.grad` 里就是 `d loss / d 它`。你可以手推公式来核对。比如 `loss = sum(x³)`，每个元素的导数是 `3x²`。如果 loss 里有 `mean`，别忘了 mean 就是除以元素个数 N，所以导数也要除以 N。

训练循环每一步做四件事：
1. 前向：算出 loss
2. `opt.zero_grad()`：清掉上一步的梯度。`.grad` 默认是**累加**的，不清零就会越加越大
3. `loss.backward()`：算梯度
4. `opt.step()`：用梯度更新参数

`zero_grad` 只要放在 `backward` 之前就行。记录 loss 要用 `loss.item()`，它返回一个 Python 数字；直接把 `loss` 张量存进列表，会把整张计算图一起留在内存里。
--- code
class Tiny(nn.Module):
    def __init__(self):
        super().__init__()
        self.w = nn.Parameter(torch.ones(2))
        self.register_buffer("count", torch.zeros(()))
        self.plain = torch.zeros(2)                    # 普通属性
m = Tiny()
print("parameters:", [n for n, _ in m.named_parameters()])
print("state_dict:", list(m.state_dict().keys()), " <- 没有 plain")

x = torch.tensor([1.0, 2.0, 3.0], requires_grad=True)
loss = (x ** 3).sum()
loss.backward()
print("autograd :", x.grad.tolist())

    """qkv: (B, T, 3*C)  ->  q, k, v，每个都是 (B, n_head, T, head_dim)

def split_heads(qkv, n_head):
    B, T, C3 = qkv.shape
    C = C3 // 3
    hs = C // n_head
    q, k, v = qkv.split(C, dim=-1)
    out = [t.view(B, T, n_head, hs).transpose(1, 2) for t in (q, k, v)]
    return out[0], out[1], out[2]

    mu = x.mean(-1, keepdim=True)

class Scaler(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(dim))
        self.register_buffer("running_max", torch.zeros(dim))

    def forward(self, x):
        with torch.no_grad():
            self.running_max.copy_(torch.maximum(self.running_max, x.detach().max(0).values))
        return x * self.weight

def collate(samples, pad_id=0):
    B = len(samples)
    Tmax = max(s.numel() for s in samples)
    x = torch.full((B, Tmax), pad_id, dtype=torch.long)

x 是 2 行 3 列：`[[0, 1, 2], [3, 4, 5]]`。

`sum(dim=0)` 让第 0 维（行）消失，也就是把两行加起来，每列剩一个数：`[0+3, 1+4, 2+5] = [3, 5, 7]`。`sum(dim=1)` 让第 1 维（列）消失，每行剩一个数：`[0+1+2, 3+4+5] = [3, 12]`。记法：`dim=k` 就是「第 k 维消失」。

`keepdim=True` 把这一维留下，长度变成 1，所以是 `(2, 1)`。这样它还能和 `(2, 3)` 广播：每一行减去自己那一行的均值（第一行 1.0，第二行 4.0），两行都变成 `[-1, 0, 1]`。
--- hints
- `dim=k` 的意思是「沿第 k 维求和，第 k 维消失」。x 是 2 行 3 列
- `dim=0` 把两行加起来，剩 3 个数；`dim=1` 把每行的 3 个数加起来，剩 2 个数

--- options
- `y.transpose(1, 2).view(B, T, nh * hs)`
- `y.transpose(1, 2).contiguous().view(B, T, nh * hs)`
- `y.transpose(1, 2).reshape(B, T, nh * hs)`
- `y.view(B, T, nh * hs)`
answer: 2,3
--- explain

--- solution
def split_heads(qkv, n_head):
    B, T, C3 = qkv.shape
    C = C3 // 3
    hs = C // n_head
    q, k, v = qkv.split(C, dim=-1)
    out = [t.view(B, T, n_head, hs).transpose(1, 2) for t in (q, k, v)]
    return out[0], out[1], out[2]

- `logits`：`(N, V)`；`target`：`(N,)`，int64
- 返回标量：每个样本 `-log p(正确类别)` 的平均
- 不许用 `F.cross_entropy` 和 `F.nll_loss`；要数值稳定（logits 差距很大时也不能出现 inf）
--- starter
def my_cross_entropy(logits, target):
    raise todo()
--- solution
def my_cross_entropy(logits, target):
    logp = logits - logits.logsumexp(dim=-1, keepdim=True)
    picked = logp.gather(-1, target.unsqueeze(-1)).squeeze(-1)
    return -picked.mean()
--- tests

    flat = torch.zeros(4, 10)
