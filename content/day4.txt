@@ concept
title: GPT 全景：形状一路走下来
ref: day4
--- body
今天要从零写出一个 GPT。先看全貌，后面的卡片再一块一块拆开。

GPT 只做一件事：读一串 token，在**每个位置**猜「下一个 token 是什么」。

今天所有的形状都用这几个字母：
- B：batch 大小（一次喂几句话）
- T：序列长度（每句几个 token）
- C：每个 token 的向量长度（代码里叫 `n_embd`）
- V：词表大小（`vocab_size`）
- nh：头数（`n_head`）；hs：每个头的维度，hs = C / nh

数据一路走下来：
1. `idx` (B, T)：整数 token id
2. `wte(idx) + wpe(pos)` → `x` (B, T, C)：token 嵌入加位置嵌入
3. 经过 L 个 Block，每个 Block 进去 (B, T, C)，出来还是 (B, T, C)
4. `ln_f` 再 `lm_head` → `logits` (B, T, V)：每个位置给词表里每个词打的原始分数（还没过 softmax）
5. 和 targets 算 `cross_entropy` → 一个数：loss

最重要的一点：**Block 不改变形状**。所以同一种 Block 想叠几层就叠几层。GPT-2 small 叠了 12 层，GPT-3 叠了 96 层。

今天的顺序：因果 mask → attention → 多头 → Block → GPT → 参数量 → 生成。下面的代码用的是今天最后要写出来的那个 GPT，先当黑盒用，只看每一步的形状。
--- code
torch.manual_seed(0)
m = GPT(vocab_size=10, block_size=8, n_layer=2, n_head=4, n_embd=16)
idx = torch.randint(0, 10, (2, 5))          # B=2 句话，每句 T=5 个 token
print("idx        ", tuple(idx.shape), "第 0 句:", idx[0].tolist())

x = m.wte(idx) + m.wpe(torch.arange(5))     # token 嵌入 + 位置嵌入
print("嵌入后      ", tuple(x.shape))
for i, block in enumerate(m.h):
    x = block(x)
    print(f"Block {i} 之后", tuple(x.shape))  # 形状不变

logits = m.lm_head(m.ln_f(x))
print("logits     ", tuple(logits.shape))   # 每个位置 10 个分数
print("第 0 句每个位置猜的下一个 token:", logits[0].argmax(-1).tolist())

@@ concept
title: 因果 mask：只能看过去
--- body
语言模型训练时，一句话一次全部喂进去，**每个位置**都去猜下一个 token。位置 2 要猜第 3 个 token。如果位置 2 能「看到」第 3 个 token，直接抄答案就行，什么也学不到。

所以 attention 里有一条规矩：**位置 i 只能看位置 0…i（过去和自己），不能看 i 之后（未来）**。这就是因果 mask（causal mask）。

attention 会算一个 (T, T) 的分数矩阵：
- 第 i 行 = 第 i 个位置，它在「看」别人（叫 query）
- 第 j 列 = 第 j 个位置，它被看（叫 key）
- 允许 j ≤ i：对角线和它左下方的格子，也就是下三角 → `torch.tril`

两种写法，效果一样：
- **加性 mask**：允许的格子是 0，禁止的格子是 `-inf`，直接加到分数上
- **masked_fill**：`scores.masked_fill(mask == 0, float("-inf"))`，mask 里 1 = 允许，0 = 禁止

为什么用 `-inf`？softmax 要算 e 的分数次方，而 e^(-inf) = 0。所以被屏蔽的格子权重**正好是 0**，剩下的格子权重加起来仍然是 1。

T 个位置一共屏蔽 T·(T−1)/2 个格子：T=4 时是 6 个。

mask 常做成 (1, 1, T, T) 的形状。attention 分数是 (B, nh, T, T)，前面两个 1 靠广播对上 batch 和头，一个 mask 就能用在所有句子、所有头上。
--- code
T = 4
allowed = torch.tril(torch.ones(T, T))      # 1 = 可以看，0 = 不许看
print(allowed)

bias = torch.zeros(T, T).masked_fill(allowed == 0, float("-inf"))
print(bias)
print("屏蔽的格子数:", int(torch.isinf(bias).sum()), "  T*(T-1)/2 =", T * (T - 1) // 2)

torch.manual_seed(0)
scores = torch.randn(T, T)                  # 随便一些分数
att = (scores + bias).softmax(dim=-1)
print(att.round(decimals=2))                # 右上角全是 0
print("每行加起来:", att.sum(dim=-1))

# (1, 1, T, T) 能广播到 (B, nh, T, T)
print((torch.randn(2, 3, T, T) + bias.view(1, 1, T, T)).shape)

@@ concept
title: 缩放点积注意力，一步一步
--- body
attention 让每个位置从别的位置「取信息」。每个位置有三个向量：
- **q**（query）：我在找什么
- **k**（key）：我这里有什么
- **v**（value）：如果你选中我，我交给你的内容

q、k、v 的形状都是 (B, nh, T, hs)。下面用 B=1、nh=1、T=4、hs=8 走一遍：

1. **打分**：`scores = q @ k.transpose(-2, -1)`。(1,1,4,8) @ (1,1,8,4) → (1,1,4,4)。`scores[i, j]` 是 q_i 和 k_j 的点积：位置 i 对位置 j 有多感兴趣。
2. **缩放**：除以 `math.sqrt(hs)`，这里是 √8 ≈ 2.83。原因见下面。
3. **mask**：未来的格子填成 `-inf`（上一张卡片）。
4. **softmax(dim=-1)**：沿最后一维，也就是每一**行**，把分数变成权重：都 ≥ 0，每行加起来是 1。写成 `dim=-2` 就变成按列归一化，是错的。
5. **加权求和**：`att @ v`。(1,1,4,4) @ (1,1,4,8) → (1,1,4,8)。位置 i 的输出 = 所有 v 按第 i 行的权重加起来。

合成一行：`softmax(q @ kᵀ / √hs + mask) @ v`。

PyTorch 自带同样的计算：`F.scaled_dot_product_attention(q, k, v, is_causal=True)`，简称 SDPA，在 GPU 上还会自动用更快的实现。自己写完拿它对答案，这叫「对拍」：两边数字的差应该非常小（1e-6 或更小，只是浮点误差）。

### 为什么除以 √hs
q 和 k 的每个数大致是均值 0、标准差 1。点积是 hs 个乘积相加，标准差会变成大约 √hs：hs=64 时约为 8。softmax 碰到相差十几、二十的分数，几乎把全部权重给最大的那一个（接近 one-hot），其他位置的梯度几乎是 0，模型很难学。除以 √hs，分数的标准差就回到 1 左右。代码最后两行打印这两个标准差。
--- code
torch.manual_seed(0)
B, nh, T, hs = 1, 1, 4, 8                   # 1 句话、1 个头、4 个 token、每个头 8 维
q, k, v = (torch.randn(B, nh, T, hs) for _ in range(3))

s = q @ k.transpose(-2, -1)                 # (1,1,4,8) @ (1,1,8,4)
print("1. 分数         ", tuple(s.shape))
s = s / math.sqrt(hs)                       # 2. 除以 √8
s = s.masked_fill(torch.tril(torch.ones(T, T)) == 0, float("-inf"))
print("3. 缩放 + mask 后:\n", s[0, 0].round(decimals=2))
att = s.softmax(dim=-1)
print("4. softmax 后，每行和为 1:\n", att[0, 0].round(decimals=2))
out = att @ v                               # (1,1,4,4) @ (1,1,4,8)
print("5. 输出         ", tuple(out.shape))

sdpa = F.scaled_dot_product_attention(q, k, v, is_causal=True)
print("和 SDPA 的最大差:", (out - sdpa).abs().max().item())

a, b = torch.randn(1000, 64), torch.randn(1000, 64)    # 1000 对 hs=64 的 q、k
dots = (a * b).sum(-1)
print("hs=64 点积的标准差：不缩放", round(dots.std().item(), 2), "  除以 √64 后", round((dots / 8).std().item(), 2))

@@ concept
title: 因果性检验：改未来，过去不许变
--- body
和 SDPA 对拍能证明「数字对」。但还有一种 bug 更危险：**信息泄漏**。mask 漏了或写反了，模型训练时偷看答案，loss 降得特别漂亮，一到生成就胡言乱语。而且它不会报任何错。

检验方法很简单，任何 causal 模型都能用：
1. 正常算一次输出 `out1`
2. 只改**最后几个位置**的输入（下面改最后 2 个位置的 k 和 v），再算一次 `out2`
3. 前面位置的输出必须**一点都不变**：`out1[:, :, :4]` 和 `out2[:, :, :4]` 相等
4. 被改的位置自己的输出应该**变了**。如果连它们都没变，说明你的检验根本没改到东西

这种测试叫「不变量测试」：不需要知道正确答案是多少，只检查一条必须成立的性质。同样的办法可以用在整个模块、整个模型上：改掉 x 的后半段，前半段的输出不许变。第 17 天会讲更多这类测试。

下面的代码用 SDPA 对比「有因果 mask」和「没有 mask」两种情况。
--- code
torch.manual_seed(0)
q, k, v = (torch.randn(1, 1, 6, 4) for _ in range(3))   # T=6
k2, v2 = k.clone(), v.clone()
k2[:, :, 4:] = torch.randn(1, 1, 2, 4)      # 只改最后 2 个位置
v2[:, :, 4:] = torch.randn(1, 1, 2, 4)

def changes(causal):
    out1 = F.scaled_dot_product_attention(q, k, v, is_causal=causal)
    out2 = F.scaled_dot_product_attention(q, k2, v2, is_causal=causal)
    past = (out1[:, :, :4] - out2[:, :, :4]).abs().max().item()
    future = (out1[:, :, 4:] - out2[:, :, 4:]).abs().max().item()
    return round(past, 4), round(future, 4)

print("有因果 mask：前 4 个位置变了", changes(True)[0], "  后 2 个位置变了", changes(True)[1])
print("没有 mask  ：前 4 个位置变了", changes(False)[0], "  后 2 个位置变了", changes(False)[1])

@@ concept
title: 多头：拆头、合头、register_buffer
--- body
一个头只能学一种「看」的方式。多头注意力把 C 维切成 nh 份，每份 hs = C / nh 维，各自独立做 attention，最后再拼回来。算力和一个大头差不多，但每个头可以关注不同的东西（有的头看前一个词，有的头看句首）。

整套形状，用 B=2、T=5、C=12、nh=3（所以 hs=4）：
1. `self.qkv(x)`：(2, 5, 12) → (2, 5, 36)。一个 Linear 一次投影出 q、k、v，比三个 Linear 快
2. `.split(C, dim=-1)` → q、k、v 各 (2, 5, 12)
3. `.view(B, T, nh, hs)` → (2, 5, 3, 4)：把 12 维切成 3 个头 × 4 维
4. `.transpose(1, 2)` → (2, 3, 5, 4)：把「头」换到第 1 维。现在每个头是一个独立的 (T, hs) 矩阵，attention 的矩阵乘法对 (B, nh) 批量做
5. attention → (2, 3, 5, 4)
6. `.transpose(1, 2)` → (2, 5, 3, 4)，再 `.contiguous().view(B, T, C)` → (2, 5, 12)：合并头
7. `self.proj(y)` → (2, 5, 12)：把各个头的结果混合一下

为什么要 `.contiguous()`？`transpose` 不搬数据，只改「按什么顺序读内存」。`view` 要求数据在内存里按顺序排好，transpose 之后不是，直接 `view` 会报错。`.contiguous()` 按新顺序复制一份。（`.reshape` 也行，它在需要时自动复制。）

### mask 存成 buffer
mask 每次 forward 都一样，没必要现造。在 `__init__` 里：
```
self.register_buffer("bias", torch.tril(torch.ones(block_size, block_size)).view(1, 1, block_size, block_size))
```
- buffer 是模块的一部分：`model.to("cuda")` 时跟着搬，`state_dict()` 里也有它
- 但它**不是参数**：`parameters()` 里没有它，优化器不会改它
- 输入可以比 block_size 短，用的时候切一块：`self.bias[:, :, :T, :T]`

名字叫 "bias" 是 nanoGPT 的叫法，其实它是 mask。
--- code
torch.manual_seed(0)
B, T, C, nh = 2, 5, 12, 3
hs = C // nh                                # 每个头 4 维
x = torch.randn(B, T, C)
qkv = nn.Linear(C, 3 * C, bias=False)

big = qkv(x)
print("qkv(x)          ", tuple(big.shape))
q, k, v = big.split(C, dim=-1)
print("split 之后 q     ", tuple(q.shape))
q = q.view(B, T, nh, hs)
print("view 拆头        ", tuple(q.shape))
q = q.transpose(1, 2)
print("transpose(1, 2) ", tuple(q.shape))

y = torch.randn(B, nh, T, hs)               # 假装这是 attention 的输出
y = y.transpose(1, 2)
print("转回来           ", tuple(y.shape), " 连续吗?", y.is_contiguous())
try:
    y.view(B, T, C)
except RuntimeError as e:
    print("直接 view 报错:  ", str(e)[:60], "...")
y = y.contiguous().view(B, T, C)
print("合并头           ", tuple(y.shape))

class WithMask(nn.Module):
    def __init__(self, block_size):
        super().__init__()
        self.register_buffer("bias", torch.tril(torch.ones(block_size, block_size)).view(1, 1, block_size, block_size))

m = WithMask(8)
print("state_dict 里有:", list(m.state_dict().keys()), "  参数个数:", sum(p.numel() for p in m.parameters()))
print("T=5 时切出来的 mask:", tuple(m.bias[:, :, :5, :5].shape))

@@ concept
title: Block：MLP + pre-LN 残差
ref: day4
--- body
一个 Block = 两个子层。两个子层用同一个套路：`x = x + 子层(LayerNorm(x))`。
```
x = x + self.attn(self.ln1(x))    # token 之间交换信息
x = x + self.mlp(self.ln2(x))     # 每个 token 自己加工
```

**MLP**：`Linear(C, 4C)` → GELU → `Linear(4C, C)`，两层都带 bias。先把维度放大 4 倍，过一个非线性函数（GELU，可以看成平滑版的 ReLU），再压回 C。它对每个位置单独做，位置之间不交流。

**残差（residual）**：`x = x + 子层(...)`。子层只需要学「在 x 上改一点什么」。可以想象一条从输入直通输出的主干道（叫 residual stream），每个子层往上面加一点东西。梯度也能沿着这条路直接传回前面的层，所以几十层也训得动。

**pre-LN**：LayerNorm 放在分支**里面**（先归一化，再进子层），主干上的 x 本身不做 LN。2017 年的原始 Transformer 是 post-LN：`x = LN(x + 子层(x))`，层一多就不稳定，要很小心地 warmup。GPT-2 开始改成了 pre-LN。因为主干上从来没做过 LN，模型出口要补一个 `ln_f`（下一张卡片）。

**一个好用的检验**：如果两个子层都输出 0，pre-LN Block 应该原样返回 x（恒等映射）。post-LN 做不到，因为 LN(x) ≠ x。练习题就用这个测试。

### 一个 Block 有多少参数
- ln1、ln2：各 2C（LayerNorm 有 weight 和 bias 各 C 个）
- qkv：3C²；proj：C²（nanoGPT 这里都不带 bias）
- fc1：4C² + 4C；fc2：4C² + C
- 合计 **12C² + 9C**。attention 占 4C²，MLP 占 8C²：大头在 MLP

下面的代码逐个打印一个 Block（C=16）的参数，再做恒等检验：同样的零件，pre-LN 接法和 post-LN 接法对比。
--- code
torch.manual_seed(0)
C = 16
blk = Block(n_embd=C, n_head=4, block_size=8)      # 今天要写的 Block（参考实现）
for name, p in blk.named_parameters():
    print(f"{name:18s} {str(tuple(p.shape)):9s} {p.numel()}")
print("合计", sum(p.numel() for p in blk.parameters()), "  12*C*C + 9*C =", 12 * C * C + 9 * C)

x = torch.randn(2, 5, C)
with torch.no_grad():                        # 让两个子层都输出 0
    blk.attn.proj.weight.zero_()
    for p in blk.mlp.parameters():
        p.zero_()
print("pre-LN : |Block(x) - x| 最大", (blk(x) - x).abs().max().item())
h = blk.ln1(x + blk.attn(x))                 # 同样的零件，post-LN 的接法
post = blk.ln2(h + blk.mlp(h))
print("post-LN: |out - x| 最大     ", round((post - x).abs().max().item(), 3))

@@ concept
title: GPT：嵌入、初始化、weight tying
ref: day4
--- body
把积木拼起来：
```
x = wte(idx) + wpe(pos)        # (B,T,C) + (T,C)，广播
for block in h: x = block(x)
logits = lm_head(ln_f(x))      # (B,T,V)
```
- `wte = nn.Embedding(V, C)`：每个 token id 查出一行向量
- `wpe = nn.Embedding(block_size, C)`：每个位置 0…block_size−1 查出一行向量，`pos = torch.arange(T)`。attention 本身不知道谁先谁后，顺序信息全靠它（第 5 天会换成 RoPE）
- `ln_f`：pre-LN 的主干没做过 LN，出口补一个
- `lm_head = nn.Linear(C, V, bias=False)`：把每个位置的向量变成 V 个分数

### 初始化：开始时 loss 应该约等于 ln V
nanoGPT 把所有 Linear 和 Embedding 的权重初始化成均值 0、标准差 0.02 的正态分布，bias 清零。写法：定义一个 `_init(m)`，然后 `self.apply(self._init)`。`apply` 会对每个子模块各调用一次。

刚初始化的模型什么都不懂，应该对 V 个词一视同仁：每个词的概率约 1/V，交叉熵约等于 ln V（第 3 天讲过这个基线）。标准差 0.02 让 logits 都很小，接近均匀分布。`nn.Embedding` 默认用的是标准差 1，大了 50 倍：logits 一开始就很大，loss 离 ln V 很远，训练前面几百步都在收拾这个烂摊子。

### weight tying（权重共享）
`self.lm_head.weight = self.wte.weight`：输出层和输入嵌入**共用同一个** (V, C) 的参数。道理是「这个词的向量」和「预测这个词时用的向量」本来就该相像。好处是少了 V·C 个参数（GPT-2 里约 3860 万个）。
- 要的是**同一个对象**：`m.lm_head.weight is m.wte.weight` 必须是 True。用 `copy_` 只复制数值不算，训练一步它们就分开了
- `parameters()` 会自动去重，共享的权重只数一次
- nanoGPT 的两种 init 都是 N(0, 0.02)，所以 tying 写在 `apply` 前面还是后面都行

### loss
`F.cross_entropy` 要 (N, V) 的分数和 (N,) 的正确答案，所以先把 batch 和时间两维摊平：`logits.reshape(-1, V)` 是 (B·T, V)，`targets.reshape(-1)` 是 (B·T,)。

整个 GPT 的参数量 = wte + wpe + L 个 Block + ln_f；lm_head 和 wte 共享，不另算。练习 d4-07 把它写成公式。
--- code
torch.manual_seed(0)
V = 65
m = GPT(vocab_size=V, block_size=16, n_layer=2, n_head=4, n_embd=32)
idx = torch.randint(0, V, (4, 16))
targets = torch.randint(0, V, (4, 16))
logits, loss = m(idx, targets)
print("logits", tuple(logits.shape), " 摊平后", tuple(logits.reshape(-1, V).shape))
print("初始 loss =", round(loss.item(), 3), "  ln(V) =", round(math.log(V), 3))

print("lm_head.weight is wte.weight:", m.lm_head.weight is m.wte.weight)
print("wte 的标准差:", round(m.wte.weight.std().item(), 4))
print("参数量:", sum(p.numel() for p in m.parameters()), "  不共享的话还要多", V * 32)

with torch.no_grad():

@@ concept
title: 生成：贪心 + 上下文裁剪
ref: day4
--- body
GPT 每次只猜**一个**下一个 token。要生成一段话，就一步一步来（叫自回归）：
1. 把当前序列喂进模型，得到 logits (B, T, V)
2. 只要**最后一个位置**的 logits：`logits[:, -1]`，形状 (B, V)。前面位置猜的那些 token 早就在序列里了
3. 选一个 token。**贪心**：直接取分数最大的，`argmax(-1, keepdim=True)` → (B, 1)
4. 拼到序列末尾：`torch.cat([idx, nxt], dim=1)`，长度 +1
5. 回到第 1 步

**上下文裁剪**：`wpe` 只有 block_size 行，mask buffer 也只有 block_size×block_size。序列一长过 block_size，查位置嵌入就越界报错。所以每一步只喂最后 block_size 个 token：`idx[:, -block_size:]`。序列还短的时候，这个切片什么也不做。

两个小习惯：
- 生成不需要梯度：函数上加 `@torch.no_grad()`，省显存，也更快
- 先 `model.eval()`：关掉 dropout 这类训练时才有的随机性

贪心的好处是**确定性**：同样的输入永远得到同样的输出，很适合写测试。缺点是容易车轱辘话来回说。temperature、top-k 这些采样方法在第 5 天讲。

下面的代码只走**一步**，并演示不裁剪会怎样。
--- code
torch.manual_seed(0)
m = GPT(vocab_size=11, block_size=8, n_layer=1).eval()
idx = torch.tensor([[3, 1, 4]])              # B=1, T=3

with torch.no_grad():
    logits, _ = m(idx)
print("logits      ", tuple(logits.shape))   # 每个位置都猜了一次
last = logits[:, -1]                         # 只要最后一个位置
print("最后一个位置  ", tuple(last.shape))
nxt = last.argmax(-1, keepdim=True)
print("下一个 token ", nxt.tolist(), tuple(nxt.shape))
idx = torch.cat([idx, nxt], dim=1)
print("拼上之后     ", idx.tolist())

too_long = torch.randint(0, 11, (1, 9))      # 9 个 token > block_size=8
try:
    m(too_long)
except IndexError as e:
    print("直接喂 9 个 token:", type(e).__name__, "-", e)
print("裁剪成最后 8 个:", tuple(too_long[:, -8:].shape))

def causal_bias(T, device=None):

def attention(q, k, v, causal=True):
    T = q.size(-2)
    att = q @ k.transpose(-2, -1) / math.sqrt(q.size(-1))
    if causal:
        att = att + causal_bias(T, q.device)
    att = att.softmax(dim=-1)
    return att @ v

--- solution
class CausalSelfAttention(nn.Module):
    def __init__(self, n_embd, n_head, block_size):
        super().__init__()
        assert n_embd % n_head == 0
        self.n_head = n_head
        self.qkv = nn.Linear(n_embd, 3 * n_embd, bias=False)
        self.proj = nn.Linear(n_embd, n_embd, bias=False)
        self.register_buffer("bias", torch.tril(torch.ones(block_size, block_size)).view(1, 1, block_size, block_size))

    def forward(self, x):
        B, T, C = x.shape
        hs = C // self.n_head
        q, k, v = self.qkv(x).split(C, dim=-1)
        q = q.view(B, T, self.n_head, hs).transpose(1, 2)
        k = k.view(B, T, self.n_head, hs).transpose(1, 2)
        v = v.view(B, T, self.n_head, hs).transpose(1, 2)
        att = q @ k.transpose(-2, -1) / math.sqrt(hs)
        att = att.masked_fill(self.bias[:, :, :T, :T] == 0, float("-inf")).softmax(-1)
        y = (att @ v).transpose(1, 2).contiguous().view(B, T, C)
        return self.proj(y)

        self.wte = nn.Embedding(vocab_size, n_embd)
        self.wpe = nn.Embedding(block_size, n_embd)
        self.h = nn.ModuleList([Block(n_embd, n_head, block_size) for _ in range(n_layer)])
        self.ln_f = nn.LayerNorm(n_embd)
        self.lm_head = nn.Linear(n_embd, vocab_size, bias=False)
        self.apply(self._init)
        self.lm_head.weight = self.wte.weight     # 共享：同一个 Parameter 对象

    @staticmethod
    def _init(m):
        if isinstance(m, (nn.Linear, nn.Embedding)):
            nn.init.normal_(m.weight, 0.0, 0.02)
            if isinstance(m, nn.Linear) and m.bias is not None:
                nn.init.zeros_(m.bias)

    def forward(self, idx, targets=None):
        B, T = idx.shape
        pos = torch.arange(T, device=idx.device)
        x = self.wte(idx) + self.wpe(pos)          # (B,T,C) + (T,C) 广播
        for b in self.h:
            x = b(x)
        logits = self.lm_head(self.ln_f(x))
        loss = None
        if targets is not None:
            loss = F.cross_entropy(logits.reshape(-1, logits.size(-1)), targets.reshape(-1))
        return logits, loss

def generate_greedy(model, idx, max_new_tokens, block_size):
    """每步取 argmax 追加。序列超过 block_size 时只喂最后 block_size 个。

@torch.no_grad()
def generate_greedy(model, idx, max_new_tokens, block_size):
    for _ in range(max_new_tokens):
        cond = idx[:, -block_size:]
        logits, _ = model(cond)
        nxt = logits[:, -1].argmax(-1, keepdim=True)
        idx = torch.cat([idx, nxt], dim=1)
    return idx

--- solution
class CausalSelfAttention(nn.Module):
    def __init__(self, n_embd, n_head, block_size):
        super().__init__()
        assert n_embd % n_head == 0
        self.n_head = n_head
        self.qkv = nn.Linear(n_embd, 3 * n_embd, bias=False)
        self.proj = nn.Linear(n_embd, n_embd, bias=False)
        self.register_buffer("bias", torch.tril(torch.ones(block_size, block_size)).view(1, 1, block_size, block_size))

    def forward(self, x):
        B, T, C = x.shape
        hs = C // self.n_head
        q, k, v = self.qkv(x).split(C, dim=-1)
        q = q.view(B, T, self.n_head, hs).transpose(1, 2)
        k = k.view(B, T, self.n_head, hs).transpose(1, 2)
        v = v.view(B, T, self.n_head, hs).transpose(1, 2)
        att = q @ k.transpose(-2, -1) / math.sqrt(hs)
        att = att.masked_fill(self.bias[:, :, :T, :T] == 0, float("-inf")).softmax(-1)
        y = (att @ v).transpose(1, 2).contiguous().view(B, T, C)
        return self.proj(y)

--- solution
class GPT(nn.Module):
    def __init__(self, vocab_size, block_size, n_layer=2, n_head=4, n_embd=32):
        super().__init__()
        self.block_size = block_size
        self.wte = nn.Embedding(vocab_size, n_embd)
        self.wpe = nn.Embedding(block_size, n_embd)
        self.h = nn.ModuleList([Block(n_embd, n_head, block_size) for _ in range(n_layer)])
        self.ln_f = nn.LayerNorm(n_embd)
        self.lm_head = nn.Linear(n_embd, vocab_size, bias=False)
        self.apply(self._init)
        self.lm_head.weight = self.wte.weight     # 共享：同一个 Parameter 对象

    @staticmethod
    def _init(m):
        if isinstance(m, (nn.Linear, nn.Embedding)):
            nn.init.normal_(m.weight, 0.0, 0.02)
            if isinstance(m, nn.Linear) and m.bias is not None:
                nn.init.zeros_(m.bias)

    def forward(self, idx, targets=None):
        B, T = idx.shape
        pos = torch.arange(T, device=idx.device)
        x = self.wte(idx) + self.wpe(pos)          # (B,T,C) + (T,C) 广播
        for b in self.h:
            x = b(x)
        logits = self.lm_head(self.ln_f(x))
        loss = None
        if targets is not None:
            loss = F.cross_entropy(logits.reshape(-1, logits.size(-1)), targets.reshape(-1))
        return logits, loss
