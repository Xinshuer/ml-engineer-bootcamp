@@ concept
title: 扩散模型：先加噪，再学去噪
--- body
DDPM（去噪扩散概率模型）是 Stable Diffusion 这一类图像生成模型的地基。它只做两件事：

- **前向过程（加噪）**：拿一张真图 `x0`，分 T 步（常用 T = 1000）一点点往里加高斯噪声。到最后一步，图已经变成纯噪声。这一步是固定的公式，不用学。
- **反向过程（去噪）**：训练一个网络，让它看着带噪的图，猜出「加进去的是什么噪声」。生成新图时，从纯噪声出发，一步步减掉网络猜的噪声。

今天一直要用的几个名字：

- `t`：时间步，0 到 T-1 的整数。t 越大，噪声越多。
- `x0` 是原图，`x_t` 是第 t 步的带噪图。
- `noise`（论文里写作 ε，读 epsilon）：标准高斯噪声，均值 0，标准差 1。
- `beta_t`：第 t 步加多少噪声。它是个很小的数，比如从 0.0001 慢慢涨到 0.02。

每一步加噪的公式：

```
x_t = sqrt(1 - beta_t) * x_{t-1} + sqrt(beta_t) * noise
```

先把上一步的图缩小一点点，再加一点点新噪声。为什么要缩小？两个系数的平方加起来正好是 1，这样方差就一直保持在 1 附近，不会越加越大。

下面的代码拿一张「纯色图」（1 万个像素，全是 2.0）加噪 1000 步。看均值怎么从 2 掉到 0，标准差怎么从 0 涨到 1。
--- code
torch.manual_seed(0)
T = 1000
betas = torch.linspace(1e-4, 0.02, T)      # 每一步的 beta：从 0.0001 涨到 0.02
x = torch.full((10000,), 2.0)              # 1 万个像素，全是 2.0
for t in range(T):
    x = (1 - betas[t]).sqrt() * x + betas[t].sqrt() * torch.randn_like(x)
    if t in (0, 99, 299, 599, 999):
        print(f"t={t:4d}   均值 {x.mean():.3f}   标准差 {x.std():.3f}")

@@ concept
title: beta 调度：linear 和 cosine
ref: day8
--- body
「调度」（schedule）就是提前算好的三张表，长度都是 T：

- `betas`：每一步加多少噪声。
- `alphas = 1 - betas`：每一步保留多少信号。
- `alphas_cumprod`：alphas 的累积乘积，论文里叫 alpha_bar（ᾱ）。第 t 个 = alphas[0] × alphas[1] × … × alphas[t]。意思是：从原图走到第 t 步，一共还剩多少信号。

小例子：alphas = [0.9, 0.8, 0.7]，累积乘积 = [0.9, 0.9×0.8, 0.9×0.8×0.7] = [0.9, 0.72, 0.504]。PyTorch 里一行就够：`alphas.cumprod(0)`（0 表示沿第 0 维乘）。

### linear 调度（DDPM 原论文）
betas 从 0.0001 到 0.02 均匀取 T 个点：`torch.linspace(1e-4, 0.02, T)`。

### cosine 调度（Improved DDPM）
linear 有个毛病：信号掉得太早。T = 1000 时，走到第 500 步 alpha_bar 只剩 0.08 左右。后面几百步基本是在「从纯噪声猜纯噪声」，训练步浪费了。低分辨率（32×32、64×64）的图上尤其明显。

cosine 调度反过来：先直接规定 alpha_bar 的曲线，再倒推出 betas。

1. `f(t) = cos((t/T + s) / (1 + s) · π/2)²`，t = 0, 1, …, T（共 T+1 个点），s = 0.008 是一个小偏移
2. `alpha_bar[i] = f(i+1) / f(0)`，i = 0 … T-1
3. `beta[i] = 1 - alpha_bar[i] / alpha_bar[i-1]`，i = 0 时把「前一个」当成 1
4. 最后几步的 beta 会接近 1，所以 clip 到 [0, 0.999]

下面的代码对比两种调度的 alpha_bar。`linear_schedule` 和 `cosine_schedule` 是藏在后台的参考实现，第 1、2 题你会自己写。
--- code
alphas = torch.tensor([0.9, 0.8, 0.7])
print("累积乘积:", alphas.cumprod(0))

lin = linear_schedule(1000)["alphas_cumprod"]
cos = cosine_schedule(1000)["alphas_cumprod"]
for t in (0, 250, 500, 750, 999):
    print(f"t={t:4d}   linear {lin[t]:.4f}   cosine {cos[t]:.4f}")

@@ concept
title: extract：每个样本取自己的系数
--- body
一个 batch 里，每张图抽到的 t 不一样。所以系数要「按样本取」：

- 系数表 `arr` 的形状是 `(T,)`，时间步 `t` 的形状是 `(B,)`。
- `arr.gather(0, t)`（或者 `arr[t]`）取出每个样本的系数，形状是 `(B,)`。

问题来了：图 x 是 `(B, C, H, W)`，直接拿 `(B,)` 去乘会出错。广播（broadcasting，形状不同的张量自动对齐）是**从最右边的维度**开始对齐的。`(B,)` 对上的是 W，不是 B。

- W ≠ B 时：直接报错，还算好发现。
- W == B 时：不报错，悄悄算错。这种最危险。

正确做法：reshape 成 `(B, 1, 1, 1)`，每个样本的系数就乘到它自己的所有像素上。1 的个数 = x 的维数 − 1。通用写法：

```
out.reshape(B, *([1] * (len(x_shape) - 1)))
```

`[1] * 3` 是 `[1, 1, 1]`；前面的 `*` 把 list 展开成几个参数，等于 `out.reshape(B, 1, 1, 1)`。

还有一点：系数表一般建在 CPU 上，训练时 t 却在 GPU 上。先 `arr.to(t.device)` 再取，不然会报 device 不一致。
--- code
arr = torch.tensor([10., 20., 30., 40.])      # T = 4 的系数表
t = torch.tensor([3, 0])                      # batch 里两张图，t 分别是 3 和 0
c = arr.gather(0, t)
print("取出来:", c, tuple(c.shape))

x = torch.ones(2, 3, 4, 4)
try:
    x * c
except RuntimeError as e:
    print("(2,3,4,4) 直接乘 (2,) 报错:", str(e)[:60])

x2 = torch.ones(2, 3, 2, 2)                   # W 恰好也是 2
wrong = x2 * c                                # 不报错！但 c 对上的是 W
print("悄悄算错，第 0 张图:\n", wrong[0, 0])
right = x2 * c.reshape(2, 1, 1, 1)
print("reshape 成 (2,1,1,1)，第 0 张图:\n", right[0, 0])

@@ concept
title: q_sample：一步跳到第 t 步，和 SNR
--- body
训练时每个样本要随机抽一个 t。如果从 x0 开始一步步加噪到 t，平均要循环 500 次，太慢了。

好消息：高斯噪声加高斯噪声，还是高斯噪声。所以 t 步可以合成一步：

```
x_t = sqrt(alpha_bar_t) * x0 + sqrt(1 - alpha_bar_t) * noise
```

- 信号的系数是 `sqrt(alpha_bar_t)`，噪声的系数是 `sqrt(1 - alpha_bar_t)`。两个平方加起来是 1。
- t = 0：alpha_bar ≈ 0.9999，x_t 几乎就是原图。
- t = 999（linear 调度）：alpha_bar ≈ 0.00004，x_t 几乎就是纯噪声。

为什么成立？看前两步。设 alphas 是 a0、a1，e0、e1 是两次采的噪声：

```
x_1 = sqrt(a1) * (sqrt(a0) * x0 + sqrt(1-a0) * e0) + sqrt(1-a1) * e1
    = sqrt(a0*a1) * x0 + [ sqrt(a1*(1-a0)) * e0 + sqrt(1-a1) * e1 ]
```

方括号里是两个独立的高斯噪声相加。独立噪声相加，方差直接相加：a1(1-a0) + (1-a1) = 1 - a0·a1。所以方括号等于 `sqrt(1 - a0*a1) * e`（e 是一个新的标准高斯噪声）。而 a0·a1 正好就是 alpha_bar_1。步数更多时同理。

### 信噪比 SNR
`SNR(t) = alpha_bar_t / (1 - alpha_bar_t)`，也就是「信号的能量 ÷ 噪声的能量」。t 越大，SNR 越小。它只描述「这一步有多吵」，和你用哪种调度无关，所以论文里常用它来比较调度、给 loss 加权。

下面的代码用两步加噪验证闭式公式：均值和标准差都对得上。
--- code
torch.manual_seed(0)
betas = torch.tensor([0.1, 0.2])
ab = (1 - betas).cumprod(0)                   # alpha_bar = [0.9, 0.72]
x0 = torch.full((100000,), 1.0)

x = x0                                        # 逐步加噪两次
for b in betas:
    x = (1 - b).sqrt() * x + b.sqrt() * torch.randn_like(x)
xj = ab[1].sqrt() * x0 + (1 - ab[1]).sqrt() * torch.randn_like(x0)   # 一步跳到 t=1

print(f"逐步两次   均值 {x.mean():.3f}   标准差 {x.std():.3f}")
print(f"一步跳     均值 {xj.mean():.3f}   标准差 {xj.std():.3f}")
print(f"公式       均值 {ab[1].sqrt():.3f}   标准差 {(1 - ab[1]).sqrt():.3f}")
print("SNR:", ab / (1 - ab))

title: 时间步嵌入：把整数 t 变成向量
--- body
UNet 要知道输入里有多少噪声，才知道该去掉多少。所以除了带噪的图，还要把 t 告诉它。

直接喂一个整数（比如 537）效果很差：数太大，相邻的 t 又几乎一样。常用的做法和 Transformer 的位置编码一样：用一串**不同频率**的 cos 和 sin 来表示 t。

```
half  = dim // 2
freqs = exp(-ln(max_period) * [0, 1, ..., half-1] / half)   # 从 1 降到约 1/max_period
args  = t[:, None] * freqs[None]                              # (B, 1) * (1, half) -> (B, half)
emb   = cat([cos(args), sin(args)], dim=-1)                   # (B, dim)
```

- 第 0 个频率是 1：t 每变 1，cos(t) 就变很多（高频）。它负责分清相邻的 t。
- 越往后频率越低：最后几维随 t 变得很慢（低频）。它们负责粗略的位置。
- t = 0 时：cos 部分全是 1，sin 部分全是 0。
- 顺序是**先 cos 后 sin**。不同代码库的顺序不一样，加载别人的预训练权重时必须对上。
- `torch.arange` 默认建在 CPU 上。t 在 GPU 上时，两者一乘就报「Expected all tensors to be on the same device」。所以要写 `device=t.device`。这种 bug 在 CPU 上永远测不出来。

看看 half = 4 时的频率，以及 t = 0、1、100 时的 args：
--- code
half, max_period = 4, 10000
freqs = torch.exp(-math.log(max_period) * torch.arange(half, dtype=torch.float) / half)
print("freqs:", freqs)                        # 1, 0.1, 0.01, 0.001

t = torch.tensor([0, 1, 100])
args = t.float()[:, None] * freqs[None]
print("args 的形状:", tuple(args.shape))
print(args)
print("t=0 那一行的 cos:", args.cos()[0])     # 全是 1

title: FiLM 和 ResBlock：把 t 注入卷积特征
--- body
现在 t 变成了向量 `emb`，形状 `(B, t_dim)`。卷积特征 `h` 的形状是 `(B, ch, H, W)`。怎么让 emb 影响 h？

### FiLM：按通道缩放和平移
1. `emb` 先过 SiLU（一个平滑的激活函数，x · sigmoid(x)），再过 `nn.Linear(t_dim, 2*ch)`，得到 `(B, 2*ch)`。
2. 加两个维度变成 `(B, 2*ch, 1, 1)`，沿通道维切成两半：`scale` 和 `shift`，各是 `(B, ch, 1, 1)`。
3. 输出 `h * (1 + scale) + shift`。`(B, ch, 1, 1)` 会广播到每个像素上。

为什么是 `1 + scale` 而不是 `scale`？Linear 的输出接近 0 时（比如权重被清零），`1 + scale` 让这一层接近「什么都不做」（恒等映射），特征原样通过。只写 `scale` 的话，特征会被乘成 0，信息全丢了。

### ResBlock：残差块
扩散 UNet 的积木。结构：

```
h = Conv3x3( SiLU( GroupNorm(x) ) )     # 通道 in_ch -> out_ch
h = FiLM(h, emb)                        # 注入时间
h = Conv3x3( SiLU( GroupNorm(h) ) )     # 通道 out_ch -> out_ch
return h + skip(x)                      # 残差：加回输入
```

- `nn.Conv2d(in_ch, out_ch, 3, 1, 1)`：3×3 卷积，stride 1，padding 1。H 和 W 不变。
- `nn.GroupNorm(8, ch)`：把通道分成 8 组，每个样本自己做归一化，不依赖 batch 大小（batch 很小时比 BatchNorm 稳）。ch 必须能被 8 整除。
- `skip`：输入 x 要能和 h 相加。通道数不同时（in_ch ≠ out_ch），用 1×1 卷积 `nn.Conv2d(in_ch, out_ch, 1)` 换通道数；相同时用 `nn.Identity()`（原样返回）。
--- code
emb = torch.randn(2, 16)                      # B=2, t_dim=16
proj = nn.Linear(16, 2 * 8)                   # ch = 8
p = proj(F.silu(emb))
print("Linear 之后:", tuple(p.shape))
p4 = p[:, :, None, None]
print("加两个维度:", tuple(p4.shape))
scale, shift = p4.chunk(2, dim=1)
print("scale / shift:", tuple(scale.shape), tuple(shift.shape))

h = torch.randn(2, 8, 4, 4)
zero = torch.zeros(2, 8, 1, 1)
print("scale=shift=0 时，h*(1+scale)+shift 等于 h 吗:", torch.equal(h * (1 + zero) + zero, h))
print("scale=shift=0 时，h*scale+shift 的绝对值之和:", (h * zero + zero).abs().sum().item())

print("3x3 卷积 8->16:", tuple(nn.Conv2d(8, 16, 3, 1, 1)(h).shape))
print("1x1 卷积 8->16:", tuple(nn.Conv2d(8, 16, 1)(h).shape))
print("GroupNorm(8, 8):", tuple(nn.GroupNorm(8, 8)(h).shape))

title: UNet：下采样、上采样、skip 拼接
--- body
扩散模型的网络要输入一张带噪图，输出一张**同样形状**的「噪声预测」。UNet 正好适合：

- **编码器（往下走）**：分辨率一层层减半（32 → 16 → 8），通道数变多。每个像素「看到」的范围越来越大。
- **中间层**：在最小的分辨率上再处理一次。
- **解码器（往上走）**：分辨率一层层翻倍（8 → 16 → 32），回到原来的大小。
- **skip 连接**：编码器每一层的输出都存下来，送到解码器同样分辨率的地方，沿通道维拼在一起。下采样丢掉的细节就从这里补回来。画出来像个 U，所以叫 UNet。

三个操作的形状：

- 下采样 `nn.Conv2d(ch, ch, 4, 2, 1)`：kernel 4、stride 2、padding 1。输出边长 = (H + 2×1 − 4) // 2 + 1，H 是偶数时正好是 H / 2。
- 上采样 `nn.Upsample(scale_factor=2, mode="nearest")`：每个像素复制成 2×2，边长翻倍。它没有参数。
- 拼接 `torch.cat([up, skip], dim=1)`：dim=1 是通道维，通道数相加（比如 64 + 64 = 128）。所以拼接之后的那个 ResBlock，输入通道要写两者之和。

奇数尺寸的坑：7 下采样变 3（向下取整），再上采样变 6，和 skip 的 7 对不上，cat 直接报错。解决办法：先给上采样的结果补 0。`F.pad(x, (左, 右, 上, 下))` 的顺序是**从最后一维开始写**：先 W 的左右，再 H 的上下。
--- code
x = torch.randn(1, 32, 32, 32)
down = nn.Conv2d(32, 32, 4, 2, 1)
up = nn.Upsample(scale_factor=2, mode="nearest")
d = down(x)
print("下采样:", tuple(d.shape))
u = up(d)
print("上采样:", tuple(u.shape))
print("和 skip 拼接:", tuple(torch.cat([u, x], dim=1).shape))

odd = torch.randn(1, 8, 7, 7)
u2 = up(nn.Conv2d(8, 8, 4, 2, 1)(odd))
print("7x7 下采样再上采样:", tuple(u2.shape))
print("右边、下边各补 1:", tuple(F.pad(u2, (0, 1, 0, 1)).shape))

@@ concept
title: 训练目标和反向一步
--- body
### 训练：让网络预测噪声
一步训练只有四行：

1. 每个样本随机抽一个 t：`torch.randint(0, T, (B,))`
2. 采噪声：`noise = torch.randn_like(x0)`
3. 加噪：`x_t = q_sample(x0, t, noise, sched)`
4. loss = `F.mse_loss(model(x_t, t), noise)`

目标是**噪声**，不是 x0。噪声永远是标准高斯，不管 t 是多少，目标的大小都一样，网络好学。

一条很有用的「基准线」：一个永远输出 0 的模型，loss = 噪声平方的均值 ≈ 1。训练时 loss 如果一直停在 1 附近，说明模型什么都没学到。

### 采样：反向一步
从 x_t 走到 x_{t-1}：

```
mean    = (x_t - beta_t / sqrt(1 - alpha_bar_t) * eps_pred) / sqrt(alpha_t)
x_{t-1} = mean + sqrt(beta_t) * z     # t > 0，z 是新采的标准高斯噪声
x_0     = mean                        # t = 0，最后一步不加噪声
```

- `eps_pred` 是网络预测的噪声。`mean` 就是「减掉一部分预测的噪声，再放大回来」。
- 最后一步输出的就是成品图，不能再往上撒随机噪声。
- batch 里每个样本的 t 可以不一样，所以「加不加噪声」要按样本决定：`(t > 0).float()` 变成 0/1，再 reshape 成 `(B, 1, 1, 1)` 乘上去。

生成一张图：从纯噪声开始，t 从 T-1 走到 0，每一步调用一次网络。T = 1000 就是 1000 次网络调用，所以 DDPM 采样很慢。第 9 天的 DDIM 用少得多的步数。
--- code
torch.manual_seed(0)
x0 = torch.randn(64, 1, 8, 8) * 10           # 一批「图」，数值故意放大 10 倍
noise = torch.randn_like(x0)
zero_pred = torch.zeros_like(noise)           # 一个永远输出 0 的「模型」
print(f"目标是噪声:   loss = {F.mse_loss(zero_pred, noise).item():.3f}")
print(f"目标写成 x0:  loss = {F.mse_loss(zero_pred, x0).item():.1f}")

print("随机抽的 t:", torch.randint(0, 1000, (4,)))
t = torch.tensor([0, 5, 0, 9])
keep = (t > 0).float().reshape(-1, 1, 1, 1)
print("加噪开关:", keep.flatten(), "形状", tuple(keep.shape))

def linear_schedule(T, beta_start=1e-4, beta_end=0.02):

--- prompt
写 `cosine_schedule(T, s=0.008)`，返回和第 1 题结构一样的 dict（三个 `(T,)` 的张量）。步骤：

1. `t = 0, 1, …, T`，共 T+1 个浮点数
2. `f = cos((t/T + s) / (1 + s) · π/2) ** 2`
3. `alphas_cumprod[i] = f[i+1] / f[0]`，i = 0 … T-1（去掉第 0 个，形状变成 `(T,)`）
4. `betas[i] = 1 - alphas_cumprod[i] / alphas_cumprod[i-1]`；i = 0 时，「前一个」当成 1。然后把 betas clip 到 [0, 0.999]

def cosine_schedule(T, s=0.008):
    t = torch.arange(T + 1, dtype=torch.float)
    f = torch.cos((t / T + s) / (1 + s) * math.pi / 2) ** 2
    ab = (f / f[0])[1:]
    prev = torch.cat([torch.ones(1), ab[:-1]])
    betas = (1 - ab / prev).clamp(0, 0.999)
    return {"betas": betas, "alphas": 1 - betas, "alphas_cumprod": ab}

def extract(arr, t, x_shape):

    return out.reshape(t.shape[0], *([1] * (len(x_shape) - 1)))

def timestep_embedding(t, dim, max_period=10000):
    half = dim // 2
    # device 必须跟着 t 走，否则模型搬到 GPU 之后这里会报 "two devices"，
    # 这类 bug 在 CPU 上永远测不出来
    freqs = torch.exp(-math.log(max_period)
                      * torch.arange(half, dtype=torch.float, device=t.device) / half)
    args = t.float()[:, None] * freqs[None]
    return torch.cat([args.cos(), args.sin()], dim=-1)

class ResBlock(nn.Module):
    def __init__(self, in_ch, out_ch, t_dim):
        super().__init__()
        self.n1 = nn.GroupNorm(8, in_ch)
        self.c1 = nn.Conv2d(in_ch, out_ch, 3, 1, 1)
        self.film = FiLM(t_dim, out_ch)
        self.n2 = nn.GroupNorm(8, out_ch)
        self.c2 = nn.Conv2d(out_ch, out_ch, 3, 1, 1)
        self.skip = nn.Conv2d(in_ch, out_ch, 1) if in_ch != out_ch else nn.Identity()

    def forward(self, x, emb):
        h = self.c1(F.silu(self.n1(x)))
        h = self.film(h, emb)
        h = self.c2(F.silu(self.n2(h)))
        return h + self.skip(x)

def unet_skip_concat(up_feat, skip_feat):
    dh = skip_feat.size(-2) - up_feat.size(-2)
    dw = skip_feat.size(-1) - up_feat.size(-1)
    if dh or dw:
        up_feat = F.pad(up_feat, (0, dw, 0, dh))
    return torch.cat([up_feat, skip_feat], dim=1)

--- solution
class MiniUNet(nn.Module):
    def __init__(self, in_ch=1, t_dim=128):
        super().__init__()
        self.t_dim = t_dim
        self.t_mlp = nn.Sequential(nn.Linear(64, t_dim), nn.SiLU(), nn.Linear(t_dim, t_dim))
        self.stem = nn.Conv2d(in_ch, 32, 3, 1, 1)
        self.rb1 = ResBlock(32, 32, t_dim)
        self.ds1 = nn.Conv2d(32, 32, 4, 2, 1)
        self.rb2 = ResBlock(32, 64, t_dim)
        self.ds2 = nn.Conv2d(64, 64, 4, 2, 1)
        self.mid = ResBlock(64, 64, t_dim)
        self.up = nn.Upsample(scale_factor=2, mode="nearest")
        self.rb3 = ResBlock(64 + 64, 32, t_dim)
        self.rb4 = ResBlock(32 + 32, 32, t_dim)
        self.out = nn.Sequential(nn.GroupNorm(8, 32), nn.SiLU(), nn.Conv2d(32, in_ch, 3, 1, 1))

    def forward(self, x, t):
        emb = self.t_mlp(timestep_embedding(t, 64))
        h = self.stem(x)
        s1 = self.rb1(h, emb)
        h = self.ds1(s1)
        s2 = self.rb2(h, emb)
        h = self.ds2(s2)
        h = self.mid(h, emb)
        h = self.rb3(unet_skip_concat(self.up(h), s2), emb)
        h = self.rb4(unet_skip_concat(self.up(h), s1), emb)
        return self.out(h)

    """DDPM 反向一步：x_t -> x_{t-1}。t: (B,)；t == 0 的样本不加噪声"""
    raise todo()
--- solution
def p_sample_step(x_t, t, eps_pred, sched, noise=None):
    beta = extract(sched["betas"], t, x_t.shape)
    alpha = extract(sched["alphas"], t, x_t.shape)
    ab = extract(sched["alphas_cumprod"], t, x_t.shape)
    mean = (x_t - beta / (1 - ab).sqrt() * eps_pred) / alpha.sqrt()
    if noise is None:
        noise = torch.randn_like(x_t)
    keep = (t > 0).float().reshape(-1, *([1] * (x_t.dim() - 1)))
    return mean + keep * beta.sqrt() * noise    # t=0 时不加噪声

- 1 次：网络一次就能预测出全部噪声
- 16 次：每张图一次
- 1000 次：每个时间步一次
- 16000 次：每张图的每个时间步各一次
answer: 3
--- explain
反向过程只能一步一步走：算 x_{t-1} 需要网络先看 x_t，而 x_t 又是上一步的结果。所以 1000 步必须串行，每步调用一次网络。batch 里的 16 张图在同一次调用里一起算，所以不是 16000 次。

这就是 DDPM 采样慢的原因。第 9 天的 DDIM 只走其中几十步，就能快很多倍。

def q_sample(x0, t, noise, sched):
    ab = extract(sched["alphas_cumprod"], t, x0.shape)
    return ab.sqrt() * x0 + (1 - ab).sqrt() * noise

    step = 60

    # 逐步加噪：x_t = sqrt(1-beta_t) * x_{t-1} + sqrt(beta_t) * eps
    x = x0.clone()
    for i in range(step + 1):
        b = s["betas"][i]
        x = (1 - b).sqrt() * x + b.sqrt() * torch.randn_like(x)

不看笔记，写出 `p_sample_step(x_t, t, eps_pred, sched, noise=None)`：DDPM 反向一步，从 x_t 算出 x_{t-1}。

- `x_t`、`eps_pred`：`(B, C, H, W)`，`eps_pred` 是网络预测的噪声
- `t`：`(B,)`，每个样本可以不同。t > 0 的样本加上 sqrt(beta_t) 倍的噪声，t = 0 的样本不加
- `noise` 是 None 时自己采
- `sched` 有 `"betas"`、`"alphas"`、`"alphas_cumprod"`；`extract` 可以直接用
--- starter
def p_sample_step(x_t, t, eps_pred, sched, noise=None):

--- solution
def p_sample_step(x_t, t, eps_pred, sched, noise=None):
    beta = extract(sched["betas"], t, x_t.shape)
    alpha = extract(sched["alphas"], t, x_t.shape)
    ab = extract(sched["alphas_cumprod"], t, x_t.shape)
    mean = (x_t - beta / (1 - ab).sqrt() * eps_pred) / alpha.sqrt()
    if noise is None:
        noise = torch.randn_like(x_t)
    keep = (t > 0).float().reshape(-1, *([1] * (x_t.dim() - 1)))
    return mean + keep * beta.sqrt() * noise    # t=0 时不加噪声
