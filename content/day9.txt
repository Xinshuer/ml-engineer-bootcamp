@@ concept
title: 图像变成 token 序列
--- body
attention 吃的是「一串 token」，形状 (B, T, C)：B 个样本，每个 T 个 token，每个 token 是 C 维向量。图像特征图的形状是 (B, C, H, W)。想让图像特征做 attention，先把它摊平成序列。

- 每个像素位置变成一个 token。这个 token 的向量，就是这个位置上 C 个通道的值。
- 一共 H*W 个 token。顺序是**行优先**：先第 0 行从左到右，再第 1 行，依此类推。
- 写法：`x.flatten(2)` 把第 2 维以后的 (H, W) 合成一维，得到 (B, C, H*W)；再 `.transpose(1, 2)` 交换第 1、2 维，得到 (B, H*W, C)。

attention 做完要接回卷积，得变回去：先 `transpose(1, 2)` 回到 (B, C, H*W)，再 `reshape(B, C, H, W)`。注意：transpose 之后内存不连续，这时 `view` 只要需要合并维度就会报错。`reshape` 永远能用，所以 transpose 之后习惯用 `reshape`。

真实的数字：64×64 的特征图、320 个通道，摊平以后是 4096 个 token，每个 320 维。
--- code
import torch

x = torch.arange(12.).reshape(1, 3, 2, 2)   # B=1, C=3, H=2, W=2
print(x[0, 0])                               # 通道 0 的 2x2
tok = x.flatten(2).transpose(1, 2)
print(tok.shape)                             # 4 个 token，每个 3 维
print(tok[0])                                # 第 0 行 = 左上角像素的 3 个通道；第 1 行 = 它右边的像素
back = tok.transpose(1, 2).reshape(1, 3, 2, 2)
print(torch.equal(back, x))                  # 变回去，一个数都不差

@@ concept
title: Cross-attention：图像提问，文本回答
--- body
self-attention 里，Q、K、V 都来自同一个序列。cross-attention 把它们分开：

- **Q 来自图像 token** x，形状 (B, Tx, C)。每个像素位置在问：「文本里哪些词和我有关？」
- **K 和 V 来自文本嵌入** ctx，形状 (B, Tc, Cc)。文本的维度 Cc 可以和 C 不一样，所以投影矩阵 wk、wv 的形状是 (Cc, C)，把文本投影到 C 维。
- 注意力矩阵是 (Tx, Tc)：每个图像 token 给每个文本 token 打一个分，softmax 以后每行加起来是 1。
- 输出是 (B, Tx, C)。**输出的长度跟着 Q（图像）走**，和文本多长无关。文本是 7 个 token 还是 77 个 token，输出形状都一样。

不需要 causal mask（因果遮挡）：每个图像 token 都可以看全部文本。

多头的拆法和第 4 天一样：投影以后 `view(B, T, n_head, hd).transpose(1, 2)`，变成 (B, n_head, T, hd)，其中 hd = C // n_head；过 `F.scaled_dot_product_attention` 以后，再 `transpose(1, 2).reshape(B, T, C)` 拼回去。唯一的区别：Q 的长度是 Tx，K、V 的长度是 Tc。

Stable Diffusion 就是这样把文字「告诉」UNet 的：UNet 里很多层都有 cross-attention，Q 是图像特征，K、V 是文本编码器的输出。
--- code
import torch
import torch.nn.functional as F

torch.manual_seed(0)
B, Tx, Tc, C, Cc = 1, 6, 3, 8, 5
x = torch.randn(B, Tx, C)        # 6 个图像 token，每个 8 维
ctx = torch.randn(B, Tc, Cc)     # 3 个文本 token，每个 5 维
wq, wk, wv = torch.randn(C, C), torch.randn(Cc, C), torch.randn(Cc, C)
q, k, v = x @ wq, ctx @ wk, ctx @ wv
print("q", tuple(q.shape), "k", tuple(k.shape), "v", tuple(v.shape))
att = (q @ k.transpose(1, 2) / C ** 0.5).softmax(-1)
print("注意力矩阵", tuple(att.shape))    # 每个图像 token 对 3 个文本 token 各打一个分
print("每行加起来", att.sum(-1))
out = F.scaled_dot_product_attention(q, k, v)
print("输出", tuple(out.shape))           # 长度跟着图像走

@@ concept
title: 类别条件：加到时间嵌入上
--- body
「条件」就是你想控制的东西：一个类别（「画一个数字 7」），或者一句文本。文本很长，用上一张卡的 cross-attention。**类别**只是一个编号，最简单的做法是：

1. 用 `nn.Embedding(num_classes, D)` 把类别编号变成一个 D 维向量（类别嵌入）。
2. 直接**加到时间嵌入上**：`emb = t_emb + class_emb`，两个都是 (B, D)。
3. 之后 emb 照常走第 8 天的 FiLM，进每一个 ResBlock。

为什么相加就够了？相加以后，后面的 Linear 层拿到的一个向量里，既有「现在是第几步」，也有「要画什么」。网络会自己学会把两者分开用。DiT 和很多按类别生成的扩散模型都是这么做的。

为 CFG 多准备一件事：多留一个编号表示「无条件」（null）。比如 10 个类别，就建 `nn.Embedding(11, D)`，编号 10 的意思是「不告诉你要画什么」。
--- code
import torch
import torch.nn as nn

torch.manual_seed(0)
D, num_classes = 4, 10
class_table = nn.Embedding(num_classes + 1, D)   # 编号 10 = null（无条件）
t_emb = torch.zeros(3, D)                         # 假装这是 3 个样本的时间嵌入
labels = torch.tensor([7, 7, 10])                 # 两个「7」，一个「无条件」
emb = t_emb + class_table(labels)
print(emb.shape)
print(emb.detach().round(decimals=2))             # 前两行一样：同一个类别、同一个时间步

@@ concept
title: 条件 dropout：CFG 的前提
--- body
下一张卡的 CFG 在采样时要**两个**预测：一个有条件，一个无条件。要训练两个模型吗？不用。训练时随机把一部分样本的条件换成 null，同一个模型就学会了两件事：

- 看到真条件：预测「按这个条件」该去掉的噪声。
- 看到 null：预测「什么都不知道时」该去掉的噪声。

要点：

- 丢弃概率 p 通常取 0.1，也就是 10% 的样本不给条件。
- **按样本丢，不是按元素丢**。一个样本的条件，要么整条保留，要么整条换成 null。像普通 dropout 那样把向量里的一部分数变成 0，得到的是「半个条件」，采样时根本用不上。
- 写法：每个样本抽**一个**随机数，`keep = torch.rand(B, 1) >= p`。形状 (B, 1) 可以广播到 (B, D)。把 keep 转成浮点数，再 `keep * cond + (1 - keep) * null`。
- 只在训练时这样做。采样时条件由你决定。
--- code
import torch

torch.manual_seed(0)
B, D, p = 6, 3, 0.5                # 这里 p 取 0.5，效果明显；真实训练常用 0.1
cond = torch.ones(B, D)            # 真条件：全 1
null = torch.zeros(D)              # null 条件：全 0
keep = (torch.rand(B, 1) >= p).float()
print(keep.squeeze(1))             # 每个样本一个 0 或 1
out = keep * cond + (1 - keep) * null
print(out)                         # 每一行要么全 1，要么全 0

@@ concept
title: CFG：公式和 batch 技巧
--- body
classifier-free guidance（CFG，无分类器引导）是让模型「更听话」的旋钮。采样的每一步，模型预测两次噪声：

- eps_u：给 null 条件时的预测（无条件）
- eps_c：给真条件时的预测（有条件）

然后这样组合：

```
eps = eps_u + scale * (eps_c - eps_u)
```

- `eps_c - eps_u` 是「条件带来的变化」，一个方向。
- scale = 0：结果就是 eps_u，条件被忽略。
- scale = 1：结果正好是 eps_c，就是普通的条件生成。
- scale > 1：沿着这个方向**再多推一点**（外推）。图更贴合条件，但多样性下降；太大（比如 20）颜色会过饱和。Stable Diffusion 默认用 7.5。

结果离 eps_u 的距离正好是 scale × |eps_c - eps_u|，所以 scale 越大离得越远。

**batch 技巧**：两个预测不要跑两次模型。把输入复制一份拼起来，一次前向算完：

1. x 变成 `torch.cat([x, x])`，形状 (2B, ...)；时间步 t 也一样拼。
2. 条件拼成 `torch.cat([null 扩成 B 行, cond])`：**前一半 null，后一半 cond**。这是约定，拆的时候要对上。
3. 输出用 `out.chunk(2)` 拆成两块，第一块是 eps_u，第二块是 eps_c，再套上面的公式。

在 GPU 上，一次 batch 为 2B 的前向，比两次 batch 为 B 的前向快。代价是这一步的激活显存翻倍。
--- code
import torch

eps_u = torch.tensor([0.0, 1.0])
eps_c = torch.tensor([1.0, 1.0])
for scale in [0.0, 1.0, 3.0, 7.5]:
    eps = eps_u + scale * (eps_c - eps_u)
    print(scale, eps.tolist(), "离 eps_u 的距离", (eps - eps_u).norm().item())

B, D = 2, 4
x = torch.randn(B, 1, 8, 8)
cond = torch.ones(B, D)
null = torch.zeros(D)
both_x = torch.cat([x, x])
both_c = torch.cat([null.expand(B, -1), cond])     # 前一半 null，后一半 cond
print(both_x.shape, both_c.shape)
print(both_c)

@@ concept
title: DDIM 的时间步：跳着走
--- body
第 8 天的 DDPM 训练时用 T=1000 步，采样时也得一步一步走 1000 步，太慢。DDIM 用**同一个训练好的模型**，只挑其中一小部分时间步来走，比如 50 步，甚至 10 步。不用重新训练。

怎么挑：等间隔。间隔 k = T // steps（整除），要的时间步是 0, k, 2k, …, (steps-1)*k，一共 steps 个。采样从噪声最大的地方开始，所以要**倒过来**，从大到小走：

- T=1000，steps=5：k=200，时间步是 [800, 600, 400, 200, 0]
- T=1000，steps=50：k=20，时间步是 [980, 960, …, 20, 0]

两个细节：

- 最后一个一定是 0。最后一步要落到干净图上。
- 个数必须正好是 steps。`torch.arange(0, T, k)` 在 T 能被 steps 整除时没问题；T=100、steps=30 时 k=3，它会给出 34 个（0, 3, …, 99），多了 4 个。

每一步从 t 走到列表里的下一个时间步，叫 t_prev（比如 800 走到 600）。最后一步从 0 走到 -1：-1 的意思是「干净图本身」。
--- code
import torch

T, steps = 1000, 5
k = T // steps
print("k =", k)
print(torch.arange(0, T, k))              # 从小到大
print(torch.arange(0, T, k).flip(0))      # 倒过来：从噪声最大的地方开始

T, steps = 100, 30
k = T // steps
print(f"k = {k}，arange(0, T, k) 给了 {len(torch.arange(0, T, k))} 个，要的是 {steps} 个")

@@ concept
title: DDIM 一步：先猜 x0，再重新加噪
ref: day8
--- body
回忆第 8 天的 q_sample：`x_t = sqrt(ab_t) * x0 + sqrt(1 - ab_t) * eps`。ab 是 alphas_cumprod（alpha 的累乘），t 越大 ab 越小，x_t 里噪声越多。

DDIM 的一步（eta=0，不加新的随机噪声）分两半：

1. **从 x_t 反推 x0**。模型预测了噪声 eps，把 q_sample 的式子倒过来解：`x0_pred = (x_t - sqrt(1 - ab_t) * eps) / sqrt(ab_t)`
2. **用同一个 eps，重新加噪到 t_prev**：`x_prev = sqrt(ab_prev) * x0_pred + sqrt(1 - ab_prev) * eps`

第 2 步其实就是 `q_sample(x0_pred, t_prev, eps)`。所以，如果模型预测的 eps 正好是当初加进去的真噪声，DDIM 一步会**精确**落在 `q_sample(x0, t_prev, eps)` 上。这是检验采样器最好用的单元测试。

- t_prev = -1 表示「走到头」：规定 ab_prev = 1，于是 x_prev 就是 x0_pred。
- 整个过程没有随机数。同一个起始噪声，永远得到同一张图。DDPM 每一步都会加新的随机噪声，所以每次都不一样。
- t 和 t_prev 都是 (B,) 的张量。取系数用第 8 天的 `extract(arr, t, x.shape)`，它把 (B,) 变成 (B, 1, 1, 1)，方便和图像广播。
- `extract` 里的 gather 不接受 -1。先用 `t_prev.clamp(min=0)` 取出 ab_prev，再用 `torch.where` 把 t_prev < 0 的位置换成 1。

**采样循环**：从 `x = torch.randn(shape)` 出发，依次走 (t, t_prev) = (800, 600), (600, 400), …, (0, -1)。每一步先 `eps = model(x, t)`，再 `x = ddim_step(x, t, t_prev, eps, sched)`。最后的 x 就是生成的图。

下面的例子只演示第 1 步：t=600 时 x_t 几乎全是噪声，但只要 eps 是真噪声，反推出来的 x0 一个数都不差。
--- code
torch.manual_seed(0)
s = linear_schedule(1000)
x0 = torch.randn(1, 4)                 # 一张只有 4 个数的「干净图」
eps = torch.randn(1, 4)                # 当初加进去的噪声
t = torch.tensor([600])
x_t = q_sample(x0, t, eps, s)
ab = extract(s["alphas_cumprod"], t, x_t.shape)
print("ab_600 =", round(ab.item(), 4))  # 很小：x_t 里几乎全是噪声
print("x_t    ", x_t)
x0_pred = (x_t - (1 - ab).sqrt() * eps) / ab.sqrt()
print("x0     ", x0)
print("x0_pred", x0_pred)              # 和 x0 一样

@@ concept
title: Latent diffusion：Stable Diffusion 的形状账
--- body
直接在 512×512 的像素上做扩散太贵：一张图有 3×512×512 ≈ 78 万个数，UNet 每一步都要处理一遍。Stable Diffusion 用的是 latent diffusion（潜空间扩散）：先用第 7 天那种 VAE 把图压小，在小的 latent 上做扩散，最后再解码回像素。

Stable Diffusion 1.x 的几个固定数字：

- VAE：长宽各缩小 8 倍，latent 有 4 个通道。
- UNet 的第一个卷积把 4 个通道升到 320 个。
- 文本编码器（CLIP）把提示词变成 77 个 token，每个 768 维。

有了这几个数，每一步的形状都能推出来。下面用 batch 2、256×256 的图举例：

1. 图像：(2, 3, 256, 256)
2. VAE 编码：256 ÷ 8 = 32，latent 是 (2, 4, 32, 32)。数的个数少了 48 倍。
3. 加噪、UNet 预测噪声、DDIM 去噪，全都在 latent 上做。UNet 输出（预测的噪声）和输入 latent 同形：(2, 4, 32, 32)。
4. UNet 里面：第一个卷积以后是 (2, 320, 32, 32)；摊平成 token 是 (2, 32*32, 320) = (2, 1024, 320)。
5. 文本嵌入：(2, 77, 768)。
6. cross-attention：Q 来自 (2, 1024, 320)，K、V 来自 (2, 77, 768)（wk、wv 把 768 投影到 320）。输出跟着 Q 走：(2, 1024, 320)。
7. 采样结束，VAE 解码回 (2, 3, 256, 256)。

再加上 CFG 的 batch 技巧，UNet 每一步实际处理的 batch 会翻倍。
--- code
import torch
import torch.nn as nn

B, H, W = 2, 256, 256
image = torch.zeros(B, 3, H, W)
latent = torch.zeros(B, 4, H // 8, W // 8)        # VAE：长宽 ÷8，4 个通道
print("image ", tuple(image.shape), image[0].numel(), "个数 / 张")
print("latent", tuple(latent.shape), latent[0].numel(), "个数 / 张")
print(f"少了 {image.numel() // latent.numel()} 倍")
h = nn.Conv2d(4, 320, 3, padding=1)(latent)       # UNet 第一层：4 -> 320 通道
tokens = h.flatten(2).transpose(1, 2)
print("latent tokens", tuple(tokens.shape))

level: 1
cards: 图像变成 token 序列

ref: day8, day9
--- context
UNet 里的 attention 层、DiT、ViT 都要先把 (B, C, H, W) 的特征图摊成 token 序列，做完再变回去。顺序一错，token 就对不上原来的像素：不会报错，但模型学不好。
--- prompt
写两个函数：

- `to_tokens(x)`：输入 (B, C, H, W)，输出 (B, H*W, C)。第 i 个 token 是第 i 个像素位置上 C 个通道的值，像素按**行优先**排（先第 0 行从左到右，再第 1 行……）。
- `to_spatial(tok, H, W)`：输入 (B, H*W, C)，输出 (B, C, H, W)。它是 `to_tokens` 的逆操作：`to_spatial(to_tokens(x), H, W)` 必须和 x 完全一样。

例子：x 的形状是 (2, 8, 4, 6)，`to_tokens(x)` 是 (2, 24, 8)。
--- starter
def to_tokens(x):
    """(B, C, H, W) -> (B, H*W, C)。这一步之后，图像就变成了「一句话」。"""
    raise todo()

def to_spatial(tok, H, W):
    """(B, H*W, C) -> (B, C, H, W)，是 to_tokens 的逆操作。"""
    raise todo()
--- solution
def to_tokens(x):
    return x.flatten(2).transpose(1, 2)          # (B,C,H,W) -> (B,C,HW) -> (B,HW,C)

def to_spatial(tok, H, W):
    B, N, C = tok.shape
    return tok.transpose(1, 2).reshape(B, C, H, W)
--- tests
@check("空间 <-> token 往返")
def t01():
    x = torch.randn(2, 8, 4, 6)
    tok = to_tokens(x)
    shape_is(tok, (2, 24, 8))
    eq(to_spatial(tok, 4, 6), x, msg="往返必须完全还原（顺序是行优先）")
    eq(tok[0, 0], x[0, :, 0, 0], msg="第 0 个 token 应该是左上角像素的通道向量")
    eq(tok[0, 1], x[0, :, 0, 1], msg="第 1 个 token 应该是它右边那个像素（行优先）")
--- hints
- `x.flatten(2)` 把第 2 维以后的 H、W 合成一维，得到 (B, C, H*W)。还差一步：把 C 换到最后。
- `to_tokens`：`x.flatten(2).transpose(1, 2)`。
- `to_spatial`：先 `tok.transpose(1, 2)` 回到 (B, C, H*W)，再 `.reshape(B, C, H, W)`。transpose 之后优先用 `reshape` 而不是 `view`：内存已经不连续，`view` 一遇到要合并维度就会报错。

level: 2

--- context
Stable Diffusion 就是靠 cross-attention 把文字告诉 UNet 的：图像特征当 Q，文本嵌入当 K 和 V。文本可以任意长，输出形状只跟着图像走，所以同一个 UNet 能配不同长度的提示词。
--- prompt
写 `cross_attention(x, ctx, wq, wk, wv, n_head)`：

- x：(B, Tx, C)，图像 token。ctx：(B, Tc, Cc)，文本嵌入。Tc 和 Tx 没有关系，Cc 也可以不等于 C。
- 权重：wq 是 (C, C)，wk 和 wv 是 (Cc, C)。投影就是 `x @ wq`、`ctx @ wk`、`ctx @ wv`，没有 bias。
- 分成 n_head 个头，每个头 hd = C // n_head 维。用 `F.scaled_dot_product_attention` 算注意力，不要 causal mask。最后把头拼回去。
- 返回 (B, Tx, C)。

测试先用 Tc=7 和参考结果对拍，再换成 Tc=77，看形状还对不对。
--- starter
def cross_attention(x, ctx, wq, wk, wv, n_head):
    """x:   (B, Tx, C)    图像 token
    ctx: (B, Tc, Cc)   文本嵌入（长度和 Tx 完全无关）
    wq: (C, C)   wk: (Cc, C)   wv: (Cc, C)

def cross_attention(x, ctx, wq, wk, wv, n_head):
    B, Tx, C = x.shape
    Tc = ctx.size(1)
    hd = C // n_head
    q = (x @ wq).view(B, Tx, n_head, hd).transpose(1, 2)       # Q 来自图像
    k = (ctx @ wk).view(B, Tc, n_head, hd).transpose(1, 2)     # K、V 来自文本
    v = (ctx @ wv).view(B, Tc, n_head, hd).transpose(1, 2)
    o = F.scaled_dot_product_attention(q, k, v)                 # (B, n_head, Tx, hd)
    return o.transpose(1, 2).reshape(B, Tx, C)

    """以概率 p 把某些样本的条件整条换成 null_emb（无条件嵌入）。
    cond_emb: (B, D)   null_emb: (D,)   返回 (B, D)。

--- solution
def drop_cond(cond_emb, null_emb, p, generator=None):
    B = cond_emb.size(0)
    keep = (torch.rand(B, 1, generator=generator) >= p).to(cond_emb.dtype)   # 每个样本一个随机数
    return keep * cond_emb + (1 - keep) * null_emb.expand_as(cond_emb)

    """不要跑两次 model。把 x 复制两份、条件拼成 [null, cond]，一次前向再拆开。
    x: (B,C,H,W)   t: (B,)   cond: (B,D)   null_cond: (D,)

--- solution
def cfg_forward(model, x, t, cond, null_cond, scale):
    B = x.size(0)
    both_x = torch.cat([x, x])
    both_t = torch.cat([t, t])
    both_c = torch.cat([null_cond.expand(B, -1), cond])       # 约定：前一半 null，后一半 cond
    out = model(both_x, both_t, both_c)
    e_u, e_c = out.chunk(2)
    return cfg_combine(e_u, e_c, scale)

def ddim_step(x_t, t, t_prev, eps_pred, sched):
    """x0_pred = (x_t - sqrt(1-ab_t) * eps) / sqrt(ab_t)
    x_prev  = sqrt(ab_prev) * x0_pred + sqrt(1-ab_prev) * eps      (eta=0，不加随机噪声)
    t / t_prev 都是 (B,) 张量。t_prev 可以是 -1，这时 ab_prev = 1（直接返回 x0_pred）。
    """

--- solution
def ddim_step(x_t, t, t_prev, eps_pred, sched):
    ab = extract(sched["alphas_cumprod"], t, x_t.shape)
    x0 = (x_t - (1 - ab).sqrt() * eps_pred) / ab.sqrt()          # 第 1 步：反推 x0
    prev_ok = (t_prev >= 0)
    tp = t_prev.clamp(min=0)                                       # gather 不接受 -1
    ab_prev = extract(sched["alphas_cumprod"], tp, x_t.shape)
    ones = torch.ones_like(ab_prev)
    ab_prev = torch.where(prev_ok.reshape(-1, *([1] * (x_t.dim() - 1))), ab_prev, ones)
    return ab_prev.sqrt() * x0 + (1 - ab_prev).sqrt() * eps_pred   # 第 2 步：用同一个 eps 重新加噪

@torch.no_grad()
def ddim_sample(model, shape, sched, steps=10, device="cpu"):
    ts = ddim_timesteps(len(sched["betas"]), steps).to(device)
    x = torch.randn(shape, device=device)
    for i, tv in enumerate(ts):
        t = torch.full((shape[0],), int(tv), dtype=torch.long, device=device)
        tp_val = int(ts[i + 1]) if i + 1 < len(ts) else -1          # 最后一步走到 -1
        t_prev = torch.full((shape[0],), tp_val, dtype=torch.long, device=device)
        x = ddim_step(x, t, t_prev, model(x, t), sched)
    return x

不看卡片，写出 `ddim_step(x_t, t, t_prev, eps_pred, sched)`（eta=0）：

- x_t：(B, C, H, W)；t、t_prev：(B,) 的 long 张量；eps_pred 和 x_t 同形状；用 `sched["alphas_cumprod"]`。
- 先从 x_t 和 eps_pred 反推 x0_pred，再用同一个 eps_pred 加噪到 t_prev，返回结果。
- t_prev 可能是 -1，这时 ab_prev 按 1 算（返回 x0_pred）。

`extract`、`linear_schedule`、`q_sample` 可以直接用。
--- starter
def ddim_step(x_t, t, t_prev, eps_pred, sched):
    raise todo()
--- solution
def ddim_step(x_t, t, t_prev, eps_pred, sched):
    ab = extract(sched["alphas_cumprod"], t, x_t.shape)
    x0 = (x_t - (1 - ab).sqrt() * eps_pred) / ab.sqrt()
    tp = t_prev.clamp(min=0)
    ab_prev = extract(sched["alphas_cumprod"], tp, x_t.shape)
    ab_prev = torch.where((t_prev >= 0).reshape(-1, *([1] * (x_t.dim() - 1))), ab_prev, torch.ones_like(ab_prev))
    return ab_prev.sqrt() * x0 + (1 - ab_prev).sqrt() * eps_pred
