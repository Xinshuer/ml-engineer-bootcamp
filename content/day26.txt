title: 第 1 步：数据、smoke test、过拟合
ref: day26
--- body
### 可复现的数据
`make_data(n, seed)` 用自己的 `torch.Generator` 抽随机数：同一个 seed 永远得到同一份数据，而且不碰全局随机数（`torch.manual_seed` 管的那个）。这样「造数据」不会改变后面训练时抽 batch 的顺序（第 18 天：可复现）。

标签必须是 `int64`（long），`F.cross_entropy` 才收（第 16 天）。

### smoke test：开训前一次 forward + backward
- 输出 shape 对不对：应该是 `(batch, 3)`。
- 有没有 nan / inf：`torch.isfinite(logits).all()`。
- 第一个 loss 应该接近 `ln 3 ≈ 1.099`：刚初始化的模型对 3 类差不多一视同仁（第 15 天）。离得很远，通常是初始化或输入的尺度有问题。
- backward 之后，每个要训练的参数都要有有限的 `.grad`。`grad is None` 说明这个参数根本没接进计算图（第 15 天）。

### 过拟合一个 batch
只拿 16 条数据反复训练，loss 应该降到接近 0。降不下去，说明代码有 bug，先别去调超参（第 14 天）。
--- code
x, y = make_data(16, seed=0)
torch.manual_seed(0)
model = TinyNet()
print("first loss:", round(smoke_test(model, x, y), 3), "  ln 3 =", round(math.log(3), 3))
losses = overfit_one_batch(model, x, y, steps=200)
print("overfit 16 rows:", round(losses[0], 3), "->", round(losses[-1], 4))

title: 第 2 步：固定种子，训练几秒
ref: day26
--- body
训练循环（第 15 天的几个坑都在这里）：
- 每一步用 `torch.randint(0, len(x), (batch_size,))` 随机抽 64 行 → forward → `F.cross_entropy` → `opt.zero_grad()` → `loss.backward()` → `opt.step()`。
- 记 `loss.item()`，不要记 `loss` 本身：tensor 会把整张计算图留在内存里（第 19 天）。
- 一开头先 `model.train()`。`accuracy` 会把模型切到 `eval()`（dropout 关掉）；不切回来，后面的训练就一直没有 dropout（第 17 天）。
- 优化器由外面建好传进来：续训时要用从 checkpoint 读回来的那个。

固定种子：`torch.manual_seed(0)` 之后再建模型、再训练，同样的代码每次得到一模一样的 loss。这是第 3 步「续训 == 不中断」能对上的前提（第 18 天）。

下面的例子在 CPU 上一两秒就跑完：前 20 步的平均 loss 约 0.75，最后 20 步约 0.18，验证集准确率约 0.95。三类数据本来就有重叠，训再久也到不了 100%。
--- code
torch.manual_seed(0)
x_train, y_train = make_data(2000, seed=1)
x_val, y_val = make_data(500, seed=2)
model = TinyNet()
opt = torch.optim.AdamW(model.parameters(), lr=3e-3)
losses = train_steps(model, opt, x_train, y_train, steps=300)
print(f"mean loss, first 20 steps: {sum(losses[:20]) / 20:.3f}")
print(f"mean loss, last 20 steps:  {sum(losses[-20:]) / 20:.3f}")
print(f"val accuracy: {accuracy(model, x_val, y_val):.3f}")

title: 第 3 步：能续训的 checkpoint
ref: day26
--- body
训练可能被打断（机器重启、云上的抢占式 GPU 被收回）。能续训的 checkpoint 要做到：「存 → 读 → 接着训」和「一口气训完」得到一模一样的权重（第 20 天）。

存两个文件：
- `model.safetensors`：只有权重。`save_file(model.state_dict(), 路径)` 存，`load_file(路径)` 读。safetensors 里只有张量，没有可执行的 pickle，读别人给的文件也安全。上线时服务只需要这一个文件。
- `train_state.pt`：只有续训才用得到的东西：`{"opt": opt.state_dict(), "step": step, "rng": torch.get_rng_state()}`。用 `torch.load(路径, weights_only=True)` 读：只允许张量、数字、列表、字典，不会执行文件里的任意代码。

少存一样会怎样：
- 没存优化器状态：AdamW 的两个动量（`exp_avg`、`exp_avg_sq`）从 0 重新开始，续训后的每一步都和原来不一样。
- 没存随机数状态：续训后抽到的 batch、dropout 的 mask 都和不中断时不一样。

两种情况都不报错，loss 也照样下降，只是结果悄悄变了。所以要用测试来证明「续训 == 不中断」。真实项目还会先写临时文件再 `os.replace`，避免写到一半断电留下坏文件（第 20 天）。
--- code
import os, tempfile
from safetensors.torch import load_file
torch.manual_seed(0)
x, y = make_data(2000, seed=1)
model = TinyNet()
opt = torch.optim.AdamW(model.parameters(), lr=3e-3)
train_steps(model, opt, x, y, steps=10)
folder = tempfile.mkdtemp()
save_checkpoint(folder, model, opt, step=10)
for name in sorted(os.listdir(folder)):
    print(name, os.path.getsize(os.path.join(folder, name)), "bytes")
print("weights:", list(load_file(os.path.join(folder, "model.safetensors")).keys()))
state = torch.load(os.path.join(folder, "train_state.pt"), weights_only=True)
print("train_state:", list(state.keys()), "  step =", state["step"])
print("AdamW state of fc1.weight:", list(state["opt"]["state"][0].keys()))

title: 第 4 步：导出 ONNX 并对拍
ref: day26
--- body
上线时常常不带 PyTorch 训练代码，而是把模型导出成 ONNX 文件，用 onnxruntime 跑（第 21 天）：
```python
model.eval()                                # 关掉 dropout：导出的是推理用的图
torch.onnx.export(model, (torch.randn(2, FEATURES),), "tinynet.onnx", dynamo=True,
                  input_names=["x"], output_names=["logits"],
                  dynamic_shapes={"x": {0: "batch"}},   # 第 0 维（batch）可以变
                  external_data=False,                  # 权重写进同一个文件
                  verbose=False)                        # 不打印进度
```
- 示例输入只用来追踪计算图。它的 batch 是 2；不加 `dynamic_shapes`，导出的文件就只收 batch 2。
- `dynamic_shapes` 的键是 `forward` 的参数名：`TinyNet.forward(self, x)` 里的 `x`。
- 不加 `external_data=False`，权重会写进旁边另一个 `.onnx.data` 文件；部署时忘了拷它，模型就加载不了。
- 导出后一定要对拍：同一批输入，比 onnxruntime 的输出和 eval 模式的 PyTorch 输出的最大绝对差。float32 下一般在 1e-7 到 1e-6 之间，容差取 1e-4。多试几个 batch 大小（1、5、64），证明 batch 维真的可变。

导出要先追踪整个模型，要几秒钟：下面的例子点运行后要等一会儿，导出的两道题时间限制是 120 秒。
--- code
import os, tempfile
import onnxruntime as ort
torch.manual_seed(0)
model = TinyNet()
path = export_onnx(model, os.path.join(tempfile.mkdtemp(), "tinynet.onnx"))
sess = ort.InferenceSession(path, providers=["CPUExecutionProvider"])
print("inputs: ", [(i.name, i.shape) for i in sess.get_inputs()])
print("outputs:", [(o.name, o.shape) for o in sess.get_outputs()])
for b in (1, 5, 64):
    x = torch.randn(b, FEATURES)
    with torch.inference_mode():
        want = model(x).numpy()
    got = sess.run(None, {"x": x.numpy()})[0]
    print(f"batch {b:2d}: max |onnx - torch| = {abs(got - want).max():.1e}")

title: 第 5 步：做成 FastAPI 服务
ref: day26
--- body
服务的结构（第 22 天）：
- **启动时加载一次**：`create_app(load_model)` 一开始就调 `load_model()`，拿到一个 `predict` 函数，之后所有请求都用它。每个请求都重新加载模型，是「服务很慢」最常见的原因。
- **预热一次**：加载完先用一行全 0 的输入调一次 `predict`。第一次调用往往特别慢（分配内存、初始化），别让第一个用户来付这个时间。
- `GET /health` 返回 `{"status": "ok"}`，给负载均衡和监控用。
- `POST /predict` 收 `{"rows": [[8 个数], ...]}`，把一个请求里的所有行**一次**送进模型（一个 batch），返回每行的 label 和 3 类的概率。

输入校验交给 pydantic：
```python
Row = Annotated[list[FiniteFloat], Field(min_length=FEATURES, max_length=FEATURES)]

class PredictRequest(BaseModel):
    rows: list[Row] = Field(min_length=1, max_length=MAX_ROWS)
```
- `FiniteFloat`：普通的 float，但不收 nan 和 inf。
- `Annotated[类型, Field(...)]` 给类型加限制；`min_length` / `max_length` 限制列表长度：每行正好 8 个数，一个请求 1 到 64 行。
- 路由函数的参数写成 `req: PredictRequest`，FastAPI 会先校验；不合格就直接回 **422**，你的函数不会被调用，模型也不会跑。

测试不用真的起服务器：`TestClient(app)` 在同一个进程里发请求。
--- code
from fastapi.testclient import TestClient
torch.manual_seed(0)
model = TinyNet()
client = TestClient(create_app(lambda: torch_predictor(model)))
print(client.get("/health").json())
x, _ = make_data(2, seed=5)
r = client.post("/predict", json={"rows": x.tolist()})
print(r.status_code, r.json()["labels"])
r = client.post("/predict", json={"rows": [[1.0] * 7]})
print(r.status_code, r.json()["detail"][0]["msg"])

ref: day26
--- body
### 延迟：看分位数，不看平均
- 先发几次预热请求，不计时（第 19 天）。
- 每次请求用 `time.perf_counter()` 前后相减，乘 1000 变成毫秒。
- 只统计成功（200）的请求：422 返回得很快，混进来会让延迟「看起来」很好。
- 报 p50 / p95 / p99：`np.percentile(times, 95)` 表示 95% 的请求比它快。平均值会被少数慢请求拉高，也把它们藏了起来；用户感到的卡顿在 p95 / p99（第 22 天）。

### 漂移：PSI
上线后输入的分布可能慢慢变了（传感器换了型号、季节变化）。PSI（population stability index，群体稳定性指数）比较一个特征在训练数据（expected）和线上数据（actual）里的分布（第 25 天）：
1. 用训练数据的分位数切 10 个桶，每个桶正好装 10% 的训练数据。
2. 数线上数据落进每个桶的比例 a，训练数据的比例 e。
3. `PSI = Σ (a − e) · ln(a / e)`。比例为 0 的桶先截到一个很小的数 eps，不然 ln 0 = −∞。

常用的经验线：小于 0.1 基本没变；0.1 到 0.25 值得看一看；大于 0.25 明显漂移，要查原因、考虑重新训练。
--- code
times = [3.1, 2.9, 3.0, 3.2, 2.8, 3.0, 3.1, 2.9, 3.0, 25.0]
report = latency_report(times)
print("mean:", round(sum(times) / len(times), 2), " p50 / p95 / p99:", [round(report[k], 2) for k in ("p50", "p95", "p99")])
x_train, _ = make_data(5000, seed=1)
x_same, _ = make_data(5000, seed=2)
x_moved, _ = make_data(5000, seed=3, shift=1.0)
print("PSI, same distribution:", round(psi(x_train[:, 0], x_same[:, 0]), 4))
print("PSI, shifted by 1.0:   ", round(psi(x_train[:, 0], x_moved[:, 0]), 4))

大训练跑了两小时才发现输出 shape 不对，或者某一层根本没接进计算图，太亏了。开训前花一秒做一次 forward + backward，把这类错误挡在门口。
--- prompt
写 `smoke_test(model, x, y)`：对一小批数据做一次 forward + backward，按顺序检查下面 4 条。哪条不满足就 `raise AssertionError("...")`，消息说清楚是哪条；全部通过就返回第一个 loss（Python float）。
1. `logits = model(x)` 的 shape 是 `(len(x), CLASSES)`。
2. `logits` 里没有 nan / inf（`torch.isfinite`）。
3. `loss = F.cross_entropy(logits, y)`，`loss.item()` 和 `math.log(CLASSES)` 的差不超过 0.5。
4. `loss.backward()` 之后，每个 `requires_grad` 为 True 的参数都有 `.grad`，而且里面全是有限值。用 `model.named_parameters()`，消息里带上参数名。
--- starter
def smoke_test(model, x, y):
    """一次 forward + backward。4 条检查，不满足就 raise AssertionError；
    全部通过返回第一个 loss（float）。"""
    raise todo()
--- solution
def smoke_test(model, x, y):
    logits = model(x)
    if tuple(logits.shape) != (len(x), CLASSES):
        raise AssertionError(f"logits 的 shape 是 {tuple(logits.shape)}，应该是 {(len(x), CLASSES)}")
    if not torch.isfinite(logits).all():
        raise AssertionError("logits 里有 nan / inf")
    loss = F.cross_entropy(logits, y)
    if abs(loss.item() - math.log(CLASSES)) > 0.5:
        raise AssertionError(f"第一个 loss {loss.item():.3f} 离 ln 3 = {math.log(CLASSES):.3f} 太远")
    loss.backward()
    for name, p in model.named_parameters():
        if p.requires_grad and (p.grad is None or not torch.isfinite(p.grad).all()):
            raise AssertionError(f"{name} 没有拿到有限的梯度")
    return loss.item()
--- setup

    try:
        fn()

        return
    raise AssertionError(msg)

def overfit_one_batch(model, x, y, steps=200, lr=1e-2):
    model.train()
    opt = torch.optim.AdamW(model.parameters(), lr=lr)
    losses = []
    for _ in range(steps):
        loss = F.cross_entropy(model(x), y)       # cross_entropy 自己会做 log_softmax
        opt.zero_grad(set_to_none=True)           # 清掉上一步的梯度
        loss.backward()
        opt.step()
        losses.append(loss.item())                # 存 float，不留计算图
    return losses

def train_steps(model, opt, x, y, steps, batch_size=64):
    model.train()                                            # accuracy() 可能刚把它切到 eval
    losses = []
    for _ in range(steps):
        idx = torch.randint(0, len(x), (batch_size,))        # 全局随机数：固定种子就能复现
        loss = F.cross_entropy(model(x[idx]), y[idx])
        opt.zero_grad(set_to_none=True)
        loss.backward()
        opt.step()
        losses.append(loss.item())
    return losses

def save_checkpoint(folder, model, opt, step):
    folder = Path(folder)
    folder.mkdir(parents=True, exist_ok=True)
    save_file(model.state_dict(), folder / "model.safetensors")          # 只有张量，读起来安全
    torch.save({"opt": opt.state_dict(), "step": step, "rng": torch.get_rng_state()},
               folder / "train_state.pt")


def load_checkpoint(folder, model, opt):
    folder = Path(folder)
    model.load_state_dict(load_file(folder / "model.safetensors"))
    state = torch.load(folder / "train_state.pt", weights_only=True)
    opt.load_state_dict(state["opt"])                                      # AdamW 的动量
    torch.set_rng_state(state["rng"])                                      # 之后抽的 batch、dropout 的 mask
    return state["step"]

def export_onnx(model, path):

def verify_onnx(model, path, batch_sizes=(1, 5, 64), tol=1e-4):

def measure_latency(client, payload, n=50, warmup=5):
    for _ in range(warmup):                                    # 预热：不计时
        client.post("/predict", json=payload)
    times = []
    for _ in range(n):
        t0 = time.perf_counter()
        r = client.post("/predict", json=payload)
        times.append((time.perf_counter() - t0) * 1000)        # 秒 -> 毫秒
        if r.status_code != 200:
            raise AssertionError(f"状态码 {r.status_code}：失败的请求不算延迟")
    return times


def latency_report(times_ms):
    t = np.asarray(times_ms, dtype=float)
    return {"p50": float(np.percentile(t, 50)), "p95": float(np.percentile(t, 95)),
            "p99": float(np.percentile(t, 99))}

def psi(expected, actual, bins=10, eps=1e-4):
    expected = torch.as_tensor(expected, dtype=torch.float64).flatten()
    actual = torch.as_tensor(actual, dtype=torch.float64).flatten()
    qs = torch.linspace(0, 1, bins + 1, dtype=torch.float64)
    edges = torch.quantile(expected, qs)[1:-1]                 # bins - 1 个内部切点
    e = torch.bincount(torch.bucketize(expected, edges), minlength=bins) / len(expected)
    a = torch.bincount(torch.bucketize(actual, edges), minlength=bins) / len(actual)
    e, a = e.clamp_min(eps), a.clamp_min(eps)                  # 空桶：避免 ln 0
    return float(((a - e) * torch.log(a / e)).sum())

def class_centers():
    g = torch.Generator().manual_seed(1234)
    return torch.randn(CLASSES, FEATURES, generator=g)


def make_data(n, seed=0, shift=0.0):
    g = torch.Generator().manual_seed(seed)
    y = torch.randint(0, CLASSES, (n,), generator=g)
    x = class_centers()[y] + torch.randn(n, FEATURES, generator=g) + shift
    return x, y


class TinyNet(nn.Module):
    def __init__(self, hidden=32, p_drop=0.1):
        super().__init__()
        self.fc1 = nn.Linear(FEATURES, hidden)
        self.drop = nn.Dropout(p_drop)
        self.fc2 = nn.Linear(hidden, CLASSES)

    def forward(self, x):
        return self.fc2(self.drop(F.relu(self.fc1(x))))


def smoke_test(model, x, y):
    logits = model(x)
    if tuple(logits.shape) != (len(x), CLASSES):
        raise AssertionError(f"logits 的 shape 是 {tuple(logits.shape)}")
    if not torch.isfinite(logits).all():
        raise AssertionError("logits 里有 nan / inf")
    loss = F.cross_entropy(logits, y)
    if abs(loss.item() - math.log(CLASSES)) > 0.5:
        raise AssertionError(f"第一个 loss {loss.item():.3f} 离 ln 3 太远")
    loss.backward()
    for name, p in model.named_parameters():
        if p.requires_grad and (p.grad is None or not torch.isfinite(p.grad).all()):
            raise AssertionError(f"{name} 没有拿到有限的梯度")
    return loss.item()


def overfit_one_batch(model, x, y, steps=200, lr=1e-2):
    model.train()
    opt = torch.optim.AdamW(model.parameters(), lr=lr)
    losses = []
    for _ in range(steps):
        loss = F.cross_entropy(model(x), y)
        opt.zero_grad(set_to_none=True)
        loss.backward()
        opt.step()
        losses.append(loss.item())
    return losses

def train_steps(model, opt, x, y, steps, batch_size=64):
    model.train()
    losses = []
    for _ in range(steps):
        idx = torch.randint(0, len(x), (batch_size,))
        loss = F.cross_entropy(model(x[idx]), y[idx])
        opt.zero_grad(set_to_none=True)
        loss.backward()
        opt.step()
        losses.append(loss.item())
    return losses


def accuracy(model, x, y):
    model.eval()
    with torch.inference_mode():
        return (model(x).argmax(dim=1) == y).float().mean().item()

def save_checkpoint(folder, model, opt, step):
    folder = Path(folder)
    folder.mkdir(parents=True, exist_ok=True)
    save_file(model.state_dict(), folder / "model.safetensors")
    state = {"opt": opt.state_dict(), "step": step, "rng": torch.get_rng_state()}
    if torch.cuda.is_available():
        state["cuda_rng"] = torch.cuda.get_rng_state_all()   # GPU 上的 dropout 用 CUDA 自己的随机数
    torch.save(state, folder / "train_state.pt")


def load_checkpoint(folder, model, opt):
    folder = Path(folder)
    model.load_state_dict(load_file(folder / "model.safetensors"))
    state = torch.load(folder / "train_state.pt", weights_only=True)
    opt.load_state_dict(state["opt"])
    torch.set_rng_state(state["rng"])
    if "cuda_rng" in state:
        torch.cuda.set_rng_state_all(state["cuda_rng"])
    return state["step"]

def export_onnx(model, path):
    model.eval()
    example = torch.randn(2, FEATURES)
    torch.onnx.export(model, (example,), str(path), dynamo=True,
                      input_names=["x"], output_names=["logits"],
                      dynamic_shapes={"x": {0: "batch"}},
                      external_data=False, verbose=False)
    return str(path)


def verify_onnx(model, path, batch_sizes=(1, 5, 64), tol=1e-4):
    import onnxruntime as ort

    model.eval()
    sess = ort.InferenceSession(str(path), providers=["CPUExecutionProvider"])
    name = sess.get_inputs()[0].name
    worst = 0.0
    for b in batch_sizes:
        x = torch.randn(b, FEATURES)
        with torch.inference_mode():
            want = model(x).numpy()
        got = sess.run(None, {name: x.numpy()})[0]
        worst = max(worst, float(np.abs(got - want).max()))
    if worst > tol:
        raise AssertionError(f"ONNX 和 PyTorch 差了 {worst:.2e}，超过容差 {tol}")
    return worst

Row = Annotated[list[FiniteFloat], Field(min_length=FEATURES, max_length=FEATURES)]


class PredictRequest(BaseModel):

def onnx_predictor(path):
    import onnxruntime as ort

    sess = ort.InferenceSession(str(path), providers=["CPUExecutionProvider"])
    name = sess.get_inputs()[0].name

    def predict(x):
        logits = sess.run(None, {name: np.asarray(x, dtype=np.float32)})[0]
        e = np.exp(logits - logits.max(axis=1, keepdims=True))
        return e / e.sum(axis=1, keepdims=True)

    return predict

def measure_latency(client, payload, n=50, warmup=5):
    for _ in range(warmup):
        client.post("/predict", json=payload)
    times = []
    for _ in range(n):

    return times

def psi(expected, actual, bins=10, eps=1e-4):
    expected = torch.as_tensor(expected, dtype=torch.float64).flatten()
    actual = torch.as_tensor(actual, dtype=torch.float64).flatten()

    torch.save({"opt": opt.state_dict(), "step": step, "rng": torch.get_rng_state()},
               folder / "train_state.pt")


def load_checkpoint(folder, model, opt):
    folder = Path(folder)
    model.load_state_dict(load_file(folder / "model.safetensors"))
    state = torch.load(folder / "train_state.pt", weights_only=True)
    opt.load_state_dict(state["opt"])
    torch.set_rng_state(state["rng"])
    return state["step"]

def create_app(load_model):
    predict = load_model()
    predict(np.zeros((1, FEATURES), dtype=np.float32))
    app = FastAPI()

    @app.get("/health")
    def health():
        return {"status": "ok"}

    @app.post("/predict")
    def predict_route(req: PredictRequest):
        x = np.asarray(req.rows, dtype=np.float32)
        probs = predict(x)
        return {"labels": [LABELS[i] for i in probs.argmax(axis=1)], "probs": probs.tolist()}

    return app

from fastapi.testclient import TestClient

def _counting_loader():
    torch.manual_seed(0)
    base = torch_predictor(TinyNet())
    calls = {"load": 0, "predict": 0, "rows": []}

    def load_model():
        calls["load"] += 1

        def predict(x):
            calls["predict"] += 1
            calls["rows"].append(len(x))
            return base(x)

        return predict

    return load_model, calls, base
