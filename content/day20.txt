@@ concept
title: state_dict：只存数字，不存代码
ref: day20
--- body
`model.state_dict()` 是一个有序字典：**参数的名字 → 张量**。名字就是属性的路径，比如 `body.weight`。里面除了参数，还有 buffer（不参与训练、但属于模型状态的张量，比如 BatchNorm 的 `running_mean`）。没有参数的层（ReLU、Dropout）不会出现。

保存模型有两种写法：

- `torch.save(model.state_dict(), path)`：只存数字。加载时先用代码造出模型（`Net()`），再用 `load_state_dict` 把数字填进去。**推荐这种。**
- `torch.save(model, path)`：把整个模型对象 pickle 下来。文件里记的是「这个类在哪个模块、叫什么名字」加上所有属性。加载时必须能 import 到**同一个路径下的同一个类**：改个文件名、挪个文件夹、给类改个名，旧文件就打不开了。它还不安全（见下一张卡片）。

记住一句话：**结构来自代码，数字来自文件。**

下面的 `Net` 是今天一直用的小模型：`body`（Linear 4→8）→ ReLU → `drop`（Dropout）→ `head`（Linear 8→2）。
--- code
import os, tempfile

model = Net()
sd = model.state_dict()
for name, t in sd.items():
    print(f"{name:12s} {tuple(t.shape)}")        # drop 没有参数，不出现

with tempfile.TemporaryDirectory() as folder:
    path = os.path.join(folder, "net.pt")
    torch.save(sd, path)
    fresh = Net()                                                # 结构来自代码
    fresh.load_state_dict(torch.load(path, weights_only=True))   # 数字来自文件

model.eval(); fresh.eval()                       # 关掉 dropout 再比较
x = torch.randn(2, 4)
print("输出一样吗?", torch.equal(model(x), fresh(x)))

@@ concept
title: torch.load 和 pickle：加载就可能执行代码
--- body
`.pt` / `.pth` / `.bin` 文件的格式是 pickle（Python 自带的「把对象存成字节」的方法）。pickle 存的不只是数据，还有「加载时要调用哪个函数、传什么参数」来重建对象。一个对象可以通过 `__reduce__` 规定：加载我的时候，请调用 `os.system("...")`。所以 **用 pickle 加载 = 运行文件作者写的代码**。

`torch.load(path, weights_only=True)` 用的是一个受限的加载器：只允许张量、dict、list、tuple、数字、字符串这类纯数据。文件里只要出现别的函数或类，它就报 `UnpicklingError`（信息里有 "Unsupported global"），一行代码都不执行。

- PyTorch 2.6 起，`torch.load` 默认就是 `weights_only=True`。老教程里的 `weights_only=False` 只能用在你自己生成的文件上。
- 这也是「只存 state_dict」的另一个好处：里面全是张量和字符串，`weights_only=True` 能直接加载；pickle 整个模型的文件会被拒绝。
- numpy 数组也不在白名单里：要存 numpy 的随机数状态，先把里面的数组转成张量。
- 来路不明的权重，最好用 safetensors（后面的卡片）。
--- code
import os, pickle, tempfile

class Sneaky:
    def __reduce__(self):          # 告诉 pickle：加载我的时候，调用 print(...)
        return (print, ("加载时执行了这行代码！换成 os.system 也照样执行",))

data = pickle.dumps(Sneaky())
pickle.loads(data)                 # 只是「加载」，代码就跑了

with tempfile.TemporaryDirectory() as folder:
    path = os.path.join(folder, "bad.pt")
    torch.save({"w": torch.ones(2), "x": Sneaky()}, path)
    try:
        torch.load(path, weights_only=True)
    except Exception as e:
        line = [l for l in str(e).splitlines() if "Unsupported global" in l][0]
        print(type(e).__name__, "->", line.split("Unsupported global:")[1].split(" was")[0].strip())

    torch.save({"w": torch.ones(2)}, path)           # 只有张量的 dict
    print(torch.load(path, weights_only=True))       # 正常加载

@@ concept
title: key 前缀：module. 和 _orig_mod.
ref: day20
--- body
有两种常见的「壳」会改掉 state_dict 的 key：

- **DDP / DataParallel**（多卡训练）：`DDP(model)` 把你的模型存在属性 `module` 里，于是 `body.weight` 变成 `module.body.weight`。
- **torch.compile**：`torch.compile(model)` 返回一个新的包装对象，原模型在属性 `_orig_mod` 里，于是 key 变成 `_orig_mod.body.weight`。两个一起用，还可能是 `_orig_mod.module.body.weight`。

推理时的模型没有壳，直接加载就会报一长串 Missing / Unexpected key。两种修法：

1. **存的时候就存里面的模型**：`ddp.module.state_dict()`，或者留着 compile 之前的那个 `model` 变量，存它。最干净。
2. **加载时去掉前缀**：只去 key **开头**的前缀（`str.removeprefix`），中间的不要动（`encoder.module.weight` 里的 `module` 可能是真的子模块名字）。PyTorch 也自带 `torch.nn.modules.utils.consume_prefix_in_state_dict_if_present(sd, "module.")`，它会直接改 sd 本身。

下面用 `Wrapper` 模仿 DDP（真的 DDP 要先启动多进程，这里只看 key 的变化）。
--- code
model = Net()
wrapped = Wrapper(model)                 # 就像 DDP(model)
sd = wrapped.state_dict()
print(list(sd)[:2])

fresh = Net()
try:
    fresh.load_state_dict(sd)
except RuntimeError as e:
    for line in str(e).splitlines()[1:]:
        print(line.strip())

print(list(wrapped.module.state_dict())[:2])      # 修法 1：存里面的模型
clean = {k.removeprefix("module."): v for k, v in sd.items()}
print(fresh.load_state_dict(clean))               # 修法 2：去掉开头的前缀

@@ concept
title: strict=False 会把 bug 藏起来
ref: day20
--- body
`model.load_state_dict(sd)` 默认 `strict=True`：两边的 key 必须完全一致，否则报错并列出：

- **missing keys**：模型需要、文件里没有。这些参数会保持随机初始化。
- **unexpected keys**：文件里有、模型不认识。这些数字被丢掉。

`strict=False` 不报错，只把这两个列表放进返回值（`result.missing_keys` / `result.unexpected_keys`）。大多数人不看返回值。于是：重构时把 `classifier` 改名成 `head`，加载「成功」了，head 却一直是随机的，服务照样上线。

几条规则：

- 加载只按**名字**匹配，不按位置。结构一样、名字不同，也一个都加载不上。
- shape 不同时，就算 `strict=False` 也会报错（size mismatch）。
- 报错时 PyTorch 可能已经把前面对得上的参数拷进去了，模型处在「一半新、一半旧」的状态。想要干净，就**先检查，再加载**。
- 真的只想加载一部分（比如换了分类头做微调）：用 `strict=False`，然后**检查返回值**，确认 missing 的正好是你打算重新训练的那几个。
--- code
torch.manual_seed(0)
v1 = Net()
sd = {k.replace("head.", "classifier."): v for k, v in v1.state_dict().items()}   # 旧版本里叫 classifier

v2 = Net()
result = v2.load_state_dict(sd, strict=False)      # 不报错！
print("missing:   ", result.missing_keys)
print("unexpected:", result.unexpected_keys)
print("body 加载了:", torch.equal(v2.body.weight, v1.body.weight))
print("head 加载了:", torch.equal(v2.head.weight, v1.head.weight))

try:
    Net().load_state_dict(sd)                      # 默认 strict=True：立刻报错
except RuntimeError as e:
    print("strict=True:", str(e).splitlines()[1].strip())

@@ concept
title: safetensors：只装张量的文件
ref: day20
--- body
safetensors 是 Hugging Face 做的权重格式，现在大部分开源模型都用它（`model.safetensors`）。文件结构很简单：开头一小段 JSON（每个张量的名字、dtype、shape、在文件里的位置），后面是原始字节。

- **安全**：只有数据，没有代码。加载别人的文件，不会执行任何东西。
- **快**：可以直接映射到内存，只读你要的那一个张量（`safe_open` + `get_tensor`）。
- **只存张量**：优化器状态、step、随机数状态这类东西放不进去。小信息可以放在 `metadata` 里，但 metadata 只能是「字符串 → 字符串」。
- 张量必须是连续的（contiguous），而且不能有两个名字共用同一块内存（下一张卡片）。

常用的几个函数（都在 `safetensors.torch` 里）：

- `save_file(sd, path, metadata={...})`：存一个「名字 → 张量」的 dict。
- `load_file(path)`：读回一个 dict，再 `model.load_state_dict(...)`。
- `with safe_open(path, framework="pt") as f:`，然后用 `f.keys()`、`f.get_tensor(name)`、`f.metadata()`。

常见搭配：发布、部署用的权重存 safetensors；训练中途的完整 checkpoint（含优化器、随机数）存 `.pt`，用 `weights_only=True` 加载。
--- code
import os, tempfile
from safetensors.torch import save_file, load_file, safe_open

model = Net()
with tempfile.TemporaryDirectory() as folder:
    path = os.path.join(folder, "net.safetensors")
    save_file(model.state_dict(), path, metadata={"step": "1200", "arch": "Net"})

    sd = load_file(path)                              # 名字 -> 张量
    print({k: tuple(v.shape) for k, v in sd.items()})
    with safe_open(path, framework="pt") as f:
        print(f.metadata())
        print(f.get_tensor("head.bias").shape)        # 只读这一个张量

    try:
        save_file(model.state_dict(), path, metadata={"step": 1200})
    except TypeError as e:
        print("metadata 只能是字符串:", e)

@@ concept
title: 共享权重遇上 safetensors
ref: day20
--- body
很多语言模型让「词嵌入」和「输出层」共用同一个权重矩阵（tied weights，比如 GPT-2）：输入时用它把 token 变成向量，输出时用它把向量变回每个词的分数。这样能省下 vocab × dim 个参数：GPT-2 small 省了 50257 × 768 ≈ 3860 万个。

代码里就一行：`self.head.weight = self.emb.weight`。两个名字，同一个 Parameter。但 `state_dict()` 里两个名字都会出现。

- `torch.save` 知道它们是同一块内存，只存一份，加载后仍然共享。
- safetensors 的 `save_file` 直接**拒绝**：`RuntimeError: Some tensors share memory...`。平铺的文件格式没法表达「这两个名字是同一块内存」，硬存就是两份。

修法：用 `save_model(model, path)` / `load_model(model, path)`（也在 `safetensors.torch` 里）。

- `save_model` 发现共享的张量，只存其中一个名字，把「head.weight 其实就是 emb.weight」记在 metadata 里。
- `load_model` 是严格加载，只是因为共享而少掉的那个名字不算 missing。
- 加载后仍然共享，因为共享关系是**模型的构造函数**建立的；加载只是把数字拷进已有的 Parameter。
--- code
import os, tempfile
from safetensors.torch import save_file, save_model, load_model, safe_open

lm = TinyLM()
print("同一个 Parameter:", lm.head.weight is lm.emb.weight)
print("state_dict 的 key:", list(lm.state_dict()))

with tempfile.TemporaryDirectory() as folder:
    path = os.path.join(folder, "lm.safetensors")
    try:
        save_file(lm.state_dict(), path)
    except RuntimeError as e:
        print("save_file 报错:", str(e).strip().split(",")[0])

    save_model(lm, path)                                  # 只存一份
    with safe_open(path, framework="pt") as f:
        print("文件里:", list(f.keys()), f.metadata())

    fresh = TinyLM()
    print("missing, unexpected:", load_model(fresh, path))
    print("仍然共享:", fresh.head.weight is fresh.emb.weight)
    print("数字一样:", torch.equal(fresh.emb.weight, lm.emb.weight))

@@ concept
title: 能续训的 checkpoint 要存什么
ref: day20
--- body
「能续训」的标准：**中断 + 恢复 = 从没中断**，连 loss 的最后一位小数都一样。要做到这一点，checkpoint 里要有：

- **模型**：`model.state_dict()`。
- **优化器**：`opt.state_dict()`。AdamW 为每个参数记着两个动量（`exp_avg`、`exp_avg_sq`）和走过的步数。漏了它，恢复后 loss 会跳一下。
- **学习率调度器**：`sched.state_dict()`（走到第几步、当前学习率）。漏了它，warmup 会重来一遍，或者学习率跳回最高点。
- **step**（还有 epoch、数据读到了哪里）：决定从哪里接着跑、日志怎么接上。
- **随机数状态**：`torch.get_rng_state()`；有 GPU 再加 `torch.cuda.get_rng_state_all()`；用了 `random` 模块就加 `random.getstate()`。dropout 和数据打乱都靠它。漏了它训练照样能跑，但结果和没中断的不一样，没法复现。
- **EMA 权重**（如果用了 EMA，扩散模型里很常见）：它是另一份权重，也要存。

加载时：先用代码造好模型、优化器、scheduler，再把各自的 `state_dict` 装回去，最后恢复随机数状态。

**怎么证明你的 checkpoint 存全了**：A 不间断训练 5 步；B 训练 3 步 → 存 → 打乱随机数、造全新的对象（模拟重启进程）→ 加载 → 再训练 2 步。A 和 B 的 loss、最终权重必须完全一样。

下面的 `make_run()` 返回模型 + AdamW + StepLR（每 2 步学习率减半），`train_step()` 训练一步（数据用 `torch.randn` 现造，模型里有 dropout）。这个 checkpoint 只存了模型和优化器：前 3 步一样，续训的 2 步就对不上了。
--- code
import os, tempfile

torch.manual_seed(0)
model, opt, sched = make_run()
full = [round(train_step(model, opt, sched), 4) for _ in range(5)]
print("不间断 5 步:", full)

torch.manual_seed(0)
model, opt, sched = make_run()
losses = [round(train_step(model, opt, sched), 4) for _ in range(3)]
with tempfile.TemporaryDirectory() as folder:
    path = os.path.join(folder, "ckpt.pt")
    torch.save({"model": model.state_dict(), "optimizer": opt.state_dict(), "step": 3}, path)  # 只存了一半
    torch.manual_seed(999)                 # 模拟重启进程：随机数状态完全不同
    model, opt, sched = make_run()         # 全新的对象
    ckpt = torch.load(path, weights_only=True)
    model.load_state_dict(ckpt["model"])
    opt.load_state_dict(ckpt["optimizer"])
losses += [round(train_step(model, opt, sched), 4) for _ in range(2)]
print("3 步 + 续训 2 步:", losses)
print("一样吗?", losses == full)

@@ concept
title: 原子保存：先写临时文件，再 os.replace
--- body
`torch.save(obj, path)` 会先把 path 清空，再往里写。如果写到一半进程被杀（抢占、OOM、断电、磁盘满），结果是：**旧的 checkpoint 没了，新的是坏的**。

原子保存（atomic save，「要么全做完，要么完全没做」）：

1. 先写到一个临时文件，比如 `path + ".tmp"`；
2. 完整写完之后，用 `os.replace(tmp, path)` 一步换过去。

`os.replace` 在同一个文件系统里是原子的：要么完全没发生（旧文件还在），要么完全发生（新文件就位），不存在「一半」。几个细节：

- 临时文件要和目标放在**同一个文件夹**。跨磁盘（比如 C: 到 G:）时 `os.replace` 做不到原子，Windows 上直接报错。
- 用 `os.replace`，不要用 `os.rename`：Windows 上目标已经存在时，`os.rename` 会报错。
- 出错时把临时文件删掉，再把错误原样抛出去，不要吞掉。
- 想更稳：写完后调用 `f.flush()` 和 `os.fsync(f.fileno())`，保证数据真的落到了磁盘上（防断电）。
--- code
import io, os, tempfile

new_bytes = io.BytesIO()
torch.save({"step": 200, "w": torch.ones(1000)}, new_bytes)
half = new_bytes.getvalue()[: len(new_bytes.getvalue()) // 2]      # 「写到一半就崩了」

with tempfile.TemporaryDirectory() as folder:
    path = os.path.join(folder, "ckpt.pt")

    # 直接覆盖写
    torch.save({"step": 100, "w": torch.ones(1000)}, path)          # 昨天的好 checkpoint
    with open(path, "wb") as f:
        f.write(half)                                               # 写到一半，进程被杀
    try:
        torch.load(path, weights_only=True)
    except Exception as e:
        print("直接覆盖: 旧的没了，新的是坏的 ->", type(e).__name__)

    # 原子写法
    torch.save({"step": 100, "w": torch.ones(1000)}, path)
    tmp = path + ".tmp"
    with open(tmp, "wb") as f:
        f.write(half)                        # 同样写到一半就崩了，根本走不到 os.replace
    print("原子写法: 旧的还在 -> step", torch.load(path, weights_only=True)["step"])

    torch.save({"step": 200, "w": torch.ones(1000)}, tmp)           # 重新来，这次写完整了
    os.replace(tmp, path)                                           # 一步换过去
    print("换成新的 -> step", torch.load(path, weights_only=True)["step"], sorted(os.listdir(folder)))

--- prompt
把空填上：保存 `model` 的 state_dict；用 `weights_only=True` 读回来；造一个新的 `Net`；把读回来的权重填进去；返回这个新模型。
--- template
def save_and_reload(model, path):
    torch.save(model.[[state_dict()]], path)          # 只存数字：名字 -> 张量
    sd = torch.load(path, weights_only=[[True]])      # 只允许张量、dict、数字这类纯数据
    fresh = [[Net()]]                                 # 结构来自代码
    fresh.[[load_state_dict]](sd)                     # 数字来自文件
    return fresh

--- context

def strip_prefix(sd, prefixes=("module.", "_orig_mod.")):
    out = {}
    for key, value in sd.items():
        while key.startswith(prefixes):          # startswith 可以收一个 tuple：以其中任意一个开头就是 True
            for p in prefixes:
                key = key.removeprefix(p)        # 只去开头；不是这个前缀就原样返回
        out[key] = value
    return out

--- solution
def load_strict(model, sd):
    want = model.state_dict()
    missing = sorted(set(want) - set(sd))
    unexpected = sorted(set(sd) - set(want))
    wrong_shape = [f"{k}: checkpoint {tuple(sd[k].shape)} vs model {tuple(want[k].shape)}"
                   for k in want if k in sd and tuple(sd[k].shape) != tuple(want[k].shape)]
    if missing or unexpected or wrong_shape:
        raise ValueError(
            "checkpoint 和模型对不上:\n"
            f"  missing（模型有、文件里没有）: {missing}\n"
            f"  unexpected（文件里有、模型没有）: {unexpected}\n"
            f"  shape 不同: {wrong_shape}")
    model.load_state_dict(sd)        # 已经确认对得上，这里不会半途失败
    return model

import random

def save_checkpoint(path, model, opt, sched, step):
    ckpt = {
        "model": model.state_dict(),
        "optimizer": opt.state_dict(),        # AdamW 的动量和步数
        "scheduler": sched.state_dict(),      # 走到第几步、当前学习率
        "step": step,
        "rng_torch": torch.get_rng_state(),   # dropout、torch.randn 都靠它
        "rng_cuda": torch.cuda.get_rng_state_all() if torch.cuda.is_available() else [],
        "rng_python": random.getstate(),
    }
    torch.save(ckpt, path)


def load_checkpoint(path, model, opt, sched):
    ckpt = torch.load(path, weights_only=True)
    model.load_state_dict(ckpt["model"])
    opt.load_state_dict(ckpt["optimizer"])
    sched.load_state_dict(ckpt["scheduler"])
    torch.set_rng_state(ckpt["rng_torch"])
    if ckpt["rng_cuda"] and torch.cuda.is_available():
        torch.cuda.set_rng_state_all(ckpt["rng_cuda"])
    random.setstate(ckpt["rng_python"])
    return ckpt["step"]

import os

def atomic_save(obj, path):
    tmp = path + ".tmp"                 # 同一个文件夹，os.replace 才是原子的
    try:
        torch.save(obj, tmp)
        os.replace(tmp, path)           # 要么完全没发生，要么完全发生
    except BaseException:
        if os.path.exists(tmp):
            os.remove(tmp)              # 不留半截的临时文件
        raise                           # 错误原样抛出去

        seen.append(f)

import random

def save_checkpoint(path, model, opt, sched, step):
    ckpt = {
        "model": model.state_dict(),
        "optimizer": opt.state_dict(),
        "scheduler": sched.state_dict(),
        "step": step,
        "rng_torch": torch.get_rng_state(),
        "rng_cuda": torch.cuda.get_rng_state_all() if torch.cuda.is_available() else [],
        "rng_python": random.getstate(),
    }
    torch.save(ckpt, path)


def load_checkpoint(path, model, opt, sched):
    ckpt = torch.load(path, weights_only=True)
    model.load_state_dict(ckpt["model"])
    opt.load_state_dict(ckpt["optimizer"])
    sched.load_state_dict(ckpt["scheduler"])
    torch.set_rng_state(ckpt["rng_torch"])
    if ckpt["rng_cuda"] and torch.cuda.is_available():
        torch.cuda.set_rng_state_all(ckpt["rng_cuda"])
    random.setstate(ckpt["rng_python"])
    return ckpt["step"]

def load_strict(model, sd):
    want = model.state_dict()
    missing = sorted(set(want) - set(sd))
    unexpected = sorted(set(sd) - set(want))
    wrong_shape = [f"{k}: checkpoint {tuple(sd[k].shape)} vs model {tuple(want[k].shape)}"
                   for k in want if k in sd and tuple(sd[k].shape) != tuple(want[k].shape)]
    if missing or unexpected or wrong_shape:
        raise ValueError(
            "checkpoint 和模型对不上:\n"
            f"  missing（模型有、文件里没有）: {missing}\n"
            f"  unexpected（文件里有、模型没有）: {unexpected}\n"
            f"  shape 不同: {wrong_shape}")
    model.load_state_dict(sd)
    return model

def _expect_value_error(model, sd, names, why=""):
    try:
        load_strict(model, sd)
    except ValueError as e:
        for n in names:
            true(n in str(e), f"消息里要写出 {n!r}。你的消息: {e}。{why}")
        return
    except NotImplementedError:
        raise
    except Exception as e:
        true(False, f"应该 raise ValueError，你的代码抛出了 {type(e).__name__}。这通常是 torch 自己的报错，说明你没先检查就加载了。{why}")
    true(False, f"checkpoint 有问题（{', '.join(names)}），却没有 raise ValueError。{why}")
