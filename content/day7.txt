@@ concept
title: 卷积 Conv2d 与输出尺寸
--- body
PyTorch 里一批图片的形状是 `(B, C, H, W)`：B 张图，每张 C 个通道（彩色图 C=3，就是 RGB），高 H，宽 W。

`nn.Conv2d(in_ch, out_ch, kernel, stride, padding)` 是卷积层：

- 一个 kernel×kernel 的小窗口在图上滑动。每停一个位置，就输出 `out_ch` 个数。
- **stride**（步长）：窗口每次移动几个像素。stride=2 时，输出的边长大约减半。
- **padding**（填充）：先在图的四周补几圈 0，让边上的像素也能被窗口完整盖住。

输出边长的公式（`//` 是向下取整的除法）：

```text
H_out = (H + 2*padding - kernel) // stride + 1
```

例子：H=32，kernel=4，stride=2，padding=1 → (32 + 2 − 4) // 2 + 1 = 30 // 2 + 1 = 16。

三个最常用的配置，值得背下来：

- kernel 3、stride 1、padding 1：边长不变
- kernel 4、stride 2、padding 1：边长减半
- kernel 1、stride 1、padding 0（1×1 卷积）：边长不变，只改通道数

输出的通道数只由 `out_ch` 决定，和上面的公式无关。
--- code
x = torch.zeros(1, 3, 32, 32)                      # (B, C, H, W)
for k, s, p in [(3, 1, 1), (4, 2, 1), (1, 1, 0), (5, 1, 0)]:
    y = nn.Conv2d(3, 8, k, s, p)(x)
    formula = (32 + 2 * p - k) // s + 1
    print(f"k={k} s={s} p={p}: 输出 {tuple(y.shape)}，公式算出边长 {formula}")

@@ concept
title: VAE：把图片编码成一个分布
--- body
**自编码器**（autoencoder）有两半：

- **encoder**（编码器）把图片压成一小块数字，叫**潜变量**（latent，记作 z）。
- **decoder**（解码器）把 z 还原成图片。

训练目标是还原得越像越好。

普通自编码器有个问题：潜空间里有很多「空洞」。随便取一个 z 交给 decoder，出来的多半是乱码，所以它没法用来生成新图。

**VAE**（变分自编码器）的改动：encoder 不再输出一个确定的 z，而是给 z 的每个数输出一个正态分布：

- `mu`：均值
- `logvar`：方差的对数，也就是 log(σ²)

训练时从这个分布里采样一个 z，交给 decoder 还原。loss 里再加一项 KL，把每个分布都拉向标准正态 N(0, 1)。这样潜空间被填满、变得平滑：训练完以后，从 N(0, 1) 随便采一个 z，decoder 也能画出像样的图。

为什么输出 logvar：标准差 σ 必须大于 0，而卷积层的输出可正可负。logvar 可以是任意实数，`std = exp(0.5 * logvar)` 永远大于 0。这里乘 0.5，是因为 σ = √(σ²)，开平方在对数里就是乘 0.5。

今天这个小 VAE 的形状：

```text
x (B, 3, 32, 32)
  --Encoder-->  mu, logvar (B, 4, 8, 8)
  --采样------>  z (B, 4, 8, 8)
  --Decoder-->  x_hat (B, 3, 32, 32)
```
--- code
logvar = torch.tensor([-4.0, -1.0, 0.0, 1.0, 4.0])   # 网络可以输出任意实数
std = torch.exp(0.5 * logvar)                        # 标准差：永远 > 0
print("logvar:", logvar.tolist())
print("std   :", [round(v, 3) for v in std.tolist()])
print("var   :", [round(v, 3) for v in (std ** 2).tolist()])

@@ concept
title: 重参数化：让采样也能传梯度
--- body
训练 VAE 时要从 N(mu, std²) 里采样 z。梯度要从 loss 一路传回 encoder 输出的 `mu` 和 `logvar`，可「采样」不是普通的加减乘除。

直接用 `torch.normal(mu, std)` 采样**不会报错**，但 PyTorch 把它对 `mu`、`std` 的梯度定义成 0。encoder 收不到任何信号，永远学不会。

**重参数化**（reparameterization trick）把随机性挪到参数外面：

1. 先抽一个和参数无关的标准正态噪声：`eps = torch.randn_like(std)`（形状、设备都和 `std` 一样）
2. 再算 `z = mu + std * eps`

z 的分布没变（均值 mu，标准差 std）。但现在 z 只是 mu 和 std 的加法和乘法：z 对 mu 的导数是 1，对 std 的导数是 eps，梯度能顺利传回去。

`torch.distributions.Normal` 里是同一回事：`.sample()` 不带梯度，`.rsample()`（r 就是 reparameterized）用的就是这个技巧。
--- code
mu = torch.tensor([1.0, 2.0], requires_grad=True)
logvar = torch.tensor([0.0, 2.0], requires_grad=True)

std = torch.exp(0.5 * logvar)
eps = torch.randn_like(std)          # 随机性在这里，和参数无关
z = mu + std * eps
z.sum().backward()

print("eps        :", eps)
print("mu.grad    :", mu.grad)                    # dz/dmu = 1
print("logvar.grad:", logvar.grad)                # 等于 0.5 * std * eps
print("0.5*std*eps:", (0.5 * std * eps).detach())

@@ concept
title: KL 散度：闭式解和蒙特卡洛
--- body
**KL 散度**衡量分布 q 离分布 p 有多远：永远 ≥ 0，只有 q 和 p 完全一样时才等于 0。它不是真正的「距离」：KL(q‖p) 和 KL(p‖q) 一般不相等。

VAE 里 q = N(mu, σ²)（encoder 给的分布），p = N(0, 1)（标准正态）。这种情况 KL 有现成的公式，叫**闭式解**（closed form）。每一维：

```text
KL = 0.5 * (mu² + σ² - 1 - log σ²)
   = 0.5 * (mu² + exp(logvar) - 1 - logvar)
```

- mu=0、logvar=0（q 就是 p）：0.5 × (0 + 1 − 1 − 0) = 0
- mu=1、logvar=0：0.5 × (1 + 1 − 1 − 0) = 0.5

潜变量的各维互相独立，所以整个 z 的 KL = 每一维的 KL **加起来**。对形状 `(B, 4, 8, 8)` 的 mu：先 `.flatten(1)` 变成 `(B, 256)`，再 `.sum(1)`，每个样本得到一个数，形状 `(B,)`。

**蒙特卡洛估计**（Monte Carlo，用随机采样求平均）直接按定义算：从 q 里采很多个 z，对 log q(z) − log p(z) 取平均。采样越多越准，但又慢又有噪声。所以训练用闭式解，蒙特卡洛只用来检查公式有没有写错。
--- code
mu, logvar = torch.tensor(1.0), torch.tensor(0.5)
closed = 0.5 * (mu ** 2 + logvar.exp() - 1 - logvar)

std = torch.exp(0.5 * logvar)
z = mu + std * torch.randn(200000)                     # 从 q 采样 20 万次
log_q = torch.distributions.Normal(mu, std).log_prob(z)
log_p = torch.distributions.Normal(0.0, 1.0).log_prob(z)

print(f"闭式解  : {closed.item():.4f}")
print(f"蒙特卡洛: {(log_q - log_p).mean().item():.4f}")

@@ concept
title: Encoder 和 Decoder：先压小，再放大
--- body
**Encoder** 用 stride 2 的卷积把边长一次次减半：32 → 16 → 8。通道数反而增加，让每个位置能存更多信息。

最后一层输出 `2 * z_ch` 个通道，沿通道维（第 1 维）切成两半：

- `h[:, :z_ch]` → mu
- `h[:, z_ch:]` → logvar

最后一层后面不接激活函数，因为 mu 和 logvar 可以是任意实数。

层与层之间接 **SiLU** 激活：SiLU(x) = x · sigmoid(x)，是一个平滑版的 ReLU，VAE 和扩散模型里很常用。

**Decoder** 反过来，把边长一次次翻倍：

- `nn.Upsample(scale_factor=2, mode="nearest")`：把每个像素复制成 2×2 的一块，边长翻倍。它没有可学习的参数。
- 后面接一个 kernel 3、stride 1、padding 1 的卷积（边长不变），把复制出来的方块「抹平」。
- 为什么不用 `nn.ConvTranspose2d`（转置卷积）来放大：它的窗口重叠得不均匀，容易在图上留下棋盘格一样的纹路。

Decoder 最后接 **tanh**：把任意实数压到 (-1, 1)。训练图片通常先归一化到 [-1, 1]（像素值 ÷ 127.5 − 1），输出范围正好对上。

`nn.Sequential(层1, 层2, ...)` 把多个层按顺序串起来。调用它，就是让输入依次过每一层。
--- code
x = torch.randn(2, 3, 32, 32)
h = nn.Conv2d(3, 8, 4, 2, 1)(x)
print("stride 2 卷积  :", tuple(h.shape))
mu, logvar = h[:, :4], h[:, 4:]
print("沿通道切成两半:", tuple(mu.shape), tuple(logvar.shape))

up = nn.Upsample(scale_factor=2, mode="nearest")
print("Upsample x2    :", tuple(up(mu).shape))
print(up(torch.tensor([[[[1.0, 2.0], [3.0, 4.0]]]])))
print("tanh:", torch.tanh(torch.tensor([-5.0, 0.0, 0.5, 5.0])))

@@ concept
title: VAE 的 loss：重建 + β·KL
--- body
VAE 的 loss 有两项，都是「越小越好」的代价，所以**相加**：

```text
total = recon + beta * kl
```

- **recon**（重建误差）：每张图把所有像素的平方误差**加起来**，再对 batch 取平均。
- **kl**：每个样本的 KL（所有潜变量维度加起来），再对 batch 取平均。

为什么 recon 用「求和」而不是「求平均」：一张 3×32×32 的图有 3072 个数，潜变量 4×8×8 只有 256 个数。两项都按「每个样本求和」算，量级才配得上（下面的代码里两项都在 30 左右）。如果 recon 对像素取平均，它会小几千倍，KL 就压倒一切：模型干脆不往 z 里存信息，重建出来一片模糊。

`F.mse_loss(x_hat, x, reduction="sum") / B` 和「每张图求和，再对 batch 平均」是同一个数（B 是 batch 大小）。

**beta**（β）调两项的比重：

- β 大：潜空间更接近标准正态、更平滑，但重建更模糊，维度也更容易坍塌。
- β 小：重建更清楚，但潜空间不像标准正态，从 N(0, 1) 采样生成的图会变差。
--- code
x = torch.rand(4, 3, 32, 32) * 2 - 1              # 4 张图，数值在 [-1, 1]
x_hat = x + 0.1 * torch.randn_like(x)             # 一个还不错的重建
sq = (x_hat - x) ** 2
print("对每个像素取平均          :", round(sq.mean().item(), 4))
print("每张图求和，再对 batch 平均:", round(sq.flatten(1).sum(1).mean().item(), 2))
print("F.mse_loss(sum) / B       :", round((F.mse_loss(x_hat, x, reduction="sum") / 4).item(), 2))

mu, logvar = 0.5 * torch.randn(4, 4, 8, 8), torch.zeros(4, 4, 8, 8)
kl = 0.5 * (mu ** 2 + logvar.exp() - 1 - logvar).flatten(1).sum(1).mean()
print("KL（每个样本求和，再平均）:", round(kl.item(), 2))

@@ concept
title: 潜空间：压缩比和 scaling_factor
--- body
**为什么要潜空间**：扩散模型（第 8 天）生成一张图，要把一个大网络跑几十次。Stable Diffusion 先用 VAE 把 512×512×3 的图压成 64×64×4 的潜变量，扩散模型只在潜空间里工作，最后再用 decoder 放大回图片。

**压缩比** = 图片的元素个数 ÷ 潜变量的元素个数：

- 512 × 512 × 3 = 786,432
- 64 × 64 × 4 = 16,384
- 786,432 ÷ 16,384 = 48 倍

**scaling_factor**：扩散模型往数据里加的是标准正态噪声，所以希望数据本身的标准差也差不多是 1。Stable Diffusion 的 VAE 训练时 KL 的权重非常小（约 1e-6），潜变量没有被拉到 N(0, 1)，标准差大约 5.5。

解决办法：算出一批潜变量的标准差 σ，取 s = 1/σ。

- 编码后乘上 s，再交给扩散模型（标准差 ≈ 1）；
- 扩散模型生成完，先除以 s 还原，再交给 decoder。

Stable Diffusion 1.x / 2.x 的 0.18215 就是这么来的：1 / 5.49 ≈ 0.182。换了 VAE，这个数要重新算（比如 SDXL 的 VAE 用 0.13025）。
--- code
print("压缩比:", (512 * 512 * 3) / (64 * 64 * 4))

lat = torch.randn(16, 4, 8, 8) * 5.49            # 假装这是 VAE 编码出来的潜变量
s = 1.0 / lat.std().item()
z = lat * s                                      # 交给扩散模型
print(f"原来 std = {lat.std().item():.2f}，s = {s:.4f}，乘完 std = {z.std().item():.2f}")
print("除以 s 能还原:", torch.allclose(z / s, lat))

@@ concept
title: 后验坍塌：潜变量被闲置
--- body
**后验**（posterior）指 encoder 给出的分布 q(z|x)：看到图片 x 以后，z 应该是什么样。

**后验坍塌**（posterior collapse）：对某些维度，encoder 不管看到什么图，都输出 mu≈0、logvar≈0，正好等于标准正态 N(0, 1)。这一维的 KL≈0，loss 很满意；可它不带任何关于图片的信息，decoder 也学会了忽略它。这一维白白浪费了。

常见原因：β 太大；decoder 太强，不看 z 也能重建（文本 VAE 里很常见）；训练初期 KL 压过了重建。

**怎么检测**：按维度看 KL，在一个 batch 上取平均。

1. 对 `(B, D)` 的 mu、logvar 逐元素算 KL，得到 `(B, D)`；
2. `.mean(0)` 对 batch 平均，每一维得到一个数，形状 `(D,)`；
3. 平均 KL 小于一个阈值（比如 0.01）的维度，就算坍塌了。

注意不能先把所有维度加起来（`kl_normal` 就是这么做的），那样就看不出是哪一维没被用上。

常见的补救：调小 β；KL 预热（KL warm-up：训练开始时 β 从 0 慢慢升到 1）。
--- code
B, D = 256, 4
mu, logvar = torch.zeros(B, D), torch.zeros(B, D)
mu[:, 0] = torch.randn(B) * 1.5      # 第 0 维：不同的图给出不同的 mu，在编码信息
mu[:, 1] = torch.randn(B) * 0.05     # 第 1 维：几乎不随图片变化
                                     # 第 2、3 维：永远是 N(0, 1)
kl = 0.5 * (mu ** 2 + logvar.exp() - 1 - logvar)       # (B, D)
per_dim = kl.mean(0)                                    # (D,)
print("每一维的平均 KL:", [round(v, 4) for v in per_dim.tolist()])

--- prompt
写 `reparameterize(mu, logvar)`：

- 输入：`mu` 和 `logvar`，形状相同（任意形状，比如 `(B, 4, 8, 8)`）。`logvar` 是方差的对数。
- 输出：`z`，形状和 `mu` 一样，服从均值 `mu`、标准差 `std` 的正态分布。
- 做法：`std = exp(0.5 * logvar)`；抽一个和 `std` 同形状的标准正态噪声 `eps`；`z = mu + std * eps`。
- 不许用 `torch.normal` 或 `torch.distributions` 的 `.sample()`：梯度传不回 `mu` 和 `logvar`。

检查会抽 2 万个样本，看均值和标准差对不对，再确认梯度能传回 `mu` 和 `logvar`。
--- above

mu = torch.tensor([[0.5, -1.0, 2.0]])        # (1, 3)：1 张图，3 个维度
logvar = torch.tensor([[0.0, -2.0, 1.0]])    # 方差的对数：方差 = exp(logvar)
--- below
z = reparameterize(mu.repeat(10000, 1), logvar.repeat(10000, 1))   # 同一张图复制 1 万份

--- starter

    """z = mu + std * eps，其中 std = exp(0.5 * logvar)，eps ~ N(0, 1)。"""

写 `kl_normal(mu, logvar)`：返回 q = N(mu, exp(logvar)) 相对 p = N(0, 1) 的 KL 散度。

- 输入：`mu`、`logvar` 形状 `(B, ...)`。第 0 维是 batch，后面可以有任意多维（比如 `(B, 4)` 或 `(B, 4, 8, 8)`）。

def kl_normal(mu, logvar):
    return 0.5 * (mu ** 2 + logvar.exp() - 1 - logvar).flatten(1).sum(1)

class Encoder(nn.Module):
    def __init__(self, z_ch=4):
        super().__init__()
        self.z_ch = z_ch
        self.net = nn.Sequential(
            nn.Conv2d(3, 32, 4, 2, 1), nn.SiLU(),
            nn.Conv2d(32, 64, 4, 2, 1), nn.SiLU(),
            nn.Conv2d(64, 2 * z_ch, 3, 1, 1),

--- prompt
VAE 的 encoder 最后一层是一个普通卷积，输出的数可正可负。为什么让它输出 logvar（方差的对数），再用 `std = exp(0.5 * logvar)` 得到标准差，而不是直接输出 std？
--- options
- logvar 比 std 算得更快
- 标准差必须大于 0，而卷积的输出可能是负数；logvar 可以是任意实数，取 exp 之后永远是正的
- KL 的公式里只能用 logvar，不能用 std
- std 不能求梯度，logvar 可以
answer: 2
--- explain

其他说法也不对：KL 公式用 std 也能写（log σ² 就是 logvar），std 本身也能求梯度。
