@@ concept
title: 函数：return 才把结果交出去
--- body
函数就是「一段起了名字的代码」。用 `def` 定义它的时候，里面的代码不执行；写函数名加括号（调用它）时才执行。

`return` 做三件事：

1. 把一个值交给调用它的地方。`r = double(5)` 之后，r 里就是那个值。
2. 让函数立刻结束。`return` 下面的代码不会再执行。
3. 没写 `return` 的函数，返回 `None`（意思是「没有值」）。函数里算对了也没用，结果被扔掉了。

参数可以有默认值：`def power(base, exp=2)`，调用时不给 `exp` 就用 2。也可以按名字传：`power(3, exp=4)`，更清楚，模型代码里到处是这种写法。

一次返回多个值：`return lo, hi` 返回的是一个元组（tuple），调用的地方可以拆开接住：`lo, hi = min_max(xs)`。这叫「解包」。以后天天见：`logits, loss = model(x, y)`。

### 读报错：从最后一行往上看

报错信息（traceback）的最后一行说「什么错」，往上几行说「在哪一行」。出错的那一行常常只是受害者，原因在更早的地方。最常见的几种：

- `TypeError: ... 'NoneType' ...`：拿 `None` 去算了。第一反应：这个值是哪个函数给的，那个函数有没有 `return`？
- `NameError: name 'x' is not defined`：名字拼错了，或者用了别的函数里的局部变量。
- `AttributeError: 'X' object has no attribute 'y'`：对象上没有 y。常见原因：忘了在 `__init__` 里写 `self.y = ...`，或者忘了 `super().__init__()`。
- `KeyError`：dict 里没有这个键。`IndexError`：下标越界（最大的下标是 `len(xs) - 1`）。
--- code
def double(n):
    return n * 2

def no_return(n):
    n * 2              # 算了，但没有 return，结果被扔掉

def min_max(xs):
    return min(xs), max(xs)

print(double(5))
print(no_return(5))
lo, hi = min_max([3, 1, 4, 1, 5])
print(lo, hi)

try:
    no_return(5) * 3   # 拿 None 去乘 3
except TypeError as e:
    print("TypeError:", e)

@@ concept
title: 切片和循环：含头不含尾
--- body
`xs[a:b]` 取下标 a、a+1、……、b-1 的元素：**含头不含尾**，一共 b-a 个。下标从 0 开始，`xs[-1]` 是最后一个。`xs[:k]` 和 `xs[k:]` 正好把列表切成不重叠的两半。字符串也能这样切，切出来还是字符串。

`range(start, stop, step)` 也是含头不含尾：`range(0, 10, 3)` 给出 0, 3, 6, 9。

`for x in xs:` 把元素一个一个拿出来，每拿一个，就把下面缩进的代码从头到尾执行一遍。几个常用写法：

- 累加：先 `total = 0`，循环里 `total += x`。训练时统计 loss 就是这样。
- 推导式：`[x * x for x in xs]` 一行造出一个新列表。读法：先看中间的 `for`，再看最前面「每轮产出什么」。
- `enumerate(xs)` 同时给出下标和元素。`zip(a, b)` 把两个列表按位置配成对，按短的那个停，所以 `zip(xs, xs[1:])` 正好是所有相邻的两个。
- `continue` 跳过这一轮剩下的代码，直接进下一轮；`break` 让整个循环立刻结束。

### 预测下一个 token 的数据，就是两行切片

`x = data[i:i + T]`，`y = data[i + 1:i + 1 + T]`。y 的每个元素，正好是 x 同一位置元素的「下一个」。这一个 `+ 1` 写错，模型会学会抄答案，而且不报任何错。
--- code
xs = [10, 20, 30, 40, 50]
print(xs[1:3], xs[:2], xs[2:], xs[-1])
print("abcdef"[1:4])
print(list(range(0, 10, 3)))

total = 0
for x in xs:
    total += x
print("total =", total)
print([x // 10 for x in xs])

for i, (a, b) in enumerate(zip(xs, xs[1:])):
    print(i, a, b, b - a)

data = list(range(10))
i, T = 3, 4
print("x =", data[i:i + T])
print("y =", data[i + 1:i + 1 + T])

title: dict：计数和排序
--- body
list 用数字下标（`xs[0]`），dict 用你自己定的「键」：`cfg["lr"]`。键不存在时，`cfg["x"]` 会报 `KeyError`；`cfg.get("x", 0)` 不报错，返回你给的默认值 0。

数数的固定写法，读作「取出 c 现在的次数，没有就当 0，加 1，再存回去」：

```
counts[c] = counts.get(c, 0) + 1
```

`d.items()` 给出所有 `(键, 值)` 对。`sorted(一串东西, key=函数)` 按「函数算出来的值」从小到大排，返回一个新 list：

- `lambda kv: ...` 是一个没有名字的小函数，这里 kv 就是一个 `(键, 值)` 对，`kv[1]` 是值。
- 想从大到小：key 取负号，`key=lambda kv: -kv[1]`。
- 想「先按次数从大到小，次数一样再按键从小到大」：key 返回一个元组 `(-kv[1], kv[0])`。元组比较时先比第一个，一样再比第二个。

dict 推导式和列表推导式一样：`{c: i for i, c in enumerate(chars)}`。第 3 天写分词器（tokenizer）就用它把字符换成编号。
--- code
counts = {}
for c in "banana":
    counts[c] = counts.get(c, 0) + 1
print(counts)
print(counts.get("z", 0))

for k, v in counts.items():
    print(k, v)

print(sorted(counts.items(), key=lambda kv: -kv[1]))
print(sorted([("x", 1), ("r", 2), ("b", 2)], key=lambda kv: (-kv[1], kv[0])))

stoi = {c: i for i, c in enumerate("abc")}
print(stoi)

@@ concept
title: 赋值是贴标签，不是复制
--- body
Python 里 `b = a` 从来不复制数据。它只是给 a 指着的那个东西，再贴一张标签 b。如果那个东西能被就地修改（list、dict，以及以后的张量和模型），通过 b 改了它，从 a 看也变了。把 list 传进函数也一样：函数拿到的是同一个 list，不是副本。

- 想真的复制，要明说：`a.copy()` 或 `list(a)`。
- `==` 问「值一样吗」，`is` 问「是不是同一个东西」。
- 数字、字符串、元组不能就地修改。`n = n + 1` 是让 n 指向一个新的数，不影响别的名字，所以不用担心。

### 由此而来的坑：可变默认参数

`def f(x, acc=[])` 里的那个 `[]`，是在**定义函数的时候**建好的，只建一次。之后每次调用用的都是同一个列表，上一次的结果会留到下一次。

正确写法：默认值写 `None`，在函数体里现建一个（`if acc is None: acc = []`）；或者干脆不把它做成参数，函数体第一行写 `acc = []`。

dataclass 里的 list 字段要写 `field(default_factory=list)`，是同一个道理：让每个对象现建一个新列表。
--- code
a = [1, 2, 3]
b = a
b.append(4)
print("a =", a, "| a is b:", a is b)

c = a.copy()
c.append(5)
print("a =", a, "| c =", c, "| a is c:", a is c)

def bad(x, acc=[]):
    acc.append(x)
    return acc

print(bad(1))
print(bad(2))      # 你以为是 [2]

def good(x, acc=None):
    if acc is None:
        acc = []   # 每次调用现建一个新的
    acc.append(x)
    return acc

print(good(1))
print(good(2))

@@ concept
title: class：self、__init__ 和 __call__
--- body
class 是一张图纸：把「一份数据」和「操作这份数据的函数」打包在一起。照图纸造出来的东西叫实例（对象），可以造很多个，互不干扰。

- `__init__(self, ...)`：造对象时 Python 自动调用它，用来把初始数据挂到对象上。它不写 `return`。
- `self` 就是点号左边的那个对象。你写 `a.add(5)`，Python 实际执行的是 `Counter.add(a, 5)`。所以定义方法时第一个参数写 `self`，调用时不用传。
- `self.n = 0` 把数据挂在对象上，别的方法和外面都读得到。方法里不带 `self.` 的变量是局部变量，方法一结束就没了。一句话：**想让数据活过这个函数，就挂到 self 上。**
- `__call__(self, ...)`：定义了它，对象就能像函数一样加括号调用，`obj(x)` 等于 `obj.__call__(x)`。

前后带两个下划线的方法（读作 dunder）都是「Python 在特定时机自动调用」的。

PyTorch 里 `y = model(x)` 能加括号，就是因为 `nn.Module` 定义了 `__call__`，它再去调用你写的 `forward`。所以永远写 `model(x)`，不要写 `model.forward(x)`（那样会跳过 PyTorch 注册的钩子 hooks）。
--- code
class Scaler:
    def __init__(self, factor):
        self.factor = factor      # 挂到 self 上，之后的方法都用得到
        self.calls = 0

    def __call__(self, x):
        self.calls += 1
        return x * self.factor

double = Scaler(2)
triple = Scaler(3)
print(double(21), triple(21))
print(double(1), double.calls, triple.calls)
print(Scaler.__call__(double, 5))  # 和 double(5) 完全一样

class Tiny(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc = nn.Linear(4, 2)

    def forward(self, x):
        return self.fc(x)

m = Tiny()
y = m(torch.ones(3, 4))            # nn.Module 的 __call__ -> 你的 forward
print(y.shape)

@@ concept
title: 继承、super() 和 @property
--- body
继承：`class B(A):` 表示 B 先照抄 A 的所有方法，再加几样、改几样。子类里写一个同名方法，就覆盖了父类的那个。

`super()` 指「父类」。两个固定用法：

- 子类自己写了 `__init__`，父类的 `__init__` 就被盖掉了，不会自动执行。所以子类 `__init__` 的第一行写 `super().__init__(...)`，先让父类把它那部分属性挂好，再加自己的。
- 子类改写一个方法，但还想保留父类的行为：在里面先调 `super().方法名(...)`，再加自己的步骤。

每个 `nn.Module` 子类的 `__init__` 第一行都是 `super().__init__()`。忘了写，给 `self.fc = nn.Linear(...)` 赋值时就会报 `AttributeError: cannot assign module before Module.__init__() call`。

### @property：读的时候不带括号的方法

在方法上面加一行 `@property`，读它就不用写括号：`m.left` 而不是 `m.left()`。适合「由别的属性算出来」的值：每次读都现算，永远和原始数据同步，不会忘了更新。

property 默认只能读。写 `m.left = 1` 会报错（`property 'left' of ... object has no setter`）。子类想换一种算法，就在子类里重新写一个同名的 `@property`。
--- code
class Meter:
    def __init__(self, total):
        self.total = total
        self.used = 0

    def use(self, k):
        self.used += k

    @property
    def left(self):                # 每次读都现算
        return self.total - self.used

class LoggedMeter(Meter):
    def __init__(self, total):
        super().__init__(total)    # 先让父类挂好 total 和 used
        self.history = []

    def use(self, k):
        super().use(k)             # 保留父类的行为
        self.history.append(k)     # 再加自己的

m = LoggedMeter(10)
m.use(3)
m.use(4)
print(m.used, m.left, m.history)

class Forgot(Meter):
    def __init__(self, total):
        self.history = []          # 忘了 super().__init__(total)

try:
    Forgot(10).left
except AttributeError as e:
    print("AttributeError:", e)

class BadNet(nn.Module):
    def __init__(self):
        self.fc = nn.Linear(2, 2)  # 忘了 super().__init__()

try:
    BadNet()
except AttributeError as e:
    print("AttributeError:", e)

@@ concept
title: 训练脚本的外壳：dataclass、f-string、pathlib
--- body
打开任何一个训练项目，最外面这层都差不多：一个配置对象，每隔几步打一行日志，把 checkpoint（模型权重的存档）存到某个目录。

### dataclass：配置对象

在 class 上面加 `@dataclass`，只写「字段名: 类型 = 默认值」，`__init__`、打印格式、比较都会自动生成。想改哪个值就按名字传：`Cfg(lr=1e-3)`。dataclass 里照样可以写方法。冒号后面的类型只是给人看的，Python 不检查。

list、dict 这种可变的默认值不能直接写 `= []`（dataclass 会直接报错），要写 `field(default_factory=list)`，让每个对象现建一个新列表（原因见卡片「赋值是贴标签，不是复制」）。

### f-string：日志

字符串前面加 `f`，`{}` 里就能放变量和表达式，冒号后面写格式：

- `{step:5d}`：整数，右对齐，宽度 5
- `{loss:.4f}`：保留 4 位小数
- `{lr:.2e}`：科学计数法，2 位小数（`3e-4` 显示成 `3.00e-04`）
- `{step:06d}`：宽度 6，前面补 0
- `{dt * 1000:.1f}`：先算，再格式化

### pathlib：路径

`Path("runs") / "gpt-tiny" / "ckpt.pt"` 用 `/` 拼路径，Windows 和 Linux 都对。`p.name` 是文件名，`p.parent` 是所在的目录。`d.mkdir(parents=True, exist_ok=True)` 把目录建出来：`parents=True` 连不存在的上级目录一起建，`exist_ok=True` 表示目录已经存在也不报错。

文件名里的步数要补零（`ckpt_000009.pt`），按名字排序时顺序才对。
--- code
from dataclasses import dataclass, field
from pathlib import Path

@dataclass
class Cfg:
    lr: float = 3e-4
    n_layer: int = 6
    tags: list = field(default_factory=list)

a = Cfg()
b = Cfg(lr=1e-3)
a.tags.append("baseline")
print(a)
print(b)

step, loss, lr, dt = 7, 2.718281, 6e-4, 0.0421
print(f"[{step:5d}] [{loss:.4f}] [{lr:.2e}] [{dt * 1000:.1f}ms] [{step:06d}]")

p = Path("runs") / "gpt-tiny" / "last.pt"
print(p.name, p.parent.name, p.suffix)
print(sorted(f"ckpt_{s}.pt" for s in [9, 10, 100]))
print(sorted(f"ckpt_{s:06d}.pt" for s in [9, 10, 100]))

title: *args / **kwargs 和装饰器
--- body
`def f(*args, **kwargs)` 能收下任何参数：按位置传的收进 `args`（一个元组），按名字传的收进 `kwargs`（一个 dict）。反过来，调用时加星号是「拆开传」：`g(*args, **kwargs)` 把它们原样交给另一个函数。

装饰器就是「接收一个函数、返回一个新函数」的函数。

```
@deco
def f(x): ...
```

等于先定义 `f`，再执行 `f = deco(f)`。

写装饰器的固定骨架：在里面定义一个 `wrapper(*args, **kwargs)`，先做你想加的事，再 `return fn(*args, **kwargs)` 原样转发，最后 `return wrapper`。在 wrapper 上面加 `@functools.wraps(fn)`，新函数才会保留原函数的名字（`__name__`），不然名字会变成 `wrapper`。

模型代码里天天见的装饰器：`@dataclass`、`@property`、`@torch.no_grad()`（这个函数里不记录求导信息，推理时用）。
--- code
import functools

def show_all(*args, **kwargs):
    print("args =", args, "| kwargs =", kwargs)

show_all(1, 2, lr=0.01)

def power(base, exp):
    return base ** exp

print(power(*(2, 10)), power(**{"base": 3, "exp": 4}))

def traced(fn):
    @functools.wraps(fn)
    def wrapper(*args, **kwargs):
        print("calling", fn.__name__, args, kwargs)
        return fn(*args, **kwargs)
    return wrapper

@traced
def add(a, b):
    return a + b

print(add(1, b=2))
print(add.__name__)

def no_wraps(fn):
    def wrapper(*args, **kwargs):
        return fn(*args, **kwargs)
    return wrapper

@no_wraps
def mul(a, b):
    return a * b

print(mul.__name__)   # 名字丢了

from dataclasses import dataclass, field

@dataclass
class TrainConfig:
    lr: float = 3e-4
    batch_size: int = 32
    n_layer: int = 6
    device: str = "cuda"
    betas: tuple = (0.9, 0.95)
    tags: list = field(default_factory=list)   # 可变默认值必须用 default_factory

    def scaled_lr(self, k):
        return self.lr * k
--- tests
@check("默认值都对")
def t01a():
    c = TrainConfig()
    true(c.lr == 3e-4, f"lr 默认值应为 3e-4，你的: {c.lr!r}")
    true(c.batch_size == 32 and c.n_layer == 6, f"batch_size / n_layer 应为 32 / 6，你的: {c.batch_size!r} / {c.n_layer!r}")
    true(c.device == "cuda", f"device 默认值应为 'cuda'，你的: {c.device!r}")
    true(c.betas == (0.9, 0.95), f"betas 默认值应为 (0.9, 0.95)，你的: {c.betas!r}")

@check("两个实例不共用同一个 tags 列表")
def t01b():
    a, b = TrainConfig(), TrainConfig()
    a.tags.append("x")
    true(b.tags == [], "两个实例共享了同一个 list —— 这就是必须用 field(default_factory=list) 的原因")

@check("scaled_lr(k) 返回 lr * k")
def t01c():
    got = TrainConfig(lr=1e-3).scaled_lr(2)
    true(close(got, 2e-3), f"TrainConfig(lr=1e-3).scaled_lr(2) 应为 0.002，你的: {got!r}")
--- hints
- 每个字段一行：`名字: 类型 = 默认值`，照着 `lr` 那一行往下写。
- 列表字段写成 `tags: list = field(default_factory=list)`，`field` 已经在第一行导入了。
- 方法和普通 class 里一样写，注意缩进在 class 里面：`def scaled_lr(self, k):`，下一行 `return self.lr * k`。

class RunningMean:
    def __init__(self):
        self.reset()

    def reset(self):
        self.total = 0.0
        self.n = 0

    def __call__(self, x):
        self.total += float(x)
        self.n += 1
        return self.value

    @property
    def value(self):
        return self.total / self.n if self.n else 0.0

--- solution
class EMAMean(RunningMean):
    def __init__(self, decay=0.9):
        super().__init__()
        self.decay = decay
        self._v = None

    def __call__(self, x):
        x = float(x)
        self._v = x if self._v is None else self.decay * self._v + (1 - self.decay) * x
        self.n += 1
        return self._v

    @property
    def value(self):
        return 0.0 if self._v is None else self._v

    def reset(self):
        super().reset()
        self._v = None

--- solution
def bucket_by_len(samples, bucket_size=2):
    out = {}                       # 修 1：可变默认值挪进函数体，每次调用现建
    for s in samples:
        L = len(s)
        out.setdefault(L, [])
        if len(out[L]) >= bucket_size:
            continue               # 修 2 + 3：先检查再 append；满了就跳过，不报错
        out[L].append(s)
    return out

class RunningMean:
    def __init__(self):
        self.reset()

    def reset(self):
        self.total = 0.0
        self.n = 0

    def __call__(self, x):
        self.total += float(x)
        self.n += 1
        return self.value

    @property
    def value(self):
        return self.total / self.n if self.n else 0.0
--- tests

def make_xy(data, i, block_size):
    x = data[i:i + block_size]
    y = data[i + 1:i + 1 + block_size]
    return x, y
--- tests
